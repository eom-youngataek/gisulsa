# 딥러닝 핵심 키워드 정리 (정보관리기술사 대비)

> **공통 답안 전개 구조**: 구조도(입력→은닉→출력) → 수식 기반 동작원리 → 활용분야/사례

---

## 1. 피드포워드NN / 역전파 / 활성화함수

| 구분 | 내용 |
|---|---|
| **구조** | 입력층 → 은닉층(1개 이상) → 출력층 — 신호가 한 방향(앞으로만)으로 흐름, 순환 없음 |

**수식 기반 동작원리**
- 순전파(Forward): y = f(W·x + b)  (W=가중치, b=편향, f=활성화함수)
- 역전파(Backpropagation): 출력의 오차(Loss)를 출력층→은닉층→입력층 방향으로 거슬러 전달하며 가중치를 수정. 연쇄법칙(Chain Rule)으로 ∂Loss/∂W 계산 후 경사하강법으로 갱신
- 활성화함수: Sigmoid(0~1 출력, 기울기 소실 문제), ReLU(음수는 0, 양수는 그대로 — 현재 표준), Softmax(다중분류 출력 확률화)

**예시 적용**
- 상황: 입력(시험점수80) → 은닉층(가중치 0.5) → 출력(합격예측 0.7)인데 실제 정답은 1(합격)
- 오차 = 1 - 0.7 = 0.3 → 이 오차를 역전파시켜 가중치를 "0.7이 1에 더 가까워지도록" 미세조정

**활용분야**
> 가장 기본적인 신경망 구조로, 모든 딥러닝 모델(CNN, RNN, 트랜스포머 등)의 학습 메커니즘(역전파)의 토대가 됨. 단순 회귀·분류 문제(신용평가, 수요예측)에 직접 활용

---

## 2. CNN Layer (Convolutional Neural Network)

| 구분 | 내용 |
|---|---|
| **구조** | 입력(이미지) → **합성곱층(Convolution)** → **풀링층(Pooling)** → (반복) → 완전연결층(FC) → 출력 |

**수식 기반 동작원리**
- 합성곱: 작은 필터(커널, 예 3×3)를 이미지 위에서 슬라이딩하며 픽셀값과 가중치를 곱해 합산 → 특징맵(Feature Map) 생성
- 풀링(Max Pooling): 영역 내 최댓값만 추출해 크기를 줄이고 핵심특징만 보존 (예: 2×2 영역에서 가장 큰 값 하나만 남김)
- 계층이 깊어질수록: 저층(Edge·선 검출) → 중층(눈·코 모양) → 고층(얼굴 전체) 순으로 추상화

**예시 적용**
- 상황: 28×28 손글씨 이미지에 3×3 필터 적용 → 26×26 특징맵 생성 → 2×2 맥스풀링 → 13×13으로 축소

**활용분야**
> 이미지 분류, 객체 검출(자율주행 보행자 인식), 의료영상 판독(CT/MRI 종양 진단)

---

## 3. GNN (Graph Neural Network)

| 구분 | 내용 |
|---|---|
| **구조** | 입력(노드+엣지로 구성된 그래프) → **메시지 전달(Message Passing)** 반복 → 노드 임베딩 → 출력(노드/그래프 분류) |

**수식 기반 동작원리**
- 각 노드는 자신의 정보와 **이웃 노드들의 정보를 집계(Aggregation)**해 자신의 표현(임베딩)을 갱신: h_v^(k) = f(h_v^(k-1), Σ h_u^(k-1) for u∈neighbors(v))
- k번 반복(레이어 수)할수록 더 먼 이웃의 정보까지 반영

**예시 적용**
- 상황: SNS 친구관계 그래프에서 "이 사람이 가짜계정인가?" 판단 — 본인 프로필 정보 + 친구들(이웃노드)의 평균적 특성을 함께 집계해 판단

**활용분야**
> 소셜네트워크 분석, 추천시스템(사용자-상품 그래프), 신약개발(분자구조 그래프), 전력수요 예측(VPP에서 발전소 간 연결망 그래프 활용)

---

## 4. VAE (Variational AutoEncoder)

| 구분 | 내용 |
|---|---|
| **구조** | 입력 → **인코더**(압축) → **잠재공간(latent space, 평균μ·분산σ로 표현)** → **디코더**(복원) → 출력 |

**수식 기반 동작원리**
- 인코더는 입력을 고정값이 아닌 **확률분포(μ, σ)**로 압축 → 이 분포에서 샘플링해 디코더에 전달
- 손실함수 = 복원오차(원본과 똑같이 만들기) + KL발산(잠재공간이 정규분포에 가깝도록 규제)

**예시 적용**
- 상황: 사람 얼굴 사진을 잠재공간(z)으로 압축 후, z값을 살짝 바꿔서 디코더에 넣으면 "비슷하지만 조금 다른 새로운 얼굴" 생성

**활용분야**
> 새로운 이미지/데이터 생성(생성형AI의 초기 모델), 이상탐지(정상데이터로만 학습 후 복원오차가 큰 데이터를 이상치로 판별), 합성데이터 생성(PET 기술과 연계)

---

## 5. SNN (Spiking Neural Network)

| 구분 | 내용 |
|---|---|
| **구조** | 입력(스파이크 신호, 시간에 따른 펄스) → 뉴런(전위 누적) → **임계값 초과 시에만 스파이크 발생(출력)** — 기존 신경망과 달리 시간축 정보를 가짐 |

**수식 기반 동작원리**
- 뉴런의 막전위(membrane potential)가 입력 스파이크를 받을 때마다 누적되다가, 임계값(threshold)을 넘으면 스파이크 1개를 발생시키고 전위는 0으로 리셋(생물학적 뉴런 모방)
- 이벤트 기반(Event-driven) 연산: 스파이크가 없으면 연산도 없음 → 초저전력

**예시 적용**
- 기존 인공신경망: 모든 뉴런이 매 순간 곱셈·합산 연산 수행(항상 켜짐) vs SNN: 신호가 들어올 때만 반응(꺼져있다가 필요시만 작동)

**활용분야**
> 뉴로모픽 반도체(저전력 AI칩)의 핵심 동작원리, 엣지디바이스·웨어러블 등 배터리 제약 환경에서의 실시간 AI 처리

---

## 6. 트랜스포머 / MoE (Mixture of Experts)

| 구분 | 내용 |
|---|---|
| **구조** | 입력(토큰 임베딩) → **인코더/디코더 블록**(Self-Attention + Feed Forward 반복) → 출력 / **MoE는 Feed Forward 부분을 여러 "전문가(Expert)" 네트워크로 교체** |

**수식 기반 동작원리**
- 트랜스포머: Self-Attention으로 문장 내 모든 토큰 간 관계를 한번에 계산(병렬처리 가능, RNN처럼 순차처리 불필요)
- MoE: 입력마다 **게이팅 네트워크(Gating)**가 "이 입력은 어떤 전문가가 처리할지" 선택 → 전체 파라미터 중 일부(예: 8개 전문가 중 2개)만 활성화해 연산

**예시 적용**
- 상황: "법률 문서"가 입력되면 게이팅이 "법률 전문가 네트워크"를 선택해 활성화, 다른 전문가(의료/코딩 등)는 쉬게 함

**활용분야**
> 대규모 언어모델(GPT, Mixtral 등)의 핵심 구조 — MoE는 모델 전체 크기를 키우면서도 실제 연산량(추론비용)은 줄이는 효율화 기법으로 활용

---

## 7. Self-Attention

| 구분 | 내용 |
|---|---|
| **구조** | 입력 토큰들 → **Query, Key, Value** 3개 벡터로 변환 → 토큰 간 연관도 계산 → 가중합으로 출력 |

**수식 기반 동작원리**
- Attention(Q,K,V) = softmax(QK^T/√dk)V
- 각 토큰의 Query와 다른 모든 토큰의 Key를 내적(유사도 계산) → softmax로 정규화(가중치 합=1) → Value에 가중합

**예시 적용**
- 문장: "그는 사과를 먹었는데, **그것**이 맛있었다" → "그것"의 Query가 문장 내 모든 단어의 Key와 비교 → "사과"의 Key와 가장 유사도가 높음 → "그것"=사과로 연결(높은 attention weight)

**활용분야**
> 문맥 파악이 필요한 모든 NLP 작업(번역, 요약), 트랜스포머/LLM의 핵심 동작원리, 이미지(Vision Transformer)에도 확장 적용

## 8. TF-IDF (log 계산)

| 구분 | 내용 |
|---|---|
| **구조** | 문서집합(입력) → 단어별 출현빈도(TF) 계산 → 단어별 문서희소성(IDF) 계산 → TF×IDF(출력 가중치) |

**수식 기반 동작원리**
- TF(단어빈도) = 해당 문서에서 그 단어가 나온 횟수
- IDF(역문서빈도) = log(전체문서수 / 그 단어가 나온 문서수)
- TF-IDF = TF × IDF

**예시 적용 (132회 기출 패턴)**
- 상황: 전체 문서 3개 중 "엔진"이라는 단어가 문서1에 15회, 3개 문서 모두에 등장(DF=3)
- IDF("엔진") = log(3/3) = log(1) = **0**
- 만약 "스티어링휠"이 문서2에만 등장(DF=1)이면 IDF = log(3/1) = **0.47**
- 판정: 모든 문서에 흔하게 등장하는 단어(엔진)는 IDF=0이 되어 가중치가 사라지고, 특정 문서에만 등장하는 단어(스티어링휠)는 가중치가 높아짐

**활용분야**
> 검색엔진의 문서 관련도 순위 산정, 문서 핵심 키워드 추출, RAG의 검색(Retrieval) 단계에서 키워드 기반 매칭 보조 지표로 활용

## 9. [신규] 안면인식 결제서비스 (생체인식AI)

| 구분 | 내용 |
|---|---|
| **구조** | 카메라 입력(얼굴영상) → **얼굴검출(Detection)** → **특징점 추출(Embedding, CNN 기반)** → **등록된 얼굴DB와 유사도 비교(매칭)** → 결제승인/거부 출력 |

**수식 기반 동작원리**
- CNN으로 얼굴을 고차원 벡터(임베딩)로 변환 → 등록된 벡터와 코사인 유사도 계산: similarity = (A·B)/(\|A\|\|B\|)
- 유사도가 임계값(예: 0.9) 이상이면 본인으로 인정해 결제 승인

**예시 적용**
- 상황: 결제 시 촬영한 얼굴의 임베딩벡터와 사전 등록된 벡터의 코사인 유사도가 0.95로 계산 → 임계값(0.9) 초과 → 본인 인증 성공, 결제 승인

**활용분야**
> 오프라인 무인매장 결제, 출입통제 시스템, 공항 자동출입국심사. 다만 **딥페이크 위변조 위험**, 생체정보 유출 시 변경 불가능한 점에서 PET(개인정보보호강화기술)·라이브니스 검사(Liveness Detection, 사진이 아닌 실제 사람인지 확인)와 결합이 필수

## 📌 키워드 간 연결 요약

```
피드포워드NN/역전파/활성화함수 ──→ (모든 딥러닝 모델의 학습 기반)
        │
        ├──→ CNN Layer ──→ 안면인식 결제서비스 (얼굴 특징추출에 CNN 활용)
        │
        ├──→ GNN (그래프 데이터 특화)
        │
        ├──→ VAE (생성·압축, 비지도학습)
        │
        └──→ SNN (저전력·생물학적 모방, 뉴로모픽 반도체와 연계)

트랜스포머/MoE ──→ Self-Attention (트랜스포머의 핵심 연산)
        │
        └──→ TF-IDF (검색·키워드 가중치, RAG의 보조 검색기법으로 연결)
```
