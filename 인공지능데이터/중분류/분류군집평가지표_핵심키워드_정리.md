# 머신러닝 핵심 키워드 정리 (정보관리기술사 대비)

> **공통 답안 전개 구조**: 알고리즘 동작원리 → 장단점 → 평가지표 계산공식 적용(주어진 TP/FP/FN/TN으로 직접 산출) → 결과해석

---

## 1. K-means Clustering

| 구분 | 내용 |
|---|---|
| **동작원리** | 군집 개수 k를 미리 정하고, 각 점을 가장 가까운 중심(centroid)에 할당 → 중심을 재계산 → 반복(수렴까지) |

**장단점**
- 장점: 알고리즘 단순, 대용량 데이터에도 빠름
- 단점: k값을 미리 정해야 함, 군집이 원형이 아니면(찌그러진 모양) 성능 저하, 이상치에 민감

**예시 적용**
- 상황: 고객 5명의 연간구매액(만원) [10, 12, 50, 52, 90]을 k=2로 군집화
- 1회 반복: 중심(10,90)에서 시작 → [10,12]는 10에 가까움, [50,52,90]은 90에 가까움 → 중심 재계산: (11, 64)
- 2회 반복: [10,12,50]은 11에 가까움, [52,90]은 64에 가까움 → 중심 재계산: (24, 71) → 수렴까지 반복

**결과해석**
> 고객을 "저가 구매군"과 "고가 구매군"으로 자동 분류 → VIP 마케팅 타겟 선정에 활용

## 2. DBSCAN

| 구분 | 내용 |
|---|---|
| **동작원리** | 밀도가 일정 기준(반경 ε 내 최소점개수 minPts) 이상인 점들을 군집으로 묶고, 밀도가 낮은 점은 이상치(Noise)로 분류 — k값을 미리 정하지 않음 |

**장단점**
- 장점: 군집 개수를 미리 몰라도 됨, 비정형(원형이 아닌) 군집도 탐지 가능, 이상치 자동 식별
- 단점: ε, minPts 파라미터 설정이 까다로움, 밀도가 서로 다른 군집이 섞이면 성능 저하

**예시 적용**
- 상황: ε=2, minPts=3 설정. 좌표 (1,1),(1,2),(2,1),(2,2),(50,50) 중 (50,50)은 반경 2 내 이웃이 0개
- 판정: (1,1)~(2,2) 4개는 밀집 → 1개 군집, (50,50)은 이웃 부족 → **Noise(이상치)**로 분류

**결과해석**
> 신용카드 이상거래 탐지 — 정상거래는 군집으로 묶이고, 패턴이 다른 거래는 자동으로 이상치로 분리되어 사기탐지에 활용

---

## 3. SVM 마진분류 2가지

| 구분 | 내용 |
|---|---|
| **동작원리** | 두 클래스를 가장 넓게 분리하는 결정경계(초평면)를 찾는 분류기. 마진(여유공간)을 최대화 |

**마진분류 2가지**
- **하드마진(Hard Margin)**: 오류를 전혀 허용하지 않고 완벽하게 분리(노이즈 없는 데이터에만 적용 가능)
- **소프트마진(Soft Margin)**: 일부 오분류를 허용(슬랙변수 도입)해 현실 데이터에 적용 가능하도록 유연화

**장단점**
- 장점: 고차원 데이터에 강함, 마진 최대화로 일반화 성능 우수
- 단점: 대용량 데이터에 느림, 커널 함수 선택이 까다로움

**예시 적용**
- 스팸메일 분류: 정상메일과 스팸메일이 깔끔히 나뉘면 하드마진, 일부 애매한 메일이 섞여있으면(현실적) 소프트마진으로 C값(허용오차) 조정

**결과해석**
> 의료영상에서 양성/악성 종양처럼 명확한 경계가 필요한 분류 문제에 적합 — 오진 허용범위를 소프트마진의 C값으로 조절 가능

## 4. 의사결정나무 (지니지수/엔트로피)

| 구분 | 내용 |
|---|---|
| **동작원리** | 데이터를 가장 잘 나누는 기준(변수)을 찾아 트리형태로 반복 분할. 분할 기준으로 지니지수 또는 엔트로피의 "불순도 감소"가 최대인 변수를 선택 |
| **수식** | 지니지수 = 1 - Σ(pi)² / 엔트로피 = -Σ pi×log2(pi) |

**예시 적용**
- 상황: 노드에 "구매" 6명, "비구매" 4명(총10명)
- 지니지수 = 1 - (0.6² + 0.4²) = 1 - (0.36+0.16) = **0.48**
- 엔트로피 = -(0.6×log2(0.6) + 0.4×log2(0.4)) = -(0.6×(-0.737)+0.4×(-1.32)) = **0.971**
- 판정: 두 지표 모두 값이 작을수록(0에 가까울수록) 순수한 노드 → 분할기준 선택 시 값이 더 작아지는 변수를 선택

**결과해석**
> 두 지표 모두 결과는 유사하나, 지니지수가 계산이 더 간단해 CART(분류회귀나무)에서 주로 사용. 대출승인 여부, 고객이탈 예측 등에서 "어떤 변수가 가장 중요한지"를 시각적으로 설명 가능한 장점

---

## 5. 앙상블 (Bagging / Boosting)

| 구분 | 내용 |
|---|---|
| **Bagging 원리** | 원본 데이터에서 복원추출로 여러 표본(부트스트랩)을 만들어 각각 독립적으로 모델 학습 → 결과를 투표/평균(예: 랜덤포레스트) |
| **Boosting 원리** | 이전 모델이 틀린 데이터에 가중치를 높여서 다음 모델이 그 부분을 더 학습 → 순차적으로 모델을 보완(예: AdaBoost, XGBoost) |

**장단점**
- Bagging: 분산(과적합) 감소에 강함, 병렬처리 가능 / 편향이 큰 모델엔 한계
- Boosting: 편향 감소에 강함, 성능이 높음 / 순차적이라 느리고 과적합 위험(이상치에 취약)

**예시 적용**
- Bagging: 의사결정나무 100개를 서로 다른 부트스트랩 표본으로 학습 후 다수결 투표 → 랜덤포레스트
- Boosting: 1차 모델이 "고소득층 이탈"을 잘못 예측 → 2차 모델은 고소득층 데이터에 가중치를 높여 재학습

**결과해석**
> "병렬로 여러 의견을 모아 평균내는 것(Bagging)"과 "약점을 순차적으로 보완해가는 것(Boosting)"의 차이로 암기. 신용평가, 추천시스템 등 실무에서 가장 널리 쓰이는 고성능 기법

## 6. SOM (Self Organizing Map)

| 구분 | 내용 |
|---|---|
| **동작원리** | 고차원 데이터를 2차원 격자(그리드)에 비지도학습으로 매핑(투영)해 시각화. 입력과 가장 유사한 뉴런(BMU)과 그 주변 뉴런들의 가중치를 함께 업데이트 |

**장단점**
- 장점: 고차원 데이터를 사람이 보기 쉬운 2D로 시각화 가능, 군집 간 위상관계(가까움/멈) 보존
- 단점: 학습시간이 오래 걸림, 격자 크기·학습률 등 파라미터 설정에 따라 결과가 민감

**예시 적용**
- 상황: 고객 100명의 구매패턴(10개 변수)을 2D 격자(5×5)에 매핑
- 결과: 비슷한 구매패턴을 가진 고객은 격자에서 가까운 칸에 모이고, 패턴이 다르면 멀리 떨어짐

**결과해석**
> 일반 군집분석(K-means)과 달리 "군집 간 거리 관계"까지 시각적으로 보여줘 시장세분화, 이상패턴 탐지 시 직관적 해석에 유리

## 7. 혼동행렬 → 정확도·정밀도·재현율·F1-score (계산형, 136회 패턴)

| 구분 | 내용 |
|---|---|
| **동작원리** | 분류모델의 예측결과를 실제값과 교차표(TP/FP/FN/TN)로 정리해 성능을 다각도로 평가 |
| **수식** | 정확도=(TP+TN)/전체, 정밀도=TP/(TP+FP), 재현율=TP/(TP+FN), F1=2×(정밀도×재현율)/(정밀도+재현율) |

**숫자 대입 (136회 기출 패턴)**

주어진 값: TP=100, FP=5, FN=7, TN=9 (총 121건)

| 지표 | 계산 | 결과 |
|---|---|---|
| 정확도 | (100+9)/121 | **90%** |
| 정밀도 | 100/(100+5) | **95%** |
| 재현율 | 100/(100+7) | **93%** |
| F1-score | 2×(0.95×0.93)/(0.95+0.93) | **94%** |

**결과해석**
> 정확도만 보면 좋아 보이지만, FP·FN의 비즈니스적 비용이 다를 때(예: 암 진단에서 FN(놓침)이 FP(과잉진단)보다 훨씬 위험) 정밀도/재현율/F1을 함께 봐야 함. 데이터 불균형(희귀병 등)일 때는 정확도보다 F1-score가 더 신뢰할 수 있는 지표

## 8. 상관관계 vs 인과관계

| 구분 | 내용 |
|---|---|
| **상관관계** | 두 변수가 같이 움직이는 통계적 연관성(원인-결과 방향 불명확) |
| **인과관계** | 한 변수의 변화가 다른 변수의 변화를 직접 유발(원인-결과 방향 명확) |
| **구분 기준** | 시간적 선행성, 통제실험(A/B테스트), 교란변수 제거 여부 |

**예시 적용**
- 상황: "아이스크림 판매량"과 "익사 사고 건수"는 상관계수 0.8로 강한 양의 상관관계
- 오류: "아이스크림이 익사를 유발한다"는 인과관계로 해석하면 틀림
- 진짜 원인: "여름철 더운 날씨"라는 교란변수(Confounding Variable)가 둘 다에 영향

**결과해석**
> 빅데이터 분석에서 상관관계만 보고 정책/투자 결정을 내리면 잘못된 인과추론으로 이어질 위험 → 인과관계 검증에는 무작위 통제실험(RCT)이나 회귀분석에서 교란변수 통제가 필요

## 9. 귀납적사고와 기계학습

| 구분 | 내용 |
|---|---|
| **개념** | 귀납적사고=개별 사례(데이터)들을 관찰해 일반적인 규칙을 도출하는 추론방식. 기계학습은 이를 알고리즘으로 자동화한 것 (반대: 연역적사고=일반 규칙→개별 결론) |

**예시 적용**
- 귀납적사고: "까마귀1도 검다, 까마귀2도 검다... 까마귀100도 검다" → "모든 까마귀는 검다"는 일반규칙 도출
- 기계학습: 고양이 사진 10,000장을 보여주면("개별사례") → "고양이의 특징 패턴"이라는 일반규칙(모델)을 스스로 학습

**한계**
> 귀납적사고/기계학습 모두 관찰된 데이터에 없는 예외(흰 까마귀, 학습데이터에 없던 새로운 고양이 종)에는 틀릴 수 있음 → 과적합·일반화 오류의 근본 원인

**결과해석**
> 기계학습 모델이 "왜 그렇게 예측했는지" 설명하기 어려운 이유도 귀납적 추론의 본질적 한계 때문 — 최근 설명가능AI(XAI)가 중요해지는 배경

## 📌 키워드 간 연결 요약

```
K-means ←──비교──→ DBSCAN ←──비교──→ SOM
   (모두 비지도학습/군집화, k 사전지정 여부가 핵심 차이)

SVM 마진분류 ──── 의사결정나무(지니/엔트로피)
   (둘 다 지도학습 분류기, 결정경계 vs 분할기준)

의사결정나무 ──→ 앙상블(Bagging=랜덤포레스트, Boosting=XGBoost)
   (트리를 여러 개 모은 확장형)

혼동행렬(정확도/정밀도/재현율/F1)
   (모든 분류모델의 공통 평가지표)

상관관계 vs 인과관계 ──→ 귀납적사고와 기계학습
   (데이터 기반 추론의 "착각 위험"을 다루는 동일 맥락 개념)
```
