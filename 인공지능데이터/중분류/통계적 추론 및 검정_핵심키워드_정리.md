# 통계 핵심 키워드 정리 (정보관리기술사 1교시 대비)

> **공통 답안 전개 구조**: 통계량 정의 → 수식 제시 → 실제 숫자 대입 가설검정(귀무/대립 → 검정통계량 → 임계값 → 판정) → 비즈니스적 해석

---

## 1. 중심극한정리(CLT)

| 구분 | 내용 |
|---|---|
| **정의** | 모집단 분포 모양과 무관하게, 표본크기 n이 충분히 크면(n≥30) 표본평균의 분포는 정규분포에 근사한다 |
| **수식** | X̄ ~ N(μ, σ²/n), 표준화: Z = (X̄-μ)/(σ/√n) |

**숫자 대입 예시**
- 상황: 어느 공장의 부품 무게는 평균 100g, 표준편차 10g이며 분포 모양은 알 수 없음. 36개씩 표본을 뽑아 평균을 구함
- 적용: n=36(≥30)이므로 CLT 적용 가능 → 표본평균의 표준오차 = 10/√36 = **1.67g**
- 판정: n≥30 조건 충족 → 표본평균은 N(100, 1.67²)에 근사한다고 결론

**비즈니스적 해석**
> 원래 데이터 분포를 몰라도, 표본을 충분히 모으면 평균값으로 안정적인 품질관리(허용범위 ±3σ 등)와 의사결정이 가능해진다. 모든 검정·신뢰구간 이론의 출발점.

---

## 2. 점추정 / 구간추정

| 구분 | 내용 |
|---|---|
| **정의** | 점추정=모수를 단일값으로 추정(X̄), 구간추정=신뢰수준 하에서 모수가 포함될 범위를 제시 |
| **수식** | 신뢰구간 = X̄ ± Zα/2 × (σ/√n) |

**숫자 대입 예시**
- 상황: 신규 앱 사용자 100명의 평균 체류시간이 X̄=8분, σ=2분으로 조사됨
- 점추정: 모든 사용자의 평균 체류시간 = **8분**
- 구간추정(95%): 8 ± 1.96×(2/√100) = 8 ± 0.392 → **(7.61분, 8.39분)**
- 판정: "모든 사용자의 평균 체류시간이 7.61~8.39분 사이에 있을 것"이라고 95% 확신

**비즈니스적 해석**
> "평균 8분"이라는 점추정만 보고하면 오차 위험을 숨기게 된다. 구간추정으로 신뢰수준을 명시해야 마케팅/투자 의사결정의 리스크를 정량적으로 전달할 수 있다.

---

## 3. 불편추정량(Unbiased Estimator)

| 구분 | 내용 |
|---|---|
| **정의** | 추정량의 기댓값이 모수와 정확히 일치하는 추정량 — E(θ̂) = θ |
| **수식** | 표본분산 s² = Σ(xi-X̄)²/(**n-1**) ← n이 아닌 n-1로 나눠야 불편추정량이 됨 |

**숫자 대입 예시**
- 표본 5개(2,4,6,8,10), X̄=6
- n으로 나눈 경우: Σ(xi-6)²/5 = 40/5 = 8 (모분산을 과소추정 — 편향 발생)
- n-1로 나눈 경우(불편추정량): 40/4 = **10** (모분산에 더 가까운 정확한 추정)
- 판정: 자유도(df=n-1=4)를 적용한 후자가 편향 없는 추정량

**비즈니스적 해석**
> 표본으로 모집단을 추정할 때 공식을 정확히 따르지 않으면 매번 같은 방향으로 틀린 결론(품질변동을 항상 작게 추정 등)을 내리게 된다. n-1 보정은 양궁에서 평균적으로 정조준되게 만드는 보정장치와 같다.

## 4. t-검정 / z-검정 (＋ANOVA, 모수적검정)

| 구분 | 내용 |
|---|---|
| **정의** | 모분산을 모르고 표본이 작을 때=t검정, 모분산을 알거나 표본이 클 때=z검정. 셋 이상 집단 비교 시=ANOVA(분산분석)로 확장 |
| **수식** | t = (X̄-μ)/(s/√n), 자유도=n-1 / Z = (X̄-μ)/(σ/√n) |

**숫자 대입 예시 (독립표본 t검정)**
- 상황: 새 다이어트약 복용 후 체중감소량 — A그룹(10명) 평균 3kg, 표준편차 1kg
- H0: 약은 효과가 없다(μ=0kg) / H1: 효과가 있다(μ>0kg)
- 검정통계량: t = (3-0)/(1/√10) = **9.49**
- 임계값(유의수준 5%, 자유도9): t0.05,9 = 1.833
- 판정: 9.49 > 1.833 → **H0 기각**

**비즈니스적 해석**
> "약 효과가 있다"는 통계적으로 입증된 결론 → 신약 출시/마케팅 클레임의 근거 자료로 사용 가능. 3개 이상 제품(A/B/C약) 비교 시엔 t검정 여러 번이 아니라 ANOVA 한 번으로 검정한다.

> 💡 **참고**: ANOVA는 등분산성 가정을 전제로 함. 모집단 분포를 가정하면 모수적검정(t/z/ANOVA), 가정하지 않으면 비모수적검정(부호검정, 윌콕슨검정 등) 사용.

## 5. 다중공선성(Multicollinearity) (＋회귀분석)

| 구분 | 내용 |
|---|---|
| **정의** | 다중회귀분석에서 독립변수들 간 상관관계가 너무 높아 회귀계수 추정이 불안정해지는 현상 |
| **수식** | VIF(분산팽창지수) = 1/(1-R²) → **VIF > 10**이면 다중공선성 의심 |

**숫자 대입 예시**
- 상황: 집값 예측모형에 "평수"와 "방 개수"를 독립변수로 모두 투입. 두 변수 간 R²=0.95
- VIF = 1/(1-0.95) = **20** → 임계값 10을 크게 초과
- 판정: 다중공선성 존재 → "방 개수"를 제거하거나 "평수당 방 개수"로 변수 통합

**비즈니스적 해석**
> 다중공선성을 무시하면 "평수가 집값에 미치는 영향"과 "방 개수가 미치는 영향"을 분리해서 말할 수 없게 되어, 가격정책 수립 시 잘못된 변수에 투자 우선순위를 둘 위험이 있다.

> 💡 **회귀분석 유형 구분**: 종속변수가 숫자면 (단순/다중)회귀, 범주(Yes/No)면 로지스틱회귀

---

## 6. 등분산성(Homoscedasticity)

| 구분 | 내용 |
|---|---|
| **정의** | 회귀모형에서 독립변수 값과 관계없이 오차항의 분산이 일정한 성질(ANOVA·t검정의 전제조건) |
| **검정법** | Breusch-Pagan 검정, 잔차 산점도 확인 |

**숫자 대입 예시**
- 상황: 소득(독립변수)으로 소비액(종속변수)을 예측하는 회귀모형의 잔차를 그려봄
- 저소득 구간: 잔차 ±5만원 / 고소득 구간: 잔차 ±50만원 → **깔때기 모양**으로 벌어짐
- 판정: 등분산성 위배(이분산성) → 가중최소제곱법(WLS)으로 재추정 필요

**비즈니스적 해석**
> 등분산성이 깨진 상태로 t검정/ANOVA를 그대로 쓰면 통계적 유의성이 과대/과소평가되어 잘못된 마케팅·정책 결론에 도달할 위험이 있다.

---

## 7. 이항분포 / 포아송분포

| 구분 | 내용 |
|---|---|
| **정의** | 이항분포=정해진 n번 시행 중 성공횟수(성공확률 p 고정) / 포아송분포=단위시간·공간 내 희귀사건 발생횟수(평균발생률 λ) |
| **수식** | 이항 E(X)=np, Var(X)=np(1-p) / 포아송 P(X=k)=λᵏe⁻λ/k!, E(X)=Var(X)=λ |

**숫자 대입 예시 (기출 패턴)**
- 문제: 주사위를 9회 던져 "1 또는 2"가 나오는 횟수 X (p=1/3)
- X ~ B(9, 1/3) → E(X) = 9×1/3 = **3**, Var(X) = 9×1/3×2/3 = **2**
- 상금 X(X-1)원의 기대값: E[X(X-1)] = E(X²)-E(X) = {Var(X)+E(X)²} - E(X) = (2+9)-3 = **8원**

**비즈니스적 해석**
> 이항분포는 "불량품 검사처럼 횟수가 정해진 상황", 포아송분포는 "콜센터 전화처럼 희귀하게 발생하는 상황"의 리스크/수요를 정량화해 인력배치·재고관리 의사결정에 활용된다.

---

## 8. 가설검정 5단계 (＋모수적/비모수적 검정)

| 구분 | 내용 |
|---|---|
| **정의** | 표본 데이터로 모집단에 대한 주장(가설)을 통계적으로 검증하는 5단계 절차 |
| **절차** | ①귀무(H0)/대립(H1) 설정 → ②검정통계량 계산 → ③유의수준(α)별 임계값 산출 → ④채택/기각 판정 → ⑤해석 |

**숫자 대입 예시 (125회 기출 패턴)**
- 상황: 기존 공정 생산시간 평균 30분, 표준편차 5분. 스마트팩토리 적용 후 49개 표본의 평균이 28.5분
- H0: μ=30분(단축효과 없음) / H1: μ<30분(단축효과 있음)
- 검정통계량: Z = (28.5-30)/(5/√49) = **-2.1**
- 임계값(α=5%): Z0.05 = -1.645
- 판정: -2.1 < -1.645 → **H0 기각**

**비즈니스적 해석**
> "스마트팩토리 도입이 통계적으로 유의미하게 생산시간을 줄였다"고 결론 — 투자 타당성 보고서의 핵심 근거 자료가 됨.

> 💡 모집단이 정규분포임을 가정하면 모수적검정, 분포를 모를 경우엔 비모수적검정(부호검정 등) 사용

---

## 9. 자기회귀모형(AR) / 이동평균모형(MA) (＋HMM, 추세외삽법)

| 구분 | 내용 |
|---|---|
| **정의** | AR=과거 자기 자신의 값으로 현재를 예측 / MA=과거 예측오차(백색잡음)의 가중합으로 현재를 예측 |
| **수식** | AR(1): Xt = φ₁Xt-1 + εt / MA(1): Xt = εt + θ₁εt-1 |

**숫자 대입 예시**
- 상황: 전월 전력수요 100만kW, φ₁=0.8로 추정된 AR(1)모형
- 예측: Xt = 0.8×100 + 평균오차(0) = **80만kW 수준으로 회귀 예상** (평균회귀 경향)
- 판정: φ₁이 1에 가까우면 추세가 오래 유지(비정상), 0에 가까우면 평균으로 빨리 복귀

**비즈니스적 해석**
> VPP(가상발전소) 전력수요 예측처럼, AR/MA(결합 시 ARMA, 비정상엔 차분 추가해 ARIMA)는 다음달 수요·매출을 예측해 발주량/인력 배치를 결정하는 데 사용된다.

> 💡 **확장 비교**: 더 단순한 방법은 추세외삽법(과거 추세선을 단순 연장), 관측되지 않는 잠재상태가 있을 땐 HMM(Hidden Markov Model) 사용

## 10. 베이즈정리(Bayes' Theorem) (＋전확률의 정리)

| 구분 | 내용 |
|---|---|
| **정의** | 사전확률(Prior)에 새로운 증거(Likelihood)를 반영해 사후확률(Posterior)을 갱신하는 정리 |
| **수식** | P(A\|B) = P(B\|A)×P(A) / P(B), 분모 P(B)는 전확률의 정리로 계산: P(B)=ΣP(B\|Ai)P(Ai) |

**숫자 대입 예시**
- 상황: 어느 질병의 사전 발병률(Prior) P(병)=1%. 검사 양성일 때 실제 병일 확률(민감도) P(양성|병)=90%, 건강한데 양성 나올 확률(오탐) P(양성|건강)=5%
- 전확률: P(양성) = 0.9×0.01 + 0.05×0.99 = 0.009+0.0495 = **0.0585**
- 베이즈정리 적용: P(병|양성) = (0.9×0.01)/0.0585 = **0.154 (15.4%)**
- 판정: 검사가 양성이어도 실제 병에 걸렸을 확률은 **15.4%에 불과**(과신 금물)

**비즈니스적 해석**
> 처음 믿음(사전확률 1%)이 검사결과(증거)를 반영해도 직관과 달리 크게 높지 않을 수 있음을 보여준다. 의료진단, 스팸필터(나이브베이즈), 신용평가 모델에서 "증거가 있어도 과신하지 말고 정량적으로 갱신"하는 의사결정에 핵심적으로 활용된다.

## 📌 키워드 간 연결 요약

```
중심극한정리 ──→ 점추정/구간추정 ──→ t/z-검정 ──→ ANOVA
                                  │
불편추정량 ──────────────────────┘ (표준오차/자유도 보정)

다중공선성 ←── 회귀분석(단순/다중/로지스틱) ←── 등분산성(전제조건)

이항분포 ←──→ 포아송분포 (n大·p小일 때 근사)

가설검정 5단계 ── 모수적검정(t/z/ANOVA) vs 비모수적검정

AR/MA ──→ ARMA/ARIMA ──→ (비교: 추세외삽법, HMM, 동적회귀모델)

베이즈정리 ←── 전확률의 정리 + 조건부확률
```
