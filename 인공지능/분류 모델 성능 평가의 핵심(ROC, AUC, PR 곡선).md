#### **분류 모델 성능 평가의 핵심: ROC, AUC, PR 곡선**

***

#### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (왜 정확도 하나만으로는 모델을 평가 못 하는가)
Ⅱ. ROC·AUC 핵심 원리
Ⅲ. PR 곡선 핵심 원리 및 ROC와의 선택 기준
Ⅳ. 결론
```

포인트: 개요에서 \*\*"앞서 다룬 다중 클래스 분류 평가(혼동행렬·Macro/Micro F1)가 '클래스별 성능을 종합'한다면, ROC(Receiver Operating Characteristic)·AUC(Area Under Curve)·PR(Precision-Recall) 곡선은 '분류 임계값(Threshold)을 바꿔가며 모델의 판별력 전체를 시각화·정량화하는 평가 기법'이다 — 단일 임계값(보통 0.5)의 정확도는 임계값 선택에 따라 크게 흔들리지만, ROC·PR 곡선은 '모든 가능한 임계값에서의 성능'을 보여줘 앞서 다룬 알고리즘 공정성 지표(TPR·FPR 기반 Equalized Odds)의 측정 기반이자, 앞서 다룬 AI 레드티밍·MIA 평가에서 공격 성공률을 정량화하는 AUC-ROC의 이론적 근거"\*\*라는 한 줄로 시작하면 전체 맥락이 드러납니다.

***

#### Ⅱ. ROC·AUC 핵심 원리

**가. ROC 곡선 구성 요소**

```
[ROC 곡선 좌표축]

Y축: TPR (True Positive Rate·재현율·민감도)
     = TP / (TP + FN)
     "실제 양성 중 맞게 예측한 비율"

X축: FPR (False Positive Rate)
     = FP / (FP + TN)
     "실제 음성 중 잘못 양성으로 예측한 비율"

[임계값 변화에 따른 곡선 생성]

임계값 낮춤 (관대한 기준):
  더 많이 양성 예측 → TPR↑·FPR↑ (우상향 이동)

임계값 높임 (엄격한 기준):
  더 적게 양성 예측 → TPR↓·FPR↓ (좌하향 이동)

→ 모든 임계값(0~1)에서의 (FPR, TPR) 점을 연결 = ROC 곡선
```

***

**나. AUC(Area Under Curve) 해석**

```
[AUC 값별 모델 판별력]

AUC = 1.0    완벽한 분류기 (이론적)
AUC = 0.9~1.0 매우 우수
AUC = 0.8~0.9 우수
AUC = 0.7~0.8 양호
AUC = 0.5~0.7 미흡
AUC = 0.5    랜덤 분류기 (대각선)
AUC < 0.5    랜덤보다 나쁨 (예측 반전 필요)

[ROC 곡선 시각화]

TPR
1.0│         ┌──────● 완벽(AUC=1.0)
   │       ╱
   │     ╱  ● 좋은 모델(AUC=0.85)
   │   ╱
   │ ╱     ● 랜덤(AUC=0.5, 대각선)
   │╱
0.0└─────────────────→ FPR
   0.0            1.0

AUC = 곡선 아래 면적
    = 무작위로 뽑은 양성 샘플이
      음성 샘플보다 높은 점수를 받을 확률
```

***

#### Ⅲ. PR 곡선 핵심 원리 및 ROC와의 선택 기준

**가. PR 곡선 구성 요소**

```
[PR 곡선 좌표축]

Y축: Precision (정밀도)
     = TP / (TP + FP)
     "양성으로 예측한 것 중 실제 양성 비율"

X축: Recall (재현율) = TPR과 동일
     = TP / (TP + FN)

[PR-AUC 해석]
  AP(Average Precision) = PR 곡선 아래 면적
  불균형 데이터에서 ROC-AUC보다 민감한 지표
```

***

**나. ROC/AUC vs PR 곡선 핵심 체계**

| **핵심 척도**      | **📊 ROC·AUC 특성 🚨**                                                         | **🔑 PR 곡선 특성 🚨**                                   | **🏁 선택 기준·불균형 데이터 💯**                                                       |
| :------------- | :--------------------------------------------------------------------------- | :--------------------------------------------------- | :---------------------------------------------------------------------------- |
| **핵심 정의**      | TPR vs FPR / 양성·음성 모두 고려 / 클래스 비율 변화에 **둔감**                                 | Precision vs Recall / **음성(TN) 미반영** / 양성 클래스 성능에 집중 | 데이터 불균형 심할수록 PR 곡선이 실질적 성능 차이를 더 잘 드러냄                                        |
| **불균형 데이터 영향** | 음성 압도적 다수(TN↑↑) → FPR 분모(FP+TN) 커짐 → **FPR 왜곡되게 낮아 보임** / ROC-AUC 과대평가 위험 🚨 | TN 관여 없음 → 불균형 영향 적음 / 소수 클래스(양성) 탐지력을 정직하게 반영 ✅     | 사기 탐지·희귀질병 진단(양성 1% 미만) → **PR 곡선 권장**                                        |
| **도메인 적합성**    | 균형 데이터·양성/음성 둘 다 중요 / 일반 분류 문제 벤치마크                                          | **불균형 데이터**·양성 클래스 자체가 중요 / 정보 검색·이상 탐지              | 앞서 다룬 **알고리즘 공정성**: Equalized Odds = ROC 기반(TPR·FPR) / 이상 탐지·MIA: PR 곡선이 더 정직 |
| **베이스라인**      | 랜덤 분류기 = 대각선(AUC=0.5) 고정                                                     | 랜덤 분류기 = **양성 비율**(불균형 시 매우 낮음) / 데이터셋마다 베이스라인 다름    | PR 곡선 해석 시 항상 양성 비율(베이스라인) 함께 명시 필요                                           |

***

**다. 실무 선택 가이드**

| 상황                  | 권장 지표           | 이유                            |
| :------------------ | :-------------- | :---------------------------- |
| **일반 이진 분류 (균형)**   | ROC-AUC         | 표준적·해석 직관적                    |
| **사기 탐지 (양성 0.1%)** | **PR-AUC**      | ROC-AUC 과대평가 방지               |
| **희귀질병 진단**         | **PR-AUC**      | 소수 클래스 탐지력 정직 반영              |
| **앞서 다룬 MIA 평가**    | ROC-AUC         | 멤버/비멤버 대체로 균형                 |
| **정보 검색·추천**        | PR-AUC (mAP)    | Precision 중심 평가               |
| **앞서 다룬 공정성 지표**    | ROC 기반(TPR·FPR) | Equalized Odds 정의 자체가 TPR·FPR |

**라. 앞서 다룬 개념과의 연결**

| 연계 개념                | 연결 내용                                         |
| :------------------- | :-------------------------------------------- |
| **다중 클래스 분류 평가**     | ROC/PR = 이진 분류 확장 / 다중클래스는 One-vs-Rest로 각각 계산 |
| **알고리즘 공정성 지표**      | Equalized Odds = 집단별 TPR·FPR 동등 = ROC 좌표축 자체  |
| **멤버십 추론 공격**        | MIA 방어력 평가 = AUC-ROC (공격자 판별력 측정)             |
| **AI 레드티밍**          | ASR(공격 성공률) 측정에 ROC 개념 응용                     |
| **AI 레드티밍·차분 프라이버시** | DP 노이즈 강도 조절 시 AUC 변화로 프라이버시-성능 트레이드오프 측정     |

***

**(제언)** "ROC·AUC·PR 곡선은 '단일 임계값의 함정을 벗어나 모델의 전체 판별력을 정직하게 드러내는 평가 도구'입니다. **일반적 균형 데이터에는 ROC-AUC가 표준이지만, 앞서 다룬 사기 탐지·이상 탐지처럼 양성 클래스가 극히 희소한 불균형 환경에서는 ROC-AUC가 실제보다 낙관적으로 나타나는 함정이 있으므로 PR-AUC를 함께 반드시 확인해야 하며, 앞서 다룬 알고리즘 공정성 지표의 Equalized Odds가 ROC 좌표축(TPR·FPR)을 집단별로 비교하는 것이라는 점에서 두 개념이 수학적으로 연결되고, MLOps 파이프라인에서 두 지표를 모두 모니터링해 데이터 드리프트로 인한 성능 저하를 조기 탐지하는 것이 실무의 핵심 전략입니다.**"
