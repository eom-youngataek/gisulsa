포인트: 개요에서 \*\*"앞서 다룬 ML 알고리즘·딥러닝이 '데이터의 패턴과 상관관계를 학습하는 예측 모델'이라면, 인과 추론(Causal Inference)은 '처치(Treatment)가 결과(Outcome)에 실제로 영향을 미치는가'라는 인과적 질문에 답하는 통계적 분석 방법론이다 — 아이스크림 판매량과 익사 사고가 상관관계를 보이지만 진짜 원인은 더위(교란변수)이듯, 관찰 데이터에서 교란변수를 통제하지 않으면 인과관계를 오인하며, 성향점수 매칭(PSM)은 RCT(무작위 대조 실험)가 불가능한 현실에서 처치군·대조군의 사전 특성을 균형 맞춰 교란변수를 통계적으로 제거하는 핵심 기법으로 앞서 다룬 AI 서비스 효과 측정·공공정책 평가·임상 연구의 핵심 분석 도구"\*\*라는 한 줄로 시작하면 전체 맥락이 드러납니다.

#### Ⅱ. 인과 추론 핵심 원리

**가. 인과 추론 핵심 개념**

```
[인과 추론의 근본 문제: 반사실적 추론]

처치 효과(Treatment Effect):
  τᵢ = Yᵢ(1) - Yᵢ(0)

  Yᵢ(1): 처치 받았을 때 결과
  Yᵢ(0): 처치 받지 않았을 때 결과
  → 동일 개인에게 두 상태 동시 관찰 불가 🚨
    (인과 추론의 근본 문제)

평균 처치 효과(ATE):
  ATE = E[Y(1) - Y(0)]
  = E[Y(1)] - E[Y(0)]

관찰 데이터의 문제:
  선택 편향(Selection Bias)
  → 처치군·대조군이 처음부터 다름
  → 단순 비교 = 인과 ≠ 상관 🚨
```

***

**나. 교란변수와 인과 다이어그램**

```
[DAG (Directed Acyclic Graph) 표현]

교란변수(Confounder) X
    ↙        ↘
처치 T  →  결과 Y

예시: 신약 효과 측정
  X(건강 상태): 건강한 사람이 신약 선택↑
  T(신약 복용): 처치
  Y(회복율): 결과

→ X를 통제 안 하면 신약 효과 과대 추정 🚨
→ PSM으로 X 균형 맞추면 T→Y 인과 효과 분리 ✅
```

#### Ⅲ. 성향점수 매칭(PSM) 핵심 원리

**가. PSM 핵심 체계**

| **핵심 척도** | **📊 성향점수 추정 🚨**                                                                                                  | **🔑 매칭·균형 검증 🚨**                                                                                                | **🏁 처치 효과 추정 💯**                                                                                                  |
| :-------- | :----------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| **핵심 개념** | **성향점수(Propensity Score)**: e(X) = P(T=1\|X) / 공변량 X가 주어졌을 때 처치 받을 확률 / 로지스틱 회귀·GBM·신경망으로 추정 / 고차원 공변량을 1차원 점수로 압축 | **매칭 방법**: 최근접 이웃(NN) / 캘리퍼(Caliper·±0.1σ 범위) / 커널 매칭 / 층화(Stratification) / **균형 검증**: SMD(표준화 평균 차이)<0.1이면 균형 ✅ | **ATT(처치군 평균 처치 효과)**: E[Y(1)-Y(0)|T=1] / 매칭 후 처치군·대조군 결과 차이 / **ATE**: 전체 집단 평균 효과 / 앞서 다룬 **A/B 테스트** 불가 시 PSM 대안 |
| **수식**    | **로지스틱 회귀**: e(X) = 1/(1+exp(-Xβ)) / X: 나이·성별·소득·건강 등 공변량 / β: 추정 계수 / 0\~1 확률값 출력                                 | **SMD 공식**: (μ₁-μ₀)/√((σ₁²+σ₀²)/2) / 매칭 전: SMD>0.1 편향 존재 🚨 / 매칭 후: SMD<0.1 균형 달성 ✅ / Love Plot으로 시각화             | **ATT 추정**: (1/n₁)Σ\[Yᵢ(T=1) - Ŷᵢ(T=0)] / 처치군 실제 결과 - 매칭된 대조군 결과 / 표준 오차: 부트스트래핑                                    |
| **핵심 가정** | **무시 가능성(Ignorability)**: T ⊥ Y(0),Y(1) | X / X가 주어지면 T는 무작위와 동일 / **관측된 공변량만** 통제 / 미관측 교란변수 있으면 편향 잔존 🚨         | **공통 지지(Common Support)**: 처치·대조군 성향점수 분포 겹침 / 겹치지 않는 영역 제외 / 앞서 다룬 **OOD 탐지**와 유사 개념                             | **민감도 분석(Rosenbaum Bounds)**: 미관측 교란변수가 있어도 결론 유지되는지 검증 / Γ값: 1에 가까울수록 민감 🚨                                        |

***

**나. PSM 수행 절차 도식화**

```
[PSM 5단계 수행 절차]

①공변량 선택
  처치·결과 모두 영향 주는 변수 선택
  나이·성별·소득·이전 건강 상태 등
  (결과에만 영향→포함 / 처치에만→제외)
       ↓
②성향점수 추정
  로지스틱 회귀: P(T=1|X)
  → 각 개인의 처치 받을 확률 계산
       ↓
③매칭 수행
  처치군 각 개인에 대해
  유사한 성향점수의 대조군 매칭
  캘리퍼 0.1σ 이내 최근접 이웃 선택
       ↓
④균형 검증
  매칭 전·후 SMD 비교
  SMD < 0.1 달성 확인
  Love Plot·QQ Plot 시각화
       ↓
⑤처치 효과 추정
  매칭된 처치군·대조군 결과 비교
  ATT = 처치군 평균 - 대조군 평균
  부트스트래핑으로 신뢰구간 계산

[Love Plot: 매칭 전·후 SMD 비교]
변수      매칭전 SMD    매칭후 SMD
나이       0.45  ─────   0.03 ✅
성별       0.32  ─────   0.07 ✅
소득       0.28  ─────   0.05 ✅
→ 매칭 후 모든 변수 SMD < 0.1 달성
```

**다. 인과 추론 방법론 비교**

| 방법              | 원리          | 강점        | 한계           |
| :-------------- | :---------- | :-------- | :----------- |
| **RCT**         | 무작위 배정      | 황금 표준 ✅   | 비용·윤리 제약 🚨  |
| **PSM**         | 성향점수 매칭     | 관찰 데이터 활용 | 미관측 교란 취약    |
| **IV (도구변수)**   | 외생적 변동 활용   | 미관측 교란 통제 | 강한 도구 찾기 어려움 |
| **DID (이중차분)**  | 처치 전후 차이 비교 | 패널 데이터 활용 | 평행 추세 가정 필요  |
| **RDD (회귀불연속)** | 임계값 전후 비교   | 국소 무작위화   | 임계값 근방만 적용   |

**(제언)** "인과 추론과 PSM은 '데이터가 말해주는 상관관계와 우리가 알고 싶은 인과관계 사이의 간극을 통계적으로 메우는 도구'입니다. **앞서 다룬 AI 서비스 효과 측정에서 A/B 테스트(RCT)가 불가능할 때 PSM으로 인과 효과를 추정하고, 앞서 다룬 공공 SaaS 도입 효과·AI 서비스 대가산정의 성과 기반 계약 검증에 PSM을 적용하며, 앞서 다룬 AI 윤리기준의 알고리즘 영향평가(AIA)에서 특정 집단에 대한 처치 효과 차이를 PSM으로 분석해 공정성을 검증하는 것이 데이터 기반 의사결정의 인과 추론 핵심 실천 전략입니다.**"**.**"
