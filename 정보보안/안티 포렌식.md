### **디지털 포렌식 대응 기술: 안티 포렌식 3대 유형 & 안티-안티 포렌식**

***

#### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (왜 포렌식 수사관이 안티 포렌식을 알아야 하는가)

Ⅲ. 안티-안티 포렌식 대응 기법

```

포인트: 개요에서 \*\*"앞서 다룬 디지털 포렌식 5대 원칙(정당성·무결성·연계보관성·재현성·신속성)이 '증거를 수집·보존·분석하는 수사관 관점'이라면, 안티 포렌식(Anti-Forensics)은 '공격자가 자신의 흔적을 지우거나 분석을 방해하는 기술'이고, 안티-안티 포렌식은 '그 방해 기법을 다시 탐지·극복하는 수사 대응 기술'이다 — 앞서 다룬 파일리스 악성코드·LotL이 탐지 회피 수단이라면, 안티 포렌식은 수사 단계에서의 증거 인멸 수단으로, 기술사 답안에서는 공격자 관점의 기술 이해를 통해 방어·수사 역량을 높이는 관점으로 접근"\*\*이라는 한 줄로 시작하면 전체 맥락이 드러납니다.

***

#### Ⅱ. 안티 포렌식 3대 유형

**가. 3대 유형 핵심 체계**

| **핵심 척도**  | **📊 데이터 은닉 (Hiding) 🚨**                                                                                                                                                      | **🔑 데이터 파괴 (Destruction) 🚨**                                                                                                                                                                | **🏁 데이터 변조 (Falsification) 💯**                                                                                                                            |
| :--------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **정의**     | 데이터를 삭제하지 않고 **찾기 어렵게 숨기는** 기법 / 정상적 파일·저장소에 데이터를 위장·은닉                                                                                                                        | 증거 데이터를 **복구 불가능하게 영구 삭제**하는 기법 / 파일 시스템·디스크·로그 완전 제거                                                                                                                                         | 타임스탬프·로그·메타데이터를 **의도적으로 위·변조**해 수사 혼란 유발                                                                                                                    |
| **대표 기법**  | **스테가노그래피(Steganography)**: 이미지·음성·문서에 데이터 은닉 / **슬랙 공간 활용**: 파일 슬랙·볼륨 슬랙·MFT 미사용 공간 / **암호화 볼륨**: VeraCrypt 숨겨진 볼륨(Hidden Volume) / **대안 데이터 스트림(ADS)**: NTFS ADS로 파일 내 파일 숨김 | **안전 삭제(Secure Delete)**: DoD 7회 덮어쓰기·Gutmann 35회 / **디가우징(Degaussing)**: 강력 자기장으로 HDD 데이터 파괴 / **로그 삭제**: Windows 이벤트 로그 지우기·리눅스 /var/log 삭제 / **메모리 초기화**: 앞서 다룬 **DRAM 전원 차단** 후 잔류 데이터 제거 | **타임스탬프 조작(Timestomping)**: MACE(수정·접근·생성·항목수정) 시간 위조 / Metasploit timestomp 명령 / **로그 변조**: Syslog·EVTX 이벤트 레코드 삭제·수정 / **메타데이터 삭제**: EXIF 정보 제거·GPS 좌표 삭제 |
| **포렌식 영향** | 단순 키워드 검색으로 발견 어려움 🚨 / 용량·위치 이상 없어 보임 / 표준 포렌식 도구 탐지 회피                                                                                                                       | 물리적 복구 불가능 수준 달성 / 법정 증거 확보 불가 🚨 / 사건 타임라인 공백                                                                                                                                                | 범행 시간·행위자 오인 유발 🚨 / 수사 방향 오도 / 알리바이 조작 가능                                                                                                                  |

#### Ⅲ. 안티-안티 포렌식 대응 기법

**가. 유형별 탐지·대응 체계**

```
[안티 포렌식 유형별 대응 매핑]

①데이터 은닉 → 탐지 기법
  스테가노그래피 탐지:
    StegDetect·Stegexpose로 통계적 이상 탐지
    픽셀 LSB(최하위 비트) 분포 분석
    파일 크기 vs 실제 이미지 해상도 불일치

  ADS 탐지:
    dir /r (Windows)·Streams 도구
    정상 파일과 다른 스트림 크기 확인

  암호화 볼륨:
    엔트로피 분석: 암호화 영역은 높은 엔트로피
    VeraCrypt 볼륨 시그니처 탐지

②데이터 파괴 → 복구 기법
  파일 복구:
    Autopsy·FTK로 MFT 손상 엔트리 복구
    파일 카빙: 헤더·푸터 시그니처로 복원
    저널(Journal) 분석: $LogFile·$UsnJrnl

  로그 복구:
    Windows EVTX: 손상 레코드 부분 복구
    데이터베이스 WAL·트랜잭션 로그 분석
    클라우드·SIEM 중앙 로그 대조

③데이터 변조 → 검증 기법
  타임스탬프 검증:
    $MFT vs $LogFile vs $UsnJrnl 3중 비교
    윈도우 프리패치(Prefetch) 타임스탬프
    섀도우 복사본(VSS) 원본 타임스탬프 대조

  로그 무결성:
    해시 기반 로그 체인 검증
    앞서 다룬 SIEM 중앙 수집 로그와 비교
    NTP 서버 기록으로 시간 교차 검증
```

**나. 도식화**

```
[안티 포렌식 vs 안티-안티 포렌식 대응 구조]

공격자                     수사관(포렌식)
──────────────────────────────────────────
스테가노그래피 은닉    ↔  엔트로피·통계 분석
ADS 파일 숨김         ↔  dir /r·Streams 탐지
암호화 볼륨           ↔  엔트로피 분석·볼륨 식별
                         (복호화 키 별도 확보 필요)

안전 삭제·덮어쓰기    ↔  파일 카빙·저널 분석
로그 삭제             ↔  SIEM 중앙 로그·클라우드 대조
메모리 초기화         ↔  신속성 원칙: 전원 차단 전 덤프

타임스탬프 조작       ↔  MFT·LogFile·USN 3중 교차 검증
EXIF 삭제             ↔  네트워크 전송 메타데이터 분석
로그 변조             ↔  해시 체인·NTP 교차 검증

[포렌식 준비 태세 (Forensic Readiness)]
  선제적 대응:
  ①중앙 SIEM 로그 수집 (삭제 불가)
  ②앞서 다룬 WORM 스토리지로 로그 보관
  ③접속기록 실시간 해시 체인 생성
  ④앞서 다룬 디지털 포렌식 5대 원칙 사전 구축
  → 안티 포렌식 효과 사전 무력화 ✅
```

**다. 앞서 다룬 개념과의 연결**

| 연계 개념              | 연결 내용                                   |
| :----------------- | :-------------------------------------- |
| **디지털 포렌식 5대 원칙**  | 무결성(해시 검증)·신속성(메모리 우선) 원칙이 안티-안티 포렌식 핵심 |
| **파일리스 악성코드·LotL** | 실행 흔적 최소화 = 안티 포렌식의 사전 단계               |
| **AI-SOC·SIEM**    | 중앙 로그 수집이 로그 삭제·변조 안티 포렌식 무력화           |
| **ARIES WAL·LSN**  | 데이터베이스 로그 체인 = 변조 탐지 기반                 |
| **개인정보 안전조치**      | 접속기록 WORM 보관 의무 = 로그 삭제 안티 포렌식 방어       |

***

*  **(제언)** "안티 포렌식 기법의 이해는 포렌식 수사관이 증거 공백과 수사 방해를 사전에 예측하고 대응하기 위한 필수 역량입니다. **앞서 다룬 AI-SOC의 SIEM 중앙 로그 수집·WORM 스토리지 보관이 로그 삭제·변조 안티 포렌식을 무력화하고, 파일 카빙·저널 분석·3중 타임스탬프 교차 검증이 데이터 파괴·변조에 대응하며, 조직의 포렌식 준비 태세(Forensic Readiness)를 사전에 구축해 안티 포렌식 효과 자체를 선제적으로 차단하는 것이 디지털 증거 보전의 핵심 전략입니다.**"
