포인트: 개요에서 **"앞서 다룬 AI 학습데이터 품질관리·데이터 계약이 '실무 관점의 데이터 품질 기준'이라면, ISO/IEC 25012는 'SQuaRE(Software product Quality Requirements and Evaluation) 시리즈의 일부로 데이터 품질을 고유 특성(Inherent)과 시스템 의존 특성(System-Dependent) 2대 관점·15개 특성으로 체계화한 국제 표준'이다 — 앞서 다룬 데이터 드리프트·데이터 계약·MLOps 품질 게이트가 무엇을 측정해야 하는지 방향을 제시하는 메타 기준이며, 공공 데이터 품질 인증·AI 학습 데이터 품질 평가의 법적·제도적 기반으로 국내 행안부 데이터 품질 관리 지침과 직접 연계"**라는 한 줄로 시작하면 전체 맥락이 드러납니다.

---

#### Ⅱ. ISO/IEC 25012 핵심 구조 및 15대 품질 특성

**가. 2대 관점 구분**

|관점|정의|핵심 의미|
|---|---|---|
|**고유 특성 (Inherent)**|데이터 자체가 본질적으로 가져야 할 품질 / 시스템과 무관|데이터 그 자체의 내재적 정확성·완전성·일관성|
|**시스템 의존 특성 (System-Dependent)**|특정 시스템·환경에서 데이터가 보이는 품질|접근성·보안성 등 시스템 맥락에서 결정되는 품질|
|**양쪽 해당**|고유+시스템 의존 양쪽 모두에 속하는 특성|일관성·이해가능성·정밀성|

---

**나. 15대 품질 특성 체계**

|**핵심 척도**|**📊 고유 특성 (Inherent) 🚨**|**🔑 시스템 의존 특성 🚨**|**🏁 양쪽 해당 특성 💯**|
|---|---|---|---|
|**특성 목록**|**정확성(Accuracy)**: 실제 값과의 일치도 / **완전성(Completeness)**: 필수 값 누락 없음 / **일관성(Consistency)**: 모순 없는 데이터 / **신뢰성(Credibility)**: 출처 신뢰 가능 / **최신성(Currentness)**: 현실 반영 최신 상태|**접근성(Accessibility)**: 권한 있는 사용자 접근 가능 / **컴플라이언스(Compliance)**: 법령·표준 준수 / **기밀성(Confidentiality)**: 비인가 접근 차단 / **효율성(Efficiency)**: 자원 대비 접근 성능 / **정밀성(Precision)**: 세부 수준 충분성 / **추적가능성(Traceability)**: 이력 추적 가능 / **가용성(Availability)**: 필요 시 접근 가능|**이해가능성(Understandability)**: 의미 명확 / **이식성(Portability)**: 다른 환경 전환 가능 / **복원성(Recoverability)**: 오류 후 복구 가능|
|**AI 연계**|**정확성**: 앞서 다룬 **IAA·코헨의 카파** / 레이블 정확도 / **완전성**: 결측값 비율·필수 피처 누락 / **최신성**: 앞서 다룬 **데이터 드리프트** 적시성 탐지|**접근성**: 앞서 다룬 **RBAC·개인정보 안전조치** / **기밀성**: PII 마스킹·앞서 다룬 **LINDDUN Disclosure** / **컴플라이언스**: 앞서 다룬 **개인정보보호법·GDPR** 준수|**이해가능성**: 데이터 사전·메타데이터 / **추적가능성**: 앞서 다룬 **데이터 계보(Lineage)**|
|**측정 방법**|정확성: 레퍼런스 데이터 비교·오류율 / 완전성: NULL 비율·필수 컬럼 충족률 / 일관성: 참조 무결성·중복 검사|접근성: 접근 성공률·응답시간 / 컴플라이언스: 법령 항목 체크리스트 달성률 / 추적가능성: 로그 완전성|이해가능성: 메타데이터 완성도 / 이식성: 포맷 표준 준수율|
