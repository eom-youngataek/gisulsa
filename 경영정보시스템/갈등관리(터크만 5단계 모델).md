터크만 모델은 원래 "팀 발전단계" 이론인데, 기술사 시험에서는 **"갈등관리"** 관점으로 변형해서 자주 냅니다. 함정은 5단계를 그냥 나열만 하면 절반 답안이 되고, **각 단계별로 어떤 갈등이 왜 생기고 PM/리더가 뭘 해야 하는지**를 짝지어야 완성됩니다.

### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (터크만 모델 정의, 팀 발전과 갈등의 관계) — 3~4줄
Ⅱ. 터크만 5단계와 단계별 갈등양상/리더십 (본론, 도식 1개 필수)
Ⅲ. 갈등해결기법 (5대 기법, 단계와 연계)
Ⅳ. 결론
```

포인트: "팀은 원래 갈등을 거쳐야 성과가 나온다"는 게 터크만 모델의 핵심 통찰입니다. 갈등을 없애는 게 목표가 아니라 **단계에 맞게 관리해서 통과시키는 것**이 목표라는 논리를 개요에서 잡아야 합니다.

### Ⅱ. 터크만 5단계 — "형·격·규·성·해" (형성-격동-규범-성취-해체)

| 단계    | 원어         | 특징                 | 갈등양상                   | 리더십 스타일                           |
| :---- | :--------- | :----------------- | :--------------------- | :-------------------------------- |
| ① 형성기 | Forming    | 팀원 간 서로 탐색, 역할 불명확 | 갈등 **표면화 안됨** (예의차림)   | **지시형** (Directing) — 목표·역할 명확화   |
| ② 격동기 | Storming   | 역할·주도권 다툼, 의견충돌    | 갈등이 **최고조** — 이 단계가 핵심 | **코칭형** (Coaching) — 경청, 중재, 규칙합의 |
| ③ 규범기 | Norming    | 역할 정리, 협업규칙 정착     | 갈등 **감소**, 신뢰 형성       | **지원형** (Supporting) — 자율성 부여     |
| ④ 성취기 | Performing | 팀 시너지 발현, 자율적 성과창출 | 갈등 **건설적**(성과지향적 논쟁)   | **위임형** (Delegating) — 권한위임       |
| ⑤ 해체기 | Adjourning | 프로젝트 종료, 팀 해산      | 상실감/이별 갈등              | **인정형** (Recognizing) — 성과인정, 마무리 |

→ 암기: **"형격규성해"** 5글자 + 각 단계 리더십은 상황대응리더십(허쉬-블랜차드)의 \*\*"지시-코칭-지원-위임"\*\*과 거의 동일 구조입니다. 이미 아는 리더십이론에 얹으면 새로 외울 게 줄어듭니다.

### 도식화 제안 (갈등수준 그래프 — 배점 핵심)

시간축(x) - 갈등수준(y) 그래프로 그리세요. 이게 터크만 모델의 시각적 핵심입니다.

```
갈등
수준
 │           ▲(격동기,최고조)
 │          ╱ ╲
 │         ╱   ╲___
 │        ╱        ╲___________
 │_______╱                      ╲___
 │(형성기)  (규범기)   (성취기)    (해체기)
 └──────────────────────────────→ 시간
```

→ "갈등은 초반에 낮고 격동기에 급상승했다가, 규범기부터 하락해서 성취기에 낮은 수준(건설적 갈등)으로 안정된다"는 곡선 하나가 본론의 시각적 핵심입니다.

### Ⅲ. 갈등해결기법 — 토마스-킬만 모델과 연계 (심화 배점)

격동기(Storming) 갈등을 실제로 어떻게 푸는지 물으면, 토마스-킬만의 5가지 갈등관리 유형과 연결하면 훨씬 풍부해집니다.

| 기법                          | 자기주장 | 협력성 | 적용상황                           |
| :-------------------------- | :--- | :-- | :----------------------------- |
| **협력** (Collaborate)        | 높음   | 높음  | Win-Win 필요, 시간 충분 (**가장 이상적**) |
| **타협** (Compromise)         | 중간   | 중간  | 양측 일부 양보, 시간 제약                |
| **강요** (Force/Compete)      | 높음   | 낮음  | 긴급상황, 규정준수 필요                  |
| **회피** (Avoid)              | 낮음   | 낮음  | 사소한 이슈, 감정격화 시 일시적             |
| **수용** (Accommodate/Smooth) | 낮음   | 높음  | 관계유지 우선, 상대가 더 옳을 때            |

→ 앞서 다룬 "리스크 대응전략(회피/전가/완화/수용)"과 이름이 비슷해서 헷갈릴 수 있는데, **갈등관리는 "자기주장 vs 협력성" 2축**이라는 점이 다릅니다. 이 차이를 한 줄 언급하면 변별력이 생깁니다.

### Ⅳ. 결론 포인트 (차별화 한 줄)

터크만 모델의 실무적 시사점은, **격동기(Storming)를 건너뛰려 하지 말고 오히려 짧고 건설적으로 지나가도록 관리**해야 한다는 점입니다 — 갈등을 억지로 누르면 규범기로 못 넘어가고 팀이 형성기에 머물게 됩니다(터크만이 말하는 "정지된 팀"). 이 한 줄로 마무리하면 이론을 실무적으로 이해했다는 인상을 줍니다.

#### **I. \[도입] 고성과 팀 빌딩의 이정표, 터크만(Tuckman) 5단계 모델 개요**

* **정의:** 프로젝트 팀이 처음 결성되어 해산하기까지 겪게 되는 그룹 발달 과정을 5단계로 체계화한 팀 빌딩(Team Building) 모델.
* **핵심 목적:** PM이 현재 팀의 발달 단계를 정확히 진단하고, 그에 맞는 적절한 리더십과 갈등 관리 전략을 구사하여 신속히 '수행기(Performing)'로 진입시키기 위함.

#### **II. \[본론 1] 터크만의 5단계 모델 및 단계별 특징 (필수 암기)**

단계별 영문 앞 글자를 따서 **\[F - S - N - P - A]** 로 암기하시면 절대 잊지 않습니다. 각 단계별로 PM이 취해야 할 \*\*'리더십 스타일'\*\*을 함께 적어주면 고득점 포인트가 됩니다.

| **발달 단계**                   | **단계별 팀의 상태 및 특징**                                        | **PM의 요구 리더십 (대응 전략)**                                         |
| :-------------------------- | :-------------------------------------------------------- | :------------------------------------------------------------- |
| **1. 형성기** (**F**orming)    | - 팀원들이 처음 모여 서로 눈치를 보고 탐색하는 시기 - 각자의 역할과 책임이 모호함          | 📢 **지시적 리더십 (Directing)** - 프로젝트 목표와 방향성을 명확히 지시하고 규칙을 제시     |
| **2. 격동기** (**S**torming)   | - 💥 **갈등 최고조 단계** - 업무 방식, 주도권, 성격 차이로 인한 충돌 및 저항 발생     | 🤝 **코칭 리더십 (Coaching)** - 갈등 관리가 핵심! 의견을 경청하되 올바른 방향으로 코칭     |
| **3. 규범기** (**N**orming)    | - 갈등이 해소되고 팀원 간의 신뢰와 \*\*그라운드 룰(Ground Rule)\*\*이 확립되는 시기 | 👥 **참여적 리더십 (Participating)** - 팀원들의 참여를 유도하고 의사결정 권한을 서서히 공유 |
| **4. 수행기** (**P**erforming) | - 🚀 **팀워크와 시너지가 폭발**하는 단계 - 독립적이고 자율적으로 문제를 해결하며 성과를 창출  | 👑 **위임적 리더십 (Delegating)** - 간섭을 최소화하고 권한을 전적으로 위임하여 자율성 보장   |
| **5. 해산기** (**A**djourning) | - 프로젝트 목표를 달성하고 팀이 해산하는 마무리 시기                            | 🏆 **축하 및 성과 보상** - 노고 치하, 교훈(Lessons Learned) 도출 및 지식 자산화     |

#### **III. \[본론 2] 갈등 관리의 핵심 '격동기(Storming)' 극복 전략**

터크만 모델에서 가장 시험에 쓰기 좋은 부분은 갈등이 폭발하는 **'격동기(Storming)'를 어떻게 넘길 것인가**입니다.

1. **그라운드 룰(Ground Rule)의 확립:** 갈등을 사전에 예방하고 중재할 수 있는 명확한 팀 행동 규범 제정.
2. **PM의 5대 갈등 해결 기법의 적절한 구사:**
   * **문제 해결/협력 (Collaborate/Problem Solve):** 양측이 모두 만족하는 최상의 결과를 도출하는 근본적 해결책 (가장 권장됨).
   * **타협 (Compromise):** 양보를 통해 부분적인 만족을 얻는 방법 (시간이 촉박할 때).
   * **원만/수용 (Smooth/Accommodate):** 관계 유지를 위해 상대방의 의견에 따르는 방법.
   * **강제/지시 (Force/Direct):** PM의 권한을 이용해 한쪽 의견을 강행 (긴급한 위기 상황 시).
   * **회피/철회 (Withdraw/Avoid):** 갈등 이슈에서 물러나거나 연기하는 방법.

#### **IV. \[결론/제언] 상황 대응 리더십(Situational Leadership)의 중요성**

* **(키워드 위주 2줄 마무리)** "훌륭한 PM은 '하나의 정답인 리더십'을 고집하지 않습니다. 팀이 형성기인지 수행기인지 파악하여 상황에 맞게 리더십 스타일을 바꾸는 \*\*'상황 대응 리더십'\*\*과, 타인의 감정을 이해하고 조율하는 \*\*'감성 지능(EQ)'\*\*을 발휘할 때 비로소 최고의 프로젝트 성과를 달성할 수 있습니다."
