### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (BSC 정의, 전략맵의 필요성) — 3~4줄
Ⅱ. BSC 4대 관점과 전략맵 인과관계 (본론, 도식 1개 필수)
Ⅲ. 전략맵 작성절차
Ⅳ. 기대효과/결론
```

포인트: 전략맵은 \*\*"아래에서 위로 쌓이는 원인-결과 사슬"\*\*입니다. 사람(역량) 있어야 → 프로세스가 좋아지고 → 고객이 만족하고 → 재무성과가 난다는 하나의 논리흐름이 답안의 뼈대입니다.

### 핵심 키워드 (암기용 최소 세트)

**4대 관점 — "학·내·고·재" (아래→위로 쌓기)**

| 순서     | 관점                             | 핵심질문                 | 대표지표              |
| :----- | :----------------------------- | :------------------- | :---------------- |
| ① (기반) | **학습과 성장** (Learning & Growth) | "우리는 변화·개선 역량이 있는가?" | 직원역량, IT역량, 조직문화  |
| ②      | **내부프로세스** (Internal Process)  | "무엇을 잘해야 하는가?"       | 프로세스 혁신, 품질, 리드타임 |
| ③      | **고객** (Customer)              | "고객에게 어떻게 보여야 하는가?"  | 고객만족도, 시장점유율      |
| ④ (정점) | **재무** (Financial)             | "주주에게 어떻게 보여야 하는가?"  | 매출, ROI, 원가절감     |

→ 암기: **"학습이 있어야 내부가 돌고, 내부가 좋아야 고객이 만족하고, 고객이 만족해야 재무성과가 난다"** — 이 한 문장이 전략맵 전체입니다. 4개를 따로 외우지 말고 이 인과문장 하나만 기억하면 자동 복원됩니다.

### 도식화 제안 (전략맵 = 이 답안의 핵심 배점 포인트)

화살표로 상향 인과관계를 그리세요:

```
[재무]        매출증대 ↑ / 원가절감 ↓
   ↑ (결과)
[고객]        고객만족 ↑ / 신규고객확보 ↑
   ↑ (결과)
[내부프로세스]  프로세스혁신 / 품질개선
   ↑ (원인=기반)
[학습과성장]   직원역량강화 / IT인프라 / 조직문화
```

→ 이 그림 하나가 "BSC를 안다"를 증명하는 핵심입니다. 화살표 방향(아래→위, 원인→결과)을 반드시 표시하세요.

### Ⅲ. 전략맵 작성절차 — "비·관·지·측·연"

| 단계                     | 내용                                   |
| :--------------------- | :----------------------------------- |
| ① 비전/전략 확인             | 조직의 비전·전략목표 명확화                      |
| ② 관점별 전략목표 도출          | 4관점별로 목표 설정                          |
| ③ 지표(KPI) 및 목표치 설정     | 관점별 핵심성과지표 도출                        |
| ④ 인과관계(연결선) 도출         | 관점 간 원인-결과 화살표 연결 → **이게 "전략맵"의 본질** |
| ⑤ 실행과제(Action Plan) 연계 | 지표 달성을 위한 실행과제 매핑                    |

→ "비관지측연" 5글자로 압축하면 절차가 자동 복원됩니다.

### Ⅳ. 결론 포인트 (차별화 한 줄)

BSC의 진짜 가치는 재무지표라는 \*\*후행지표(lagging indicator)\*\*를, 학습·성장이라는 \*\*선행지표(leading indicator)\*\*로 사전관리 가능하게 만든다는 점입니다. 이 한 줄을 결론에 넣으면 "암기가 아니라 이해했다"는 인상을 줍니다.
