### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (AX 정의·필요성) — 3~4줄
Ⅱ. AX 추진절차와 단계별 장애요인 (본론, 도식 1개 필수)
Ⅲ. 장애요인 극복방안 (시사점)
Ⅳ. 결론 (기대효과·향후과제)
```

포인트: Ⅱ번에서 절차 5단계 옆에 각 단계의 장애요인을 바로 붙여 쓰면, 채점자 입장에서도 "절차를 이해하고 있구나"가 보이고, 수험자 입장에서도 "절차 5개 + 장애요인 5개"가 아니라 "짝지어진 5세트"만 외우면 됩니다.

### 핵심 키워드 (암기용 최소 세트)

**추진절차 5단계 — "진·전·파·확·내"**

| 단계         | 핵심활동                  | 붙는 장애요인                    |
| :--------- | :-------------------- | :------------------------- |
| ① 진단/공감대   | 현황분석, 경영진 인식          | 리더십 의지 부족, 변화저항(문화)        |
| ② 전략/로드맵   | AX 비전, 과제 발굴(BPR/ISP) | 전략 모호, 예산·거버넌스 미비          |
| ③ 파일럿(PoC) | 시범적용, 효과검증            | 데이터 품질/부재, 기술역량 부족         |
| ④ 확산/전개    | 전사 확대                 | 부서 이기주의(사일로), 조직 저항        |
| ⑤ 내재화      | 표준화·고도화               | 인력유지 어려움, 지속투자 단절, 성과측정 곤란 |

→ 외울 땐 **"진전파확내"** 다섯 글자만 기억하면, 각 글자에서 절차와 장애요인이 자동으로 딸려 나오게 연습하시면 됩니다.

### 도식화 제안 (2페이지 답안 배점에 유리)

화살표 흐름도 하나만 그리세요:

```
[진단]→[전략]→[파일럿]→[확산]→[내재화]
  ↓        ↓        ↓        ↓        ↓
리더십   예산/     데이터/   사일로   지속투자
저항     거버넌스  기술부족  저항     성과측정
```

이 그림 하나가 본론의 70%를 대신합니다. 텍스트로 다 풀어쓰지 말고 그림 밑에 1\~2줄씩만 설명 붙이면 시간도 절약됩니다.

### 극복방안(Ⅲ)은 장애요인을 그대로 뒤집기

* 리더십 저항 → **탑다운 스폰서십 + Quick-win 성과 공유**
* 데이터 부족 → **데이터 표준화·품질관리 선행**
* 사일로 → **애자일/전담조직(CoE) 운영**
* 성과측정 곤란 → **KPI·ROI 프레임 사전설계**

→ 즉, 장애요인 4개 외우면 극복방안도 자동으로 대응되니 따로 외울 게 없습니다.
