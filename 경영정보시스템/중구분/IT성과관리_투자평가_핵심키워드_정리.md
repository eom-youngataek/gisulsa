# IT 성과관리 프레임워크 핵심 키워드 정리 (정보관리기술사 대비)

> **공통 답안 전개 구조**: 정의 → 구성요소 → 실제 전략맵/지표 작성

---

## 1. BSC (Balanced Score Card, 균형성과기록표)

**정의**
> Kaplan&Norton이 제시한 성과관리 프레임워크 — 재무성과 같은 단일지표에 치우치지않고, **4가지 관점을 균형있게** 측정해 전략을 실행으로 연결

**구성요소(4대 관점 및 인과관계)**
```
[재무관점(Financial)] 최상위목표 — 매출증대, 수익성개선
        ↑ (지원)
[고객관점(Customer)] 고객만족도, 시장점유율 향상
        ↑ (지원)
[내부프로세스관점(Internal Process)] 업무효율화, 품질개선, 배송시간단축
        ↑ (지원)
[학습과성장관점(Learning&Growth)] 직원역량, IT인프라, 조직문화(가장 하위기반)
```
> 4관점은 **인과관계 사슬**로 연결 — 하위관점(학습성장)의 개선이 상위관점(재무)의 목표달성으로 이어지는 구조

**실제 전략맵 작성 (125회 기출패턴 — "매출증대 목표 달성을 위한 배송시간절감+만족도증가" 전략맵)**

```
[재무관점]        매출증대
                     ↑
[고객관점]    고객만족도 향상 ←──┐
                     ↑          │
[내부프로세스관점]  배송시간 단축 ─┘
                     ↑
[학습과성장관점]   물류시스템 IT역량강화, 배송인력 교육
```

**전략맵 인과관계 서술**: "물류시스템 IT역량을 강화하면(학습성장) → 배송프로세스가 자동화되어 배송시간이 단축되고(내부프로세스) → 고객은 빠른배송에 만족하게 되며(고객) → 결과적으로 재구매율 상승으로 매출이 증대된다(재무)"

**지표설계(관점별 KPI 예시)**

| 관점 | 전략목표 | KPI(핵심성과지표) |
|---|---|---|
| 재무 | 매출증대 | 전년대비 매출성장률(%) |
| 고객 | 만족도향상 | 고객만족도조사 점수, NPS |
| 내부프로세스 | 배송시간단축 | 평균배송리드타임(시간) |
| 학습성장 | IT역량강화 | 물류시스템 도입율, 직원교육이수율 |

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| KPI/KGI | BSC 각 관점의 목표(KGI)와 측정지표(KPI)의 구체적 표현방식 |
| AHP | BSC의 여러 전략목표 간 우선순위를 정량적으로 결정할 때 결합활용(이전파일과 연결) |
| IT거버넌스 | BSC를 IT조직에 특화시킨 "IT BSC"가 IT거버넌스 효과측정 방법론으로 활용(이전파일과 연결) |

## 2. IT-ROI (IT Return on Investment)

**정의**
> IT투자(시스템구축·인프라투자 등)로 인해 발생한 **수익(또는 비용절감)을 투자비용으로 나눈** 투자효율성 지표

**구성요소(계산구조)**
```
ROI(%) = (IT투자로 인한 순이익 / IT투자비용) × 100
        = {(투자후 효익 - 투자비용) / 투자비용} × 100

[효익(Benefit) 구성요소]
- 직접효익: 비용절감(인건비감소,오류감소), 매출증대(신규채널,고객확대)
- 간접효익: 의사결정속도향상, 브랜드이미지개선(정량화 어려움 — 정성평가 병행필요)

[비용(Cost) 구성요소]
- 초기투자비(하드웨어,소프트웨어,개발비) + 운영유지비(TCO관점 — 인건비,유지보수비)
```

**실제 지표 작성(예시계산)**
```
A시스템 도입: 초기투자 5억원, 연간운영비 1억원(3년누적 8억원)
효과: 연간 인건비절감 2억원 + 매출증대효과 1.5억원 = 연간3.5억원(3년 10.5억원)

3년 ROI = {(10.5억-8억)/8억}×100 = 31.25%
```

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| TCO(Total Cost of Ownership) | ROI계산의 분모(비용)를 정확히 산정하기 위한 전체수명주기비용 개념 |
| CBAM | ROI계산을 아키텍처 의사결정에 특화시킨 정량적 비교기법(SW아키텍처 도메인과 연결) |
| NPV/IRR | ROI와 함께 사용되는 재무적 투자타당성 평가지표(시간가치를 반영한 보완지표) |

## 3. IT투자평가 (정량적/정성적 평가항목)

**정의**
> IT투자의 타당성을 **수치로 측정가능한 정량적측면**과 **수치화하기 어려운 가치를 판단하는 정성적측면**을 종합해 평가하는 체계

**구성요소(평가항목 분류)**

| 구분 | 평가항목 |
|---|---|
| **정량적평가** | ROI, NPV(순현재가치), IRR(내부수익률), Payback Period(투자회수기간), TCO |
| **정성적평가** | 전략적합치도(경영전략과의 정합성), 리스크수준, 고객만족도 기여, 조직역량강화효과, 경쟁우위확보 가능성 |

**실제 평가표 작성(예시 — IT프로젝트 타당성 평가 매트릭스)**

| 평가축 | 평가항목 | A안(ERP고도화) | B안(신규채널구축) |
|---|---|---|---|
| 정량 | 3년ROI | 25% | 40% |
| 정량 | 투자회수기간 | 2.5년 | 1.8년 |
| 정성 | 전략적합치도 | 중(기존업무효율화) | 상(신사업방향과 일치) |
| 정성 | 리스크수준 | 낮음(검증된기술) | 높음(신규시장불확실성) |
| 종합판단 | - | 안정적이나 성장성낮음 | 고위험고수익, 전략우선순위 高 |

**평가절차**: 정량지표만으로 의사결정시 "단기수익률은 높으나 전략방향과 안맞는" 투자를 선택할 위험 → 정량+정성을 **가중치 결합**(AHP 등 활용)해 종합점수산출 후 우선순위 결정

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| AHP | 정량·정성 평가항목 간 가중치를 체계적으로 산정하는 도구(이전파일과 연결) |
| CBAM | "비용-효익"의 경제적 가치를 시나리오기반으로 정량화하는 유사기법(SW아키텍처 도메인과 연결) |
| EVM(획득가치관리) | 투자평가가 사전(투자결정시점)인 반면, EVM은 사후(진행중 프로젝트)의 정량평가체계로 비교 |

## 4. IT투자분석 프로세스/프레임워크/방법론 (125회 기출패턴)

**정의**
> IT투자의사결정을 체계적으로 지원하기 위한 전체적 접근체계 — **프로세스(절차)**, **프레임워크(분석틀)**, **방법론(구체기법)** 3가지 차원으로 구성

**구성요소**

**①프로세스(절차)**
```
①투자기회 식별 → ②투자대안 분석(정량+정성) → ③투자의사결정(우선순위화)
   → ④투자집행(프로젝트수행) → ⑤사후평가(투자효과 실측, PIR-Post Implementation Review)
```

**②프레임워크(분석틀)**
| 프레임워크 | 특징 |
|---|---|
| Val IT(ISACA) | IT가치창출을 거버넌스(IT투자관리체계) 관점에서 체계화 |
| 정보화투자관리체계(국내공공) | 사전협의·심의→집행→성과평가의 공공IT투자 표준절차 |

**③방법론(구체기법)**
- 재무적방법론: ROI, NPV, IRR, Payback Period
- 비재무적방법론: BSC, 정보경제학(IE, Information Economics — 가중점수법으로 정성요소 정량화)
- 옵션이론: 실물옵션(Real Option) — 불확실성이 큰 IT투자를 "선택권"으로 보고 단계적 투자결정의 유연성을 가치화

**실제 적용 예시(전체 통합)**: AI도입투자 시 — (프로세스)PoC로 기회식별→ROI·리스크 분석→경영진 의사결결 / (프레임워크)Val IT 기반 거버넌스체계로 투자관리 / (방법론)초기엔 NPV로 정량평가하되, 불확실성이 크므로 실물옵션으로 "단계적 확장권리"의 가치를 추가평가

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 정보경제학(IE) | 정성적가치를 가중점수로 정량화하는 IT투자평가의 보완방법론 |
| 실물옵션(Real Option) | 불확실성이 큰 신기술(AI 등) 투자의 단계적 의사결정을 가치화하는 고급기법 |
| PIR(사후평가) | 투자분석 프로세스의 마지막단계, 차기 투자의사결정의 학습데이터로 환류 |
| AX(AI Transformation) | 최신 IT투자분석의 핵심 적용대상(IT전략기획 이전파일과 연결) |

## 종합 흐름도

```
[성과관리 프레임워크] BSC(4관점 전략맵) — 재무관점이 최상위, 나머지 3관점이 인과적으로 지원
        │
[투자효율성 측정] IT-ROI(투자대비 효익 정량화)
        │
[투자의사결정 평가] IT투자평가(정량+정성 종합판단)
        │
[투자관리 전체체계] IT투자분석(프로세스+프레임워크+방법론) — 위 모든 요소를 통합 관리하는 상위체계
```

| IT투자분석 | "절차(프로세스)+분석틀(프레임워크)+기법(방법론)의 3중구조" |
