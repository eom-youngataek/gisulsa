### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (전자정부 발전지수 정의·목적) — 3~4줄
Ⅱ. 평가체계 구성 (EGDI 3대 지수 + EPI) — 본론, 도식 1개
Ⅲ. 한국의 시사점/향후과제
Ⅳ. 결론
```

포인트: EGDI는 **"서비스(온라인) + 인프라(통신) + 사람(인적자본)"** 3개 축의 합성지수라는 것 하나만 확실히 잡으면, 세부 지표는 저절로 따라옵니다. 시험에서 이 구조를 모르고 세부지표만 나열하면 감점됩니다.

### 핵심 키워드 (암기용 최소 세트)

**① EGDI = 3대 지수의 가중평균 — "서·통·인"**

| 지수               | 원어                                     | 측정내용                     |
| :--------------- | :------------------------------------- | :----------------------- |
| **OSI** (온라인서비스) | Online Service Index                   | 정부 웹사이트·포털의 서비스 제공 범위·품질 |
| **TII** (통신인프라)  | Telecommunication Infrastructure Index | 인터넷·이동통신·유선 가입자 비율 등     |
| **HCI** (인적자본)   | Human Capital Index                    | 문해율, 교육등록률(초중고+대학)       |

→ 암기: **"서비스 잘 만들어도(OSI), 인프라 없으면(TII) 못쓰고, 쓸 사람(HCI)이 없으면 무의미하다"** 한 문장으로 3지수의 존재이유를 함께 외우면 잊지 않습니다.

**② EPI — EGDI와 짝을 이루는 보조지수**

| 구분               | 핵심                                                  |
| :--------------- | :-------------------------------------------------- |
| **EPI** (전자참여지수) | E-Participation Index — 정보제공, 협의, 의사결정참여(3단계) 수준 측정 |

→ EGDI는 "정부가 얼마나 잘 서비스하는가", EPI는 "국민이 얼마나 참여할 수 있는가"로 대비해서 외우면 헷갈리지 않습니다.

### 도식화 제안

```
        [전자정부 발전지수 EGDI]
     ┌────────┼────────┐
   [OSI]     [TII]     [HCI]
   서비스     인프라     인적자본
   
        (보조) [EPI 전자참여지수]
   정보제공 → 협의 → 의사결정참여
```

이 그림 하나로 "3+1 구조"가 한눈에 보여집니다.

### Ⅲ. 시사점(한국 특화 — 채점자에게 어필 포인트)

한국은 **OSI(서비스)에서는 최상위권이지만, TII·HCI는 상대적으로 여유가 있는 구조**라는 게 반복적으로 지적되는 포인트입니다. 이걸 뒤집어서 향후과제로 쓰면:

* 서비스 고도화 → **AI 기반 선제적(proactive) 행정서비스**로 진화
* 인프라 초격차 유지 → 5G/6G, 클라우드 전환
* 인적자본 격차 해소 → **디지털 취약계층 포용(디지털 역량교육)**

→ 3지수 프레임 그대로 향후과제에 매핑하면 별도로 외울 게 없습니다.
