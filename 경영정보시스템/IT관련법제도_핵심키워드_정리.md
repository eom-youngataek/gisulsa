## 1. 개인정보보호법

**조항(핵심 조문)**
| 조항 | 내용 |
|---|---|
| 제3조 | 개인정보 보호원칙(최소수집, 목적명확화, 안전관리, 투명성, 정보주체권리보장 등) |
| 제15조 | 개인정보의 수집·이용 (동의 등 법적근거) |
| 제28조의2 | **가명정보의 처리**(통계작성·연구·공익기록보존 목적시 동의없이 처리가능, 데이터3법 개정사항) |
| 제28조의5 | 가명정보 처리시 금지의무(재식별시도 금지) |
| 제29조 | 안전조치의무(기술적·관리적·물리적 보호조치) |
| 제35조~39조 | 정보주체의 권리(열람,정정,삭제,처리정지 요구권) |

**포함내용**: 개인정보 처리의 전생애주기(수집→이용→제공→파기)에 걸친 의무사항, 개인정보보호위원회의 감독권한, 위반시 과징금·형사처벌 규정

**기대효과**: 정보주체의 자기정보결정권 보장, 데이터활용과 프라이버시보호의 균형(가명정보제도로 산업적활용 촉진), 글로벌 개인정보보호 수준(GDPR 등)과의 정합성 확보

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 개인정보 안전성확보조치 기준 | 제29조의 구체적 시행기준을 담은 하위고시(보안 도메인과 연결) |
| PbD(Privacy by Design) | 제3조의 보호원칙을 시스템설계 단계에 구현하는 실무방법론(보안 도메인과 연결) |
| 데이터3법 | 개인정보보호법 개정이 포함된 패키지법안(아래에서 종합정리) |

## 2. 소프트웨어진흥법 (조항별)

**조항(핵심 조문 — 132회 기출패턴)**

| 조항 | 내용 |
|---|---|
| 제5조(기본계획의 수립 등) 제2항 | 소프트웨어진흥 기본계획에 포함되어야할 사항(산업육성방향, 인력양성, 기술개발지원 등) 명시 |
| 제30조(소프트웨어안전 확보) 제2항 | 소프트웨어안전 확보를 위한 지침에 포함되어야할 사항(안전성기준, 진단방법 등) 명시 |
| (관련) 상용소프트웨어 직접구매 관련조항 | 국가기관 등의 상용SW 직접구매시 품질성능평가시험 의무 규정 |
| (관련) 소프트웨어사업 영향평가 근거조항 | 공공SW사업 발주전 민간시장 영향평가 의무화 |

**포함내용**: SW산업육성 기본계획, SW안전관리(안전성진단·인증), SW사업대가기준 근거, SW기술자 경력관리체계, 영향평가·과업변경심의 등 공공SW사업 전반의 법적기반

**기대효과**: SW산업 경쟁력강화, 공공SW사업의 품질·안전성 제고, 민간시장 침해방지를 통한 SW생태계 상생

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 소프트웨어사업 영향평가 | 진흥법에 근거한 핵심 제도(SW비용산정 도메인과 연결) |
| SW안전진단 가이드 / FTA·FMEA | 제30조의 안전성확보 지침을 구현하는 구체적 기법(SW품질 도메인과 연결) |
| SW기술자 등급제 / IT직무제 | 진흥법체계 내 인력관리제도(132회 기출과 연결) |

## 3. 데이터산업법 (데이터산업진흥 및 이용촉진에 관한 기본법)

**조항(핵심 조문 — 127회 기출패턴)**

| 조항 | 내용 |
|---|---|
| 목적조항 | 데이터의 생산·거래·활용 촉진을 통한 데이터산업 발전과 국민생활향상 도모 |
| 데이터자산 보호조항 | 데이터의 부정취득·사용행위 금지(데이터자산을 법적보호대상으로 명시) |
| 데이터거래사업자 등록조항 | 데이터거래소·중개플랫폼의 등록·관리기준 |
| 데이터안심구역 지정근거조항 | 안전한 데이터활용환경 구축을 위한 법적근거 |

**포함내용**: 데이터의 자산적 가치인정, 데이터거래 활성화를 위한 인프라(데이터거래소,안심구역) 법제화, 데이터분쟁조정위원회 운영근거

**기대효과**: 데이터를 둘러싼 법적불확실성 해소로 데이터경제 활성화, 데이터거래시장의 신뢰성·투명성 제고, 중소기업·스타트업의 데이터접근성 향상

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 데이터안심구역 / 데이터가치평가 / 데이터커머스 | 데이터산업법이 제도적기반을 제공하는 핵심 데이터경제 인프라(DB도메인과 연결) |
| 데이터3법 | 데이터산업법은 "활용촉진"에 초점, 데이터3법은 "개인정보의 안전한 활용"에 초점(상호보완) |

## 4. 데이터3법 (개인정보보호법·정보통신망법·신용정보법 통합개정)

**조항(3개법 개정 핵심포인트 — 130회 기출패턴)**

| 법률 | 핵심개정조항 |
|---|---|
| 개인정보보호법 | 가명정보 처리근거 신설(제28조의2), 개인정보보호위원회의 중앙행정기관 격상 |
| 정보통신망법 | 온라인 개인정보보호 관련규정을 개인정보보호법으로 이관(중복규제 통합) |
| 신용정보법 | 가명·익명처리 신용정보의 빅데이터분석 허용, **마이데이터(본인신용정보관리업)** 라이선스 신설 |

**포함내용(개인정보 전송요구권 — 130회 기출 핵심)**: 개인정보보호법 개정에 따른 정보주체의 **개인정보 전송요구권**(본인정보를 본인이 지정한 제3자에게 전송요구가능) 및 AI를 활용한 자동화된 의사결정에 대한 **설명요구·거부권** 신설

**기대효과**: 데이터 활용경제로의 전환 가속화, 마이데이터 등 신산업 법적기반 마련, 감독기구 일원화로 규제 명확성·집행력 강화

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 마이데이터 사업 | 데이터3법(신용정보법)의 직접적 산물(DB도메인과 연결) |
| 가명·익명처리 / PET | 데이터3법이 허용한 가명정보 활용을 기술적으로 구현하는 수단(보안 도메인과 연결) |
| AI 자동화 의사결정 대응권 | 130회 기출의 핵심 신설권리(AI거버넌스 도메인과 연결) |

## 5. 전자정부법 (공공SLA 관련 — 139회 기출 최신 정책)

**조항(핵심 조문)**
| 조항 | 내용 |
|---|---|
| 제57조 | 정보시스템 감리 의무화 근거 |
| (개정조항, 139회 기출) | 행정·공공기관 **정보시스템 등급제** 도입 및 **공공SLA(서비스수준협약) 표준** 적용 근거 — 2027년부터 의무화 추진 |

**포함내용**: 정보시스템을 중요도·영향범위에 따라 등급분류(예: 1~3등급), 등급별로 차등화된 SLA기준(가용률,장애조치시간,위약금체계) 적용, 반복되는 공공전산망 장애사고에 대한 제도적 대응

**기대효과**: 공공정보시스템의 안정성·신뢰성 제고, 장애발생시 책임소재 명확화, 시스템 중요도에 비례한 효율적 투자·관리자원 배분

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| 클라우드SLA / TIA-942 | 공공SLA가 참조하는 민간 클라우드SLA체계 및 데이터센터등급기준(경영정보시스템/컴퓨터구조 도메인과 연결) |
| 차세대시스템 오픈장애 재발방지대책 | 공공SLA 의무화의 직접적 정책배경(이전파일과 연결) |
| 정보시스템감리 | 동일법(전자정부법) 내에서 SLA규정과 함께 시스템품질을 관리하는 인접조항 |

## 6. 디지털서비스 전문계약제도

**조항(법적근거)**: 「소프트웨어진흥법」 및 「국가를 당사자로 하는 계약에 관한 법률」 특례 — 클라우드 등 디지털서비스를 신속하게 조달할 수 있도록 마련된 전문계약 절차(별도 수의계약 형태 허용)

**포함내용(주요 특징 및 디지털서비스 종류)**
```
[기존조달 한계] 일반 공공조달은 입찰절차가 복잡·장기간 소요되어 클라우드 등 신속도입이 필요한 
              디지털서비스에 부적합

[디지털서비스 전문계약제도] 
①디지털서비스몰(카탈로그)에 사전등록된 서비스 중에서 ②수요기관이 직접 선택해 
③비교적 신속한 절차로 계약체결(일반조달보다 간소화)

[대상 디지털서비스 종류] 클라우드(IaaS/PaaS/SaaS), 정보보호서비스, AI서비스 등
```

**기대효과**: 공공기관의 클라우드·AI서비스 도입속도 향상(디지털전환 가속화), 우수 디지털서비스기업의 공공시장 진입장벽 완화, 신기술기반 서비스의 신속한 검증·확산

**📌 연관 키워드**
| 키워드 | 연결 포인트 |
|---|---|
| CSAP | 디지털서비스몰 등록을 위한 전제조건(보안인증 필요)(이전파일과 연결) |
| 공공SaaS이용가이드라인 | 전문계약으로 도입한 SaaS의 운영단계 보안관리 가이드(이전파일과 연결) |
| 소프트웨어사업 영향평가 | 전문계약 대상사업도 일정규모 이상이면 영향평가 대상 검토 필요(SW비용산정 도메인과 연결) |

## 종합 흐름도

```
[데이터/개인정보 법제축]
개인정보보호법 ──┬── 데이터3법(3법통합개정) ──→ 마이데이터/가명정보 활용
                 └── 데이터산업법(데이터자산화·거래촉진)

[SW산업/공공조달 법제축]
소프트웨어진흥법(산업육성+안전+대가기준) ──→ 디지털서비스 전문계약제도(신속조달)

[공공시스템 운영 법제축]
전자정부법(감리의무 + 등급제/공공SLA, 최신 2027년 의무화)
```

### 한 줄 비교 암기
| 법률 | 핵심 한 줄 |
|---|---|
| 개인정보보호법 | "수집부터 파기까지 전생애주기 보호 + 가명정보 활용근거" |
| 소프트웨어진흥법 | "SW산업육성 기본계획 + SW안전확보 지침의 법적토대" |
| 데이터산업법 | "데이터를 자산으로 인정, 거래·활용 촉진" |
| 데이터3법 | "3개법 통합개정으로 데이터경제 전환 가속(마이데이터 탄생)" |
| 전자정부법 | "감리의무화(기존) + 등급제·공공SLA(최신, 2027년)" |
| 디지털서비스 전문계약제도 | "디지털서비스몰에서 신속하게 클라우드/AI서비스 조달" |
