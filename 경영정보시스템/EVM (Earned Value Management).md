포인트: 개요에서 **"앞서 다룬 ES(Earned Schedule)가 'EVM의 일정 지표가 프로젝트 후반부에 왜곡되는 문제'를 보완하는 후속 개념이었다면, EVM(Earned Value Management)은 그 자체로 '비용과 일정이라는 서로 다른 두 축을 하나의 통합된 화폐 단위로 환산해 동시에 측정하는' 프로젝트 성과 관리의 원조 방법론이다 — 전통적인 프로젝트 관리가 '계획된 예산 대비 실제 지출액'만 비교하면, 프로젝트가 예산을 그대로 쓰고 있어도 실제로는 계획된 작업량의 절반밖에 못 끝냈을 수 있다는 치명적 함정(지출은 정상인데 진도는 지연)을 놓치는데, 1960년대 미 국방부가 개발한 EVM은 여기에 '실제로 완료한 작업의 계획 가치(EV)'라는 제3의 축을 추가함으로써 원가 초과와 일정 지연을 각각 독립적으로, 그러나 동시에 정량화하는 프로젝트 관리의 사실상 국제 표준"**이라는 한 줄로 시작하면 전체 맥락이 드러납니다.

#### Ⅱ. EVM 핵심 구성요소 및 지표

**가. EVM 3대 기본 데이터**

```
[EVM 3대 기준값: PV, EV, AC]

PV(Planned Value, 계획가치)
  = 특정 시점까지 "계획대로라면" 완료했어야 할 작업의 예산 가치
  = BCWS(Budgeted Cost of Work Scheduled)의 후속 용어

EV(Earned Value, 획득가치)
  = 특정 시점까지 "실제로" 완료한 작업의 계획상 예산 가치
  = BCWP(Budgeted Cost of Work Performed)의 후속 용어
  ★ EVM의 핵심 혁신: "얼마를 썼는가"가 아니라
    "계획된 화폐가치로 환산했을 때 얼마만큼의 작업을 끝냈는가"를 측정

AC(Actual Cost, 실제원가)
  = 특정 시점까지 실제로 지출한 비용
  = ACWP(Actual Cost of Work Performed)의 후속 용어

예시: 전체 예산 1,000만원짜리 작업을
      계획상 이번 달까지 500만원어치(PV=500) 끝냈어야 하는데
      실제로는 400만원어치 작업만 끝냈고(EV=400)
      그 작업에 실제로는 450만원을 지출(AC=450)
```

**나. EVM 핵심 파생 지표**

|지표|산출식|의미|
|---|---|---|
|**CV(Cost Variance, 원가차이)**|**CV = EV - AC**|양수(+)면 예산 절감, 음수(-)면 예산 초과|
|**SV(Schedule Variance, 일정차이)**|**SV = EV - PV**|양수(+)면 일정 앞섬, 음수(-)면 일정 지연(앞서 다룬 종료시점 왜곡 문제 존재)|
|**CPI(Cost Performance Index, 원가성과지수)**|**CPI = EV / AC**|1보다 크면 효율적(투입 대비 산출 우수), 작으면 비효율|
|**SPI(Schedule Performance Index, 일정성과지수)**|**SPI = EV / PV**|1보다 크면 일정 앞섬, 작으면 지연|

**다. 완료 시점 예측 지표**

| 지표                                      | 산출식                          | 의미                            |
| --------------------------------------- | ---------------------------- | ----------------------------- |
| **BAC(Budget At Completion)**           | 프로젝트 전체 계획 예산(고정값)           | 애초에 세운 총예산                    |
| **EAC(Estimate At Completion)**         | **EAC = BAC / CPI**(전형적 산출법) | 현재 추세가 계속될 때 예상되는 최종 총비용      |
| **ETC(Estimate To Complete)**           | **ETC = EAC - AC**           | 완료까지 앞으로 추가로 필요한 비용           |
| **VAC(Variance At Completion)**         | **VAC = BAC - EAC**          | 최종적으로 예산을 초과할지 절감할지의 예측치      |
| **TCPI(To-Complete Performance Index)** | **TCPI = (BAC-EV)/(BAC-AC)** | 남은 예산 내에서 완료하려면 앞으로 필요한 효율 수준 |

#### Ⅲ. 지표 해석 및 적용 체계

**가. CPI·SPI 조합에 따른 4분면 프로젝트 상태 진단**

|CPI/SPI 조합|원가 상태|일정 상태|진단|
|---|---|---|---|
|**CPI>1, SPI>1**|예산 절감|일정 앞섬|**이상적 상태**(우수)|
|**CPI<1, SPI>1**|예산 초과|일정 앞섬|속도를 위해 초과 지출 중(재검토 필요)|
|**CPI>1, SPI<1**|예산 절감|일정 지연|자원 부족 등으로 진도가 느림|
|**CPI<1, SPI<1**|예산 초과|일정 지연|**최악의 상태**(원가·일정 동시 악화, 즉각 조치 필요)|

**나. EVM vs 전통적 원가관리(단순 예산 대비 지출) 비교**

|비교 항목|전통적 원가관리|EVM|
|---|---|---|
|**비교 대상**|계획예산(PV) vs 실제지출(AC)만|**PV·EV·AC 3자 통합 비교** ✅|
|**진도 반영 여부**|진도(작업 완료율) 미반영 🚨|**EV로 실제 완료 작업량을 화폐가치로 반영** ✅|
|**함정**|"예산대로 쓰고 있다"≠"제대로 진행 중" 오판 위험|원가·일정을 독립적으로 동시 진단|
|**미래 예측력**|제한적|**EAC·VAC로 최종 결과 조기 예측** ✅|

**다. EVM vs ES(Earned Schedule) 관계**

|비교 항목|EVM 기본 지표(SV·SPI)|ES 보완 지표(SV(t)·SPI(t))|
|---|---|---|
|**측정 단위**|금액(원·달러)|**시간(월·주·일)**|
|**종료 시점 신뢰도**|강제로 0·1에 수렴, 왜곡 🚨|**끝까지 신뢰도 유지** ✅|
|**관계**|EVM의 기본 데이터(PV·EV)를 그대로 재활용해 ES가 시간 축으로 재해석||

**라. 실무 적용 시 고려사항**

|고려사항|내용|
|---|---|
|**작업분류체계(WBS) 정밀도**|EV 산정의 정확도는 결국 WBS가 얼마나 세밀하게 작업을 분해했는지에 좌우됨|
|**EV 측정 방법 선택**|완료 여부(0/100%)·중간 마일스톤(50/50)·비례식(진도율 직접 산정) 등 방법에 따라 EV 값이 달라짐|
|**EAC 산출 공식 선택**|현재 CPI 추세가 계속될지, 새로운 계획으로 재수립할지에 따라 EAC 공식이 여러 변형 존재|
|**앞서 다룬 ES와의 병행**|프로젝트 후반부에는 SV·SPI 대신 ES 기반 지표로 전환해 왜곡 없는 일정 통제 유지|

---

**(제언)** "EVM의 근본적 통찰은 '돈을 얼마나 썼는가'와 '일이 얼마나 진행됐는가'라는 서로 다른 두 개의 질문을 EV라는 하나의 공통 화폐 단위로 환산해 동시에 답할 수 있게 만들었다는 데 있으며, 이는 프로젝트가 예산은 그대로 소진하면서도 실제 산출물은 계획보다 훨씬 뒤처지는 가장 위험하면서도 가장 흔히 발생하는 실패 패턴을 조기에 드러내는 강력한 조기경보 체계입니다. 다만 EVM이 신뢰할 수 있는 진단을 내리려면 그 출발점인 WBS가 충분히 세밀하고 각 작업 패키지의 EV 측정 기준이 명확해야 한다는 전제조건이 있으므로, 프로젝트 초기 계획 단계에서 앞서 다룬 ISO/IEC/IEEE 29148 수준의 명확하고 검증 가능한 작업 정의를 갖추지 못하면 EVM 지표 자체가 부정확한 착시를 낳을 수 있으며, 실무에서는 프로젝트 초중반에는 CPI·SPI로 원가·일정의 큰 흐름과 4분면 진단을 활용하고 후반부로 갈수록 앞서 다룬 ES 기반 SV(t)·SPI(t)로 전환해 종료 시점의 왜곡을 피하는 이원화된 관리 체계를 구축하는 것이 EVM을 도입한 공공·기업 프로젝트 관리의 핵심 실무 전략입니다.

**앞서 다룬 개념과의 연결**

| 연계 개념                   | 연결 내용                                                      |
| ----------------------- | ---------------------------------------------------------- |
| **ES(Earned Schedule)** | EVM의 SV·SPI가 프로젝트 후반부에 왜곡되는 문제를 시간 축으로 재해석해 보완하는 직접적 후속 개념 |
| **ISO/IEC/IEEE 29148**  | WBS·작업 정의의 명확성이 EV 측정 정확도의 전제조건으로 직결                       |
| **IT감리(관리적 영역)**        | 감리의 프로젝트 관리 영역에서 EVM 지표를 진도·원가 통제 증빙으로 활용                  |
| **SAFe(PI Planning)**   | 애자일 대규모 프로그램에서는 EVM 대신 번다운차트·속도(Velocity)가 유사한 역할 수행       |
