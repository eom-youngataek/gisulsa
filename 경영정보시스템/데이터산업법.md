데이터산업법(정식명: 데이터 산업진흥 및 이용촉진에 관한 기본법)은 \*\*"데이터를 자산으로 인정하고 그 자산이 잘 돌게(생산-보호-유통-활용) 만드는 법"\*\*이라는 한 줄 개념이 핵심입니다. 이 흐름 하나로 조항이 다 꿰어집니다.

### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (제정배경 - 데이터3법과의 차이) — 3~4줄
Ⅱ. 법 체계 (데이터 생애주기별 조항 구조, 본론①, 도식 1개)
Ⅲ. 핵심 조항 (본론②)
Ⅳ. 결론
```

포인트: 개요에서 \*\*"데이터3법(개인정보보호법·정보통신망법·신용정보법)은 '보호'가 중심, 데이터기본법은 '산업진흥·자산화'가 중심"\*\*이라는 대비를 던지면, 앞서 다룬 개인정보보호법 답안과 명확히 구분되는 시작점을 잡을 수 있습니다.

### Ⅱ. 법 체계 — 데이터 생애주기 "생·보·이·유·활" 5단계

**함정 방지: 조항을 번호순으로 나열하지 말고 "데이터가 태어나서 쓰이기까지의 흐름"으로 재배열하면 스토리가 됩니다.**

| 단계            | 핵심조항                                   | 내용                                                |
| :------------ | :------------------------------------- | :------------------------------------------------ |
| ① **생산**      | 제2조(정의), 제7조(기본계획)                     | 데이터 개념 정의, 국가데이터정책 총괄                             |
| ② **보호(자산화)** | **제12조(데이터자산 보호)**                     | 상당한 투자·노력으로 생성한 데이터의 경제적 가치 보호, 부정취득·사용 금지        |
| ③ **이동**      | **제15조(데이터 이동권)**                      | 본인 데이터를 본인/제3자에게 이동시킬 제도적 기반 구축 — **마이데이터의 원류조항** |
| ④ **유통·거래**   | 제18조(유통·거래체계), 제20조(품질관리), 제21조(표준계약서) | 데이터거래사, 품질인증기관, 표준계약서                             |
| ⑤ **활용**      | 데이터산업 창업·인력양성·기술개발 지원                  | 산업생태계 조성                                          |

→ 암기: **"만들어지고(생산) → 지켜지고(보호) → 옮겨지고(이동) → 거래되고(유통) → 쓰인다(활용)"** 5단계 스토리로 압축.

### 도식화 제안

```
[생산] 데이터 정의/기본계획
   ↓
[보호] ★제12조: 데이터자산 보호(부정사용 금지)★
   ↓
[이동] ★제15조: 데이터이동권(마이데이터 근거)★
   ↓
[유통·거래] 표준계약서/품질인증/데이터거래사
   ↓
[활용] 창업·인력양성·기술개발 지원
```

### Ⅲ. 핵심 조항 3개 — 시험에 가장 많이 나오는 부분

| 조항                            | 핵심포인트                                                                              | 왜 중요한가                                                                    |
| :---------------------------- | :--------------------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| **제12조 (데이터자산 보호)**           | "상당한 투자와 노력"으로 만든 데이터는 경제적 가치를 가지는 **자산**으로 보호. 무단취득·사용·기술적보호조치 회피 등을 **금지행위**로 명시 | 데이터에 저작권 없이도 **부정경쟁방지법 유사 보호**를 부여한 게 핵심 — "데이터=재산권은 아니지만 보호대상"이라는 절묘한 위치 |
| **제15조 (데이터이동)**              | 정부가 데이터를 **제3자에게 원활히 이동**시킬 제도적 기반을 구축하도록 노력                                       | 개인정보보호법 제35조의2(전송요구권)의 **입법적 뿌리** — 두 법이 연결된다는 점을 답안에 넣으면 심화배점            |
| **제18조/제20조/제21조 (유통·거래 기반)** | 데이터거래사 자격, 데이터 품질인증기관 지정, 표준계약서 제정                                                 | 데이터 시장의 신뢰기반(품질·계약) 조성                                                    |

→ "제12조는 지키는 조항, 제15조는 옮기는 조항, 제18\~21조는 거래를 돕는 조항"이라는 3분류로 외우면 조번호 암기 부담이 줄어듭니다.

### 결론 포인트 (차별화 한 줄)

데이터기본법의 진짜 의의는 데이터에 **소유권과 유사한 재산적 권리를 직접 부여한 게 아니라, "부정사용을 금지"하는 방식으로 간접 보호**한다는 점입니다 — 이는 데이터의 **비경쟁성·비배제성(누가 써도 없어지지 않는 특성)** 때문에 물권적 소유권 개념을 그대로 적용하기 어렵다는 데이터 고유의 특성을 반영한 입법기술이라는 논리로 마무리하면, 앞서 다룬 개인정보보호법(제35조의2 전송요구권)과의 연결성까지 보여주는 완결된 답안이 됩니다.

### **1. 답안 전개 스토리 (머릿속 핵심 흐름)**

> "4차 산업혁명 시대, 데이터는 '새로운 원유(Oil)'라 불리지만 정작 이를 사고파는 시장의 룰(Rule)이 없었다. 남이 힘들게 구축한 데이터를 무단 크롤링으로 훔쳐가도 처벌이 애매했고, 내 데이터가 시장에서 얼마짜리인지 평가할 객관적 기준도 없었다. 이 '데이터 경제'의 판을 깔기 위해 대한민국이 세계 최초로 제정한 법이 바로 \*\*'데이터산업법'\*\*이다. 이 법은 데이터를 함부로 훔치지 못하게 \*\*'자산으로 보호'\*\*하고, 가격표를 매겨주는 \*\*'가치평가 체계'\*\*를 만들며, 안전하게 데이터를 까볼 수 있는 \*\*'데이터 안심구역'\*\*과 이를 중개하는 **'데이터 거래사'** 제도를 도입하여, 데이터가 돈이 되어 유통되는 거대한 생태계를 만드는 핵심 근거법이다."

***

### **2. 실제 답안에 쓸 핵심 내용 (암기용)**

#### **I. \[도입] 데이터 경제 생태계의 주춧돌, 데이터산업법 개요**

* **정확한 법칭:** 데이터 산업진흥 및 이용촉진에 관한 기본법 (2022년 본격 시행)
* **목적:** 데이터의 안전한 생산·유통·활용을 촉진하고, 데이터 산업의 기반을 조성하여 '데이터 경제' 시대를 선도하기 위한 세계 최초의 데이터 기본법.
* **차별점:** 기존 「개인정보보호법」이 유출을 막는 **'보호(Protection)'** 중심이라면, 데이터산업법은 데이터를 시장에서 돈이 되게 하는 \*\*'산업 진흥 및 유통(Promotion)'\*\*에 철저히 방점이 찍혀 있음.

#### **II. \[본론 1] 데이터 유통 및 활용을 폭발시키는 4대 핵심 제도 (필수 암기)**

답안지 작성 시, 아래의 4가지 제도를 키워드로 명확히 뽑아주면 점수가 크게 상승합니다.

| **핵심 제도**                   | **주요 내용 (핵심 메커니즘)**                                                                 | **실무적 기대 효과**                                        |
| :-------------------------- | :---------------------------------------------------------------------------------- | :--------------------------------------------------- |
| **1. 데이터 안심구역** (Safe Zone) | - 원본 데이터(보안이 필요한 미개방 데이터)를 **외부로 유출/반출하지 않고, 구역 내부에서만 안전하게 분석**하고 결과값만 반출하도록 지정된 공간 | - 민감한 공공/민간 데이터의 안전한 융합 및 혁신적 AI/통계 모델 개발 촉진         |
| **2. 데이터 가치평가** 및 품질인증 체계   | - 데이터의 경제적 가치를 시장에서 정당하게 평가해 주는 **'가치평가기관'** 및 오류를 검증하는 **'품질인증기관'** 지정             | - 데이터에 '객관적 가격표'를 부여하여 **데이터 담보 대출** 및 시장 거래 활성화     |
| **3. 데이터 거래사** 양성           | - 복잡한 데이터 거래 기획, 가치 평가, 계약 중개, 법률/기술 컨설팅을 전문적으로 수행하는 **국가 공인 '데이터 거래사' 육성**         | - 정보 비대칭성을 해소하여 투명하고 활발한 B2B 데이터 거래 시장(Brokerage) 조성 |
| **4. 국가데이터 정책위원회** 신설       | - 국무총리 소속으로 범정부 차원의 데이터 정책을 총괄/조정하는 최고 수준의 **컨트롤 타워(Control Tower)** 신설             | - 각 부처(과기부, 행안부 등)로 흩어진 데이터 정책을 일원화하여 시너지 극대화        |

#### **III. \[본론 2] 무단 크롤링 철퇴! '데이터 자산의 보호' 명문화**

기업 실무에서 가장 중요한 조항입니다. 남의 데이터를 훔쳐 가는 행위에 철퇴를 가하는 법적 근거입니다.

* **데이터 자산 보호 조항:** 상당한 투자와 노력으로 생성된 데이터 자산을 공정한 상거래 관행에 반하여 **무단으로 크롤링(Crawling), 복제, 유용하는 행위를 '부정경쟁행위'로 간주하여 금지**함.
* **의의:** 기존 저작권법으로 보호받기 힘들었던 '단순 데이터의 축적물'에 대해서도 경제적 권리(자산 가치)를 확실하게 인정하여, 데이터 생성 기업의 투자 의욕을 고취함.

#### **IV. \[결론/제언] '개인정보보호법'과의 톱니바퀴 조화 및 생태계 조성 제언**

* **(키워드 위주 2줄 마무리)** "아무리 데이터산업법(엑셀)이 훌륭해도 개인정보 유출이라는 치명적 리스크(브레이크)를 제어하지 못하면 데이터 경제는 멈춥니다. 따라서 \*\*「개인정보보호법」의 '가명정보 결합 제도' 및 '마이데이터(전송요구권)'\*\*와 이 법의 가치평가/거래사 제도를 유기적으로 맞물려 융합시키는 \*\*'투트랙(Two-Track) 거버넌스'\*\*가 확립될 때, 비로소 진정한 데이터 경제 패권 국가로 도약할 수 있습니다."
