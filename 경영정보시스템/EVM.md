포인트: PV/EV/AC 3개를 먼저 확실히 구분한 뒤, "**PV·EV 비교 = 일정**, EV·AC 비교 = 원가"라는 대칭구조로 SV/CV/SPI/CPI를 도출하면 4개 공식을 따로 외울 필요가 없습니다.

### Ⅱ. 3대 기준값 — "계·번·실" (헷갈리기 쉬운 부분, 정의 정확히)

| 지표     | 원어            | 정의                        | 쉬운 표현              |
| :----- | :------------ | :------------------------ | :----------------- |
| **PV** | Planned Value | 계획된 시점까지 **계획된** 작업의 예산가치 | "원래 이만큼 하기로 했던 돈"  |
| **EV** | Earned Value  | 현재까지 **실제로 완료한** 작업의 예산가치 | "실제로 해낸 만큼의 돈(가치)" |
| **AC** | Actual Cost   | 현재까지 **실제로 지출한** 비용       | "실제로 쓴 돈"          |

→ 헷갈리는 이유는 EV입니다. \*\*EV는 "완료한 작업량 × 원래 예산단가"\*\*로 계산 — 실제 지출액(AC)이 아니라는 점이 핵심 함정입니다.

**예시로 각인 (계산문제 대비):**

> 예산 1,000만원짜리 작업을 계획대로면 오늘까지 60% 진행(PV=600), 실제로는 50%만 진행(EV=500), 그런데 이미 700만원 지출(AC=700)

### Ⅲ. 4대 파생지표 — "일정 축 vs 원가 축" 대칭구조

**공식 도출 원리: "EV(실적) - 비교대상" 구조를 기억하면 SV/CV는 자동**

| 지표               | 공식      | 의미                 | 판단기준           |
| :--------------- | :------ | :----------------- | :------------- |
| **SV** (일정편차)    | EV - PV | 계획보다 일정이 앞섰는지/늦었는지 | **음수(-) = 지연** |
| **CV** (원가편차)    | EV - AC | 예산보다 초과지출했는지       | **음수(-) = 초과** |
| **SPI** (일정성과지수) | EV ÷ PV | 계획 대비 진행 효율 (비율)   | **1 미만 = 지연**  |
| **CPI** (원가성과지수) | EV ÷ AC | 지출 대비 원가 효율 (비율)   | **1 미만 = 초과**  |

→ 위 예시로 즉시 계산 연습:

* SV = 500-600 = **-100** (일정 지연)
* CV = 500-700 = **-200** (원가 초과)
* SPI = 500/600 = **0.83** (계획보다 83% 속도)
* CPI = 500/700 = **0.71** (1원당 0.71원 가치만 생산 = 초과지출)

→ 암기: **"EV가 항상 앞에 온다"**(EV-PV, EV-AC / EV÷PV, EV÷AC). 뺄셈(V로 끝나는 것)은 "편차(금액차이)", 나눗셈(I로 끝나는 것)은 "지수(비율)"로 짝짓기.

**도식 (좌우 대칭구조):**

```
              [EV] 실제 완료한 가치
           ┌────────┴────────┐
      비교: PV(계획)        비교: AC(실지출)
      ↓                      ↓
   [일정 축]                [원가 축]
   SV = EV-PV               CV = EV-AC
   SPI = EV/PV              CPI = EV/AC
   (-,1미만=지연)            (-,1미만=초과)
```

### Ⅳ. 활용 — 예측(Forecasting)까지 연결하면 고득점

| 지표                  | 공식              | 의미                 |
| :------------------ | :-------------- | :----------------- |
| **EAC** (완료시점 예상원가) | BAC ÷ CPI (단순법) | 현재 효율 유지 시 최종 예상비용 |
| **ETC** (완료까지 잔여원가) | EAC - AC        | 앞으로 추가로 들 비용       |

→ "지금까지 성과(CPI)가 앞으로도 계속된다고 가정하면 최종 비용이 얼마냐"는 논리 한 줄만 붙이면 충분합니다. 공식을 억지로 외우기보다 **BAC(총예산)를 CPI로 나눈다** 이 감각만 있으면 됩니다.

### Ⅴ. 결론 포인트 (차별화 한 줄)

SPI/CPI를 함께 봐야 하는 이유는, **일정은 앞서지만(SPI≥1) 원가가 초과(CPI<1)되는 경우처럼 두 지표가 상충할 수 있기 때문**입니다 — 예를 들어 "돈을 더 써서 일정을 당긴 경우". 이 상충 사례를 결론에 한 줄 넣으면 단순 공식암기가 아니라는 걸 보여줄 수 있습니다.


**I. \[도입] 일정과 원가의 통합 통제, EVM(Earned Value Management) 개요**

* **정의:** 프로젝트의 범위, 일정, 원가를 통합하여 현재까지의 달성된 성과(Earned Value)를 화폐 단위로 환산해 프로젝트 건강 상태를 측정하는 관리 기법.
* **목적:** 주관적 진단의 한계 극복, 객관적 수치 기반의 조기 경보(Early Warning) 제공 및 향후 종료 시점의 예상 원가(EAC) 예측.

#### **II. \[본론 1] EVM의 3대 기본 지표 (이것만 알면 모두 풀림)**

세 가지 기본 지표의 영어 약자와 의미를 명확히 제시합니다.

| **지표 (약어)**            | **풀이 (의미)**                   | **과거 명칭** | **쉽게 이해하기 (직관적 해석)**          |
| :--------------------- | :---------------------------- | :-------- | :---------------------------- |
| **PV** (Planned Value) | **계획 가치** (현 시점까지 계획된 예산)     | BCWS      | "오늘까지 **하기로 계획했던** 일의 가치(돈)"  |
| **EV** (Earned Value)  | **획득 가치** (현 시점까지 달성한 성과)     | BCWP      | "오늘까지 **내가 실제로 해낸** 일의 가치(돈)" |
| **AC** (Actual Cost)   | **실제 원가** (현 시점까지 실제로 지출한 비용) | ACWP      | "오늘까지 **내 주머니에서 실제로 나간** 돈"   |

#### **III. \[본론 2] 편차(Variance)와 지수(Index) 계산 및 해석 (채점 핵심)**

> 💡 **\[초간단 암기 비법]**
>
> 1. 모든 공식은 \*\*무조건 EV(내가 해낸 일)가 맨 앞(또는 분자)\*\*에 옵니다.
> 2. \*\*차이(Variance)\*\*를 구할 때는 빼기(`-`), \*\*지수(Index)\*\*를 구할 때는 나누기(`/`)를 합니다.
> 3. 결과값이 **'0'보다 크거나(+) '1'보다 크면 무조건 좋은 것**입니다.

이 암기법을 적용하여 아래의 4대 지표 표를 답안지에 그대로 작성합니다.

| **구분**    | **지표명**                              | **공식 (EV가 맨 앞!)** | **결과 해석 (1이나 0보다 크면 좋은 것)**                                                |
| :-------- | :----------------------------------- | :---------------- | :------------------------------------------------------------------------- |
| **일정 차이** | **SV** (Schedule Variance)           | = **EV** - PV     | **(+) 양수:** 일정 단축 (계획보다 많이 해냄!) **(-) 음수:** 일정 지연 (계획보다 덜 해냄)              |
| **원가 차이** | **CV** (Cost Variance)               | = **EV** - AC     | **(+) 양수:** 원가 절감 (벌어들인 가치가 쓴 돈보다 큼!) **(-) 음수:** 원가 초과 (벌어들인 가치보다 돈을 더 씀) |
| **일정 효율** | **SPI** (Schedule Performance Index) | = **EV** / PV     | **> 1 :** 일정 단축 (우수) **< 1 :** 일정 지연 (불량)                                  |
| **원가 효율** | **CPI** (Cost Performance Index)     | = **EV** / AC     | **> 1 :** 원가 절감 (우수) **< 1 :** 원가 초과 (불량)                                  |

*(작성 예시: SPI가 0.8이고 CPI가 1.2라면? → 일정은 지연되고 있으나, 원가는 절감하며 효율적으로 쓰고 있음)*

#### **IV. \[결론/제언] 성공적인 EVM 적용을 위한 PM의 역할**

* "EVM은 과거의 실적을 분석하는 것을 넘어, 현재의 CPI/SPI 추세를 바탕으로 **완료 시점의 총 예상 원가(EAC)와 잔여 필요 예산(ETC)을 과학적으로 예측**하는 데 진정한 가치가 있습니다. 단, EVM이 제대로 작동하려면 프로젝트 착수 시점에 WBS가 완벽하게 작성되고 각 워크 패키지별로 정확한 예산(PV)이 할당되어야 하므로, 초기 베이스라인(Baseline) 수립 시 PM의 역량이 매우 중요합니다."
