데이터3법은 이미 다룬 개인정보보호법 답안과 겹치는 부분이 많아서, 오늘은 \*\*"3개 법이 어떻게 역할을 나눠 가지는가"\*\*에 초점을 맞추면 차별화됩니다. 3법을 각각 설명하면 중복이니, \*\*"개인정보 하나를 두고 3개 법이 각자 다른 각도에서 규율한다"\*\*는 구조로 스토리를 짜겠습니다.

### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (데이터3법 정의, 2020년 개정 배경) — 3~4줄
Ⅱ. 3법 역할분담 (본론①, 도식 1개 필수)
Ⅲ. 3법 통합의 핵심 개정내용 (본론②)
Ⅳ. 최신 동향 및 결론
```

포인트: 개요에서 \*\*"3법이 개인정보를 각각 다른 관점(일반법/온라인/금융)에서 다루다 보니 중복규제·사각지대가 생겼고, 이를 정비한 게 2020년 데이터3법 개정"\*\*이라는 한 줄로 시작하면, "왜 3법이 묶여서 개정됐는가"의 논리가 섭니다.

### Ⅱ. 3법 역할분담 — "일·온·금" (일반/온라인/금융)

**함정 방지: 3법을 각각 통째로 설명하면 앞서 다룬 개인정보보호법 답안과 중복. 오늘은 "역할 경계"만 명확히.**

| 법률          | 소관        | 규율범위                                                 |
| :---------- | :-------- | :--------------------------------------------------- |
| **개인정보보호법** | 개인정보보호위원회 | **일반법** — 모든 분야 개인정보처리의 기본원칙·정보주체 권리 (앞서 다룬 8원칙 등)   |
| **정보통신망법**  | 방송통신위원회   | **온라인 특화** — 정보통신서비스제공자의 개인정보 수집·이용, 광고성 정보전송 규제     |
| **신용정보법**   | 금융위원회     | **금융 특화** — 신용정보(금융거래정보) 처리, 마이데이터(본인신용정보관리업)의 법적 근거 |

→ 암기: **"모두에게 적용되는 기본법(일반), 인터넷에 특화된 법(온라인), 돈에 특화된 법(금융)"** — 3개 영역이 겹치지 않게 역할을 나눈다는 게 핵심.

**2020년 개정의 핵심: 중복→통합**

개정 전에는 온라인상 개인정보 관련 규정이 정보통신망법에도 있고 개인정보보호법에도 있어 **이중규제**였는데, 2020년 개정으로 온라인 개인정보 관련 규정을 **개인정보보호법으로 일원화**하고, 정보통신망법은 순수 통신·온라인서비스 규제로 역할이 축소됐습니다.

### 도식화 제안

```
              [개인정보]
       ┌────────┼────────┐
   일반법          온라인특화       금융특화
[개인정보보호법]  [정보통신망법]   [신용정보법]

 - 정보주체권리     - 통신서비스      - 마이데이터
     (2020개정: 온라인 개인정보조항 이관 ← 통합)
```

### Ⅲ. 3법 통합의 핵심 개정내용 — "통·가·마·독" (4대 키워드)

| 키워드             | 내용                                                              |
| :-------------- | :-------------------------------------------------------------- |
| **통합(거버넌스)**    | 개인정보보호위원회를 **중앙행정기관으로 격상**, 감독권한 일원화                            |
| **가명정보 도입**     | **가명정보**(추가정보 결합 없이는 식별 불가) 개념 신설 — 통계작성·연구 목적 시 **동의없이 활용** 가능 |
| **마이데이터 근거**    | 신용정보법에 **본인신용정보관리업** 신설 — 금융 마이데이터 산업의 법적 근거                    |
| **독립성/거버넌스 개편** | 정보통신망법의 개인정보 관련 조항 상당수를 개인정보보호법으로 이관                            |

→ 암기: **"감독기관 통합하고, 가명정보 만들고, 마이데이터 열어주고, 조항을 정리했다"** — 4개 키워드로 압축.

### Ⅳ. 최신 동향 및 결론

**최신 동향**: 앞서 다룬 개인정보보호법 답안에서 언급한 2026년 개정(CPO책임강화·ISMS-P인증의무화·과징금 10%상향)과 함께, 정보통신망법도 \*\*2026년 3월 개정(침해사고 반복시 과징금 신설, 광고성정보 전송규제 강화)\*\*이 병행 통과되어, 데이터3법이 **동시에 개정되는 패턴**이 이어지고 있습니다 — 3법이 원래 하나의 정책목표(개인정보보호 강화) 아래 움직인다는 걸 보여주는 대목입니다.

**결론 포인트 (차별화 한 줄)**: 데이터3법의 핵심가치는 \*\*"보호와 활용의 균형(가명정보)"\*\*에 있으며, 앞서 다룬 데이터산업법(제12조 데이터자산보호, 제15조 데이터이동)이 **"산업진흥" 관점**이라면, 데이터3법은 **"개인정보보호" 관점**에서 같은 데이터경제를 다른 각도로 규율한다는 대비로 마무리하면, 앞선 두 답안(개인정보보호법·데이터산업법)이 하나의 큰 그림으로 완성됩니다.

### **1. 답안 전개 스토리 (머릿속 핵심 흐름)**

> "과거에는 데이터 관련 규제가 3개의 법에 뿔뿔이 흩어져 있어 기업들이 큰 혼란을 겪었고, 빅데이터 분석을 하려 해도 깐깐한 동의 절차 때문에 막대한 데이터를 그냥 쌓아두기만 했다. 이 족쇄를 풀고 진정한 데이터 경제 시대를 열기 위해 3개의 법을 일괄 개정한 것이 바로 \*\*'데이터 3법'\*\*이다. 핵심은 감독기관을 **'개인정보보호위원회'** 하나로 깔끔하게 일원화하고, 누구인지 못 알아보게 처리한 \*\*'가명정보'\*\*를 도입하여 동의 없이도 AI 학습과 연구에 데이터를 마음껏 쓰게 해 주며, 금융 분야부터 내 데이터를 내가 관리하는 **'마이데이터'** 비즈니스의 문을 활짝 열어준 것이다."

### **2. 실제 답안에 쓸 핵심 내용 (암기용)**

#### **I. \[도입] 데이터 경제 활성화를 위한 규제 혁신, 데이터 3법 개요**

* **정의:** 데이터를 안전하면서도 활발하게 산업에 활용하기 위해, 중복되고 흩어져 있던 규제를 통합하고 신산업(빅데이터, AI) 육성의 룰을 마련한 3개 법률(**개인정보보호법, 정보통신망법, 신용정보법**)의 일괄 개정안.
* **추진 배경:** 4차 산업혁명 시대 핵심 자원인 데이터의 활용 제약 극복, 여러 부처로 나뉜 비효율적인 개인정보 감독기구 통합 필요, 그리고 유럽(EU)의 GDPR 적정성 평가 통과를 위한 글로벌 스탠다드 충족.

#### **II. \[본론 1] 데이터 3법의 3대 핵심 개정 방향 (법률별 역할 분담표)**

답안지 작성 시, 어떤 법이 어떻게 바뀌었는지 표로 명확히 보여주는 것이 고득점 포인트입니다.

| **법률 명칭**              | **핵심 개정 내용 및 역할 변화**                                                                                     | **기대 효과 (수험용 키워드)**                              |
| :--------------------- | :------------------------------------------------------------------------------------------------------- | :----------------------------------------------- |
| **1. 개인정보 보호법** (기본법)  | ⚖️ **감독기구 일원화 및 가명정보 도입** - 흩어진 감독 권한을 국무총리 소속 **'개인정보보호위원회(개보위)'로 격상 및 통합** - 개인을 알아볼 수 없는 '가명정보' 개념 도입 | - 부처 간 중복 규제와 혼란 완벽 해소 - 동의 없는 빅데이터 분석의 길잡이 역할   |
| **2. 정보통신망법** (온라인 통제) | 🗑️ **개인정보 관련 규정 삭제 및 이관** - 정보통신망법에 있던 온라인 개인정보 보호 관련 조항을 모조리 **개인정보보호법으로 이관**                          | - 온·오프라인 이원화 규제 철폐 - 개인정보보호법의 위상 및 통제력 강화        |
| **3. 신용정보법** (금융 통제)   | 💰 **마이데이터 산업 도입 및 결합 전문기관** - 금융 분야의 마이데이터(본인신용정보관리업) 신설 - 이기종 산업 간 데이터를 안전하게 합쳐주는 **데이터 결합 전문기관** 지정   | - 흩어진 금융 정보를 한곳에 모으는 혁신적 **핀테크(FinTech)** 서비스 창출 |

#### **III. \[본론 2] 데이터 3법이 쏘아 올린 산업 혁신의 무기: '가명정보'**

데이터 3법에서 가장 중요한 기술적 개념은 단연 \*\*'가명정보'\*\*입니다. 이 부분을 강조해서 적어야 합니다.

* **가명정보의 정의:** 원래의 상태로는 특정 개인을 알아볼 수 없고, 복원하기 위한 '추가 정보'를 결합해야만 개인 식별이 가능하도록 처리(비식별 조치)한 정보.
* **폭발적 파급력:** 기존에는 반드시 '정보주체의 동의'가 있어야만 데이터를 쓸 수 있었으나, 가명정보로 처리하면 **①통계 작성, ②과학적 연구(AI 학습 알고리즘 개발 등), ③공익적 기록 보존**의 3가지 목적에 한해 **동의 없이도 데이터를 상업적으로 활용**할 수 있게 됨.

#### **IV. \[결론/제언] 데이터 3법의 진화: 최신 개보법 개정과의 연계**

* **(키워드 위주 2줄 마무리)** "2020년 데이터 3법 개정이 가명정보를 통한 '기업 중심의 빅데이터 활용'을 열었다면, 최근 개정된 「개인정보보호법(2023\~)」은 신용정보법(금융)에만 갇혀 있던 마이데이터(전송요구권)를 의료, 통신 등 전 산업으로 확장하여 \*\*'정보주체(국민) 중심의 데이터 주권'\*\*을 완성하는 방향으로 데이터 거버넌스의 패러다임을 진화시키고 있습니다."
