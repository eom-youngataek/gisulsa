## Ⅰ. 개요 키워드

**TAM·SAM·SOM 프레임워크**
신사업·스타트업·IT 서비스 기획 시 시장 규모를 **3단계 계층**으로 정량화하는 시장 분석 프레임워크.
투자자 설득·사업 타당성 검증·전략적 의사결정의 핵심 도구.

**활용 목적**
- **투자 유치(IR)**: 시장 규모의 객관적 근거 제시
- **사업 기획**: 진입 가능한 현실적 목표 시장 설정
- **전략 수립**: 단기(SOM)→중기(SAM)→장기(TAM) 확장 로드맵
- **IT 거버넌스 연계**: IT 투자 ROI 산정의 시장 기반 데이터

**등장배경**
벤처캐피털·스타트업 생태계에서 "얼마나 큰 시장인가(How big is the market?)"에 대한 체계적 답변 필요. TAM만 제시 시 비현실적 낙관 → SAM·SOM으로 실현 가능성 구분.

## Ⅱ. TAM (Total Addressable Market)

**정의**
**전체 목표 시장(총 잠재 시장)**
특정 제품·서비스가 이론적으로 도달할 수 있는 **최대 시장 규모**.
지리적·경쟁적·기술적 제약을 고려하지 않은 전체 기회.

**핵심 키워드**
- **전체 잠재 수요(Total Potential Demand)**: 해당 카테고리의 전 세계 또는 전국 총 수요
- **이상적 시나리오(Ideal Scenario)**: 경쟁 없이 100% 점유 시 얻을 수 있는 매출
- **거시 시장 규모**: IDC·가트너·KPMG 등 리서치 기관의 글로벌 시장 보고서 활용
- **단위**: 연간 매출 금액(억 원·Billion $) 또는 고객 수(명)

**산출 방식**
```
TAM = 잠재 고객 수(전체) × 1인당 평균 구매액(연간)
예) 국내 중소기업 수(300만개) × AI 솔루션 연간 구독료(100만원)
   = 3조 원 (TAM)
```

**특징**
- 가장 큰 원(최외각)
- 현실적 진입 가능성 미고려
- 시장 매력도(Market Attractiveness) 평가 지표

---

## Ⅲ. SAM (Serviceable Addressable Market)

**정의**
**유효 목표 시장(서비스 가능 시장)**
TAM 중 자사의 **제품·기술·유통·지역·규제** 조건상 실제로 도달 가능한 시장 규모.
경쟁사 포함 전체 시장에서 자사가 싸울 수 있는 영역.

**핵심 키워드**
- **세분화(Segmentation)**: TAM을 지역·업종·규모·기술 수준으로 세분화
- **타깃 세그먼트(Target Segment)**: 자사 역량으로 경쟁 가능한 특정 세그먼트
- **실현 가능 시장(Reachable Market)**: 영업·유통·파트너십으로 접근 가능한 범위
- **규제·인증 제약**: 공공기관 대상 서비스의 CSAP·조달 자격 요건 등

**산출 방식**
```
SAM = TAM × 세그먼트 비율(지역·업종·규모 필터)
예) TAM 3조원 × 국내 IT 서비스 기업 비율(15%) × 예산 요건 충족 비율(30%)
   = 1,350억 원 (SAM)
```

**특징**
- 중간 원(TAM의 부분집합)
- 현실적 경쟁 영역 정의
- 마케팅·영업 전략의 기준 시장

---

## Ⅳ. SOM (Serviceable Obtainable Market)

**정의**
**획득 가능 시장(실현 가능 점유 시장)**
SAM 중 **단기(1~3년)** 내 자사가 실제로 획득할 수 있는 현실적 시장 점유 규모.
자사의 현재 역량·자원·브랜드·파이프라인을 기반으로 산출.

**핵심 키워드**
- **시장 점유율(Market Share)**: 현실적으로 달성 가능한 점유율 목표
- **단기 매출 목표**: 1~3년 사업 계획과 연동
- **경쟁 우위(Competitive Advantage)**: 자사만의 차별화 요소로 확보 가능한 고객
- **파이프라인(Pipeline)**: 현재 영업 중인 잠재 고객·계약 추진 건수

**산출 방식**
```
SOM = SAM × 현실적 점유율(%)
예) SAM 1,350억 원 × 목표 점유율 5%
   = 67.5억 원 (SOM) → 연간 매출 목표
```

**특징**
- 가장 작은 원(SAM의 부분집합)
- 투자자가 가장 주목하는 숫자
- 실행 가능한 사업 계획의 매출 기준

## Ⅴ. 3단계 계층 구조 및 비교표

**동심원(Concentric Circle) 구조**
```
┌─────────────────────────────────┐
│  TAM (Total Addressable Market) │
│  전체 잠재 시장 (가장 큰 원)      │
│  ┌──────────────────────────┐  │
│  │  SAM (Serviceable)       │  │
│  │  유효 목표 시장            │  │
│  │  ┌──────────────────┐   │  │
│  │  │  SOM (Obtainable)│   │  │
│  │  │  획득 가능 시장    │   │  │
│  │  └──────────────────┘   │  │
│  └──────────────────────────┘  │
└─────────────────────────────────┘
```

**3단계 비교표**

| 구분 | TAM | SAM | SOM |
|---|---|---|---|
| **정의** | 전체 잠재 시장 | 유효 목표 시장 | 획득 가능 시장 |
| **영문** | Total Addressable Market | Serviceable Addressable Market | Serviceable Obtainable Market |
| **범위** | 이론적 최대 | 기술·지역·규제 필터 | 현실적 점유 가능 |
| **시간 관점** | 장기(궁극적 목표) | 중기(확장 목표) | 단기(1~3년 매출 목표) |
| **활용** | 시장 매력도 평가 | 경쟁 전략 수립 | 투자자 설득·사업 계획 |
| **크기** | 가장 큼 | 중간 | 가장 작음 |
| **산출 기준** | 전체 잠재 수요 | 세그먼트 필터링 | 현실적 점유율 적용 |

## Ⅵ. 시장 규모 추정 방법론

### Top-Down(하향식) 방법

**개념**
전체 시장 통계→세분화 필터 적용→목표 시장 도출
거시 데이터에서 출발해 점진적으로 좁혀가는 방식.

**핵심 키워드**
- **리서치 기관 보고서**: IDC·Gartner·Forrester·KPMG 글로벌 시장 데이터
- **통계청·KISA·NIA 통계**: 국내 IT 시장 통계 활용
- **세분화 비율 적용**: 전체 시장 × 타깃 세그먼트 비율 순차 적용
- **빠른 추정 가능**: 공신력 있는 수치 활용으로 설득력 높음

**계산 흐름**
```
글로벌 AI 시장(1,500억$) → 국내 비율(2%) → 30억$ (TAM)
→ 중소기업 세그먼트(20%) → 6억$ (SAM)
→ 목표 점유율(3%) → 1,800만$ (SOM)
```

**한계**: 세분화 비율의 자의적 설정 가능 / 검증 어려움

---

### Bottom-Up(상향식) 방법

**개념**
실제 단위 데이터에서 출발해 전체 시장 규모 산출.
고객 단위 매출에서 적산(積算)하는 방식.

**핵심 키워드**
- **단위 경제학(Unit Economics)**: 고객 1인당 매출·원가 분석
- **고객 수 추정**: 타깃 고객 모집단 × 전환율
- **파이프라인 기반**: 현재 영업 중인 잠재 고객 데이터 활용
- **현실적 근거**: 실제 거래 데이터 기반으로 신뢰도 높음

**계산 흐름**
```
국내 IT 기업 수(5만개) × 타깃 비율(10%) = 5,000개 (잠재 고객)
× 연간 계약 단가(5,000만원) = 2,500억원 (SAM)
× 현실적 점유율 5% = 125억원 (SOM)
```

**한계**: TAM 산출에 부적합 / 데이터 확보 어려움

---

### Top-Down vs Bottom-Up 비교

| 구분 | Top-Down | Bottom-Up |
|---|---|---|
| **출발점** | 거시 시장 통계 | 단위 고객 데이터 |
| **적합 시장** | TAM·SAM 산출 | SAM·SOM 산출 |
| **장점** | 빠른 추정·공신력 | 현실 기반·정확성 |
| **단점** | 자의적 비율 설정 | 데이터 확보 한계 |
| **추천 활용** | 시장 매력도 제시 | 투자자 설득·사업 계획 |

**Best Practice**: Top-Down으로 TAM·SAM 산출 + Bottom-Up으로 SOM 검증 → **교차 검증(Cross-Validation)** 으로 신뢰도 향상

## Ⅶ. IT 분야 적용 사례

**AI 소프트웨어 시장 진입 사례**
```
TAM: 국내 전체 기업 SW 시장 → 15조원
SAM: 국내 AI/ML 솔루션 도달 가능 기업 → 2조원
     (IT 예산 1억 이상 + AI 도입 의향 기업 필터)
SOM: 1~3년 내 확보 목표 → 200억원 (1% 점유)
```

**클라우드 MSP 사업 사례**
```
TAM: 국내 전체 클라우드 서비스 시장 → 5조원
SAM: 중견기업 대상 AWS/Azure 관리 서비스 → 8,000억원
SOM: 초기 레퍼런스 30개사 × 연간 계약 2억원 → 60억원
```

**공공 AI 서비스 사례 (CSAP 연계)**
```
TAM: 전체 공공기관 IT 예산 → 10조원
SAM: AI 적용 가능 + CSAP 인증 보유 영역 → 1조원
SOM: CSAP 하등급 적용 가능 SaaS 목표 시장 → 500억원
```

## 📌 1교시 암기 체크리스트

- [ ] **TAM** = Total Addressable Market / 전체 잠재 시장 / 이론적 최대
- [ ] **SAM** = Serviceable Addressable Market / 유효 목표 시장 / 기술·지역·규제 필터
- [ ] **SOM** = Serviceable Obtainable Market / 획득 가능 시장 / 단기 현실적 점유
- [ ] **크기 관계**: TAM > SAM > SOM (동심원 구조)
- [ ] **시간 관점**: TAM(장기) > SAM(중기) > SOM(단기 1~3년)
- [ ] SOM = SAM × 현실적 점유율(%)
- [ ] **Top-Down**: 거시 통계→세분화 / TAM·SAM 산출에 적합
- [ ] **Bottom-Up**: 단위 고객→적산 / SAM·SOM 산출에 적합
- [ ] **교차 검증**: Top-Down + Bottom-Up 병행으로 신뢰도 향상
- [ ] **투자자(IR)** 관점: SOM이 가장 중요한 숫자
- [ ] **리서치 기관**: IDC·Gartner·Forrester / 국내 KISA·NIA·통계청
