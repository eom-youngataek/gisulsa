### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (갈등의 양면성 - 순기능/역기능) — 3~4줄
Ⅱ. 갈등요인 분류 (3대 범주, 본론①)
Ⅲ. 해결전략 (요인별 맞춤 + 예방적 접근, 본론②, 도식 1개)
Ⅳ. 결론
```

포인트: 개요에서 \*\*"갈등=역기능만 있는 게 아니라, 적정수준의 갈등은 성과를 높인다(순기능)"\*\*는 로빈스(Robbins)의 상호작용론적 관점을 한 줄 넣으면 시작부터 차별화됩니다.

### Ⅱ. 갈등요인 3대 범주 — "개·구·조"

**함정 방지: 요인을 무작정 나열하지 말고 "원인의 층위"로 분류**

| 범주         | 핵심요인                                                        | 예시                  |
| :--------- | :---------------------------------------------------------- | :------------------ |
| **개인적 요인** | 가치관·성격차이, 의사소통방식 차이, 목표인식 차이                                | 완벽주의자 vs 속도우선주의자 충돌 |
| **구조적 요인** | 역할·책임 모호(R\&R 불명확), 자원(인력·예산) 부족·경쟁, 상호의존성(Interdependency) | 두 부서가 같은 예산을 놓고 경쟁  |
| **조직적 요인** | 목표 불일치(부서 이기주의), 보상체계 불공정, 권력/지위 차이                         | 영업팀 vs 개발팀 KPI 상충   |

→ 암기: **"사람이 달라서(개인), 구조가 애매해서(구조), 조직목표가 어긋나서(조직)"** — 아래 계층일수록 개인이 못 바꾸고 위(제도) 개입이 필요하다는 게 핵심 논리입니다.

**+ PM 실무 심화 (PMBOK식 세부요인, 언급하면 가점)**

일정(Schedule), 우선순위(Priority), 자원(Resource), 기술적 견해차(Technical), 행정절차(Administrative), 비용(Cost), 개인성향(Personality) — **"일·우·자·기·행·비·개"** 7요인. 위 3범주 중 "구조적 요인"의 세부항목으로 붙이면 자연스럽게 연결됩니다.

### Ⅲ. 해결전략 — "예방(사전) + 대응(사후)" 2단 구조

**함정 방지: 해결전략 = 토마스-킬만 유형(협력/타협/강요 등) 나열만 하면 이미 다룬 내용 반복. 오늘은 "요인별 맞춤 해법 + 제도적 예방"으로 차별화.**

| 갈등요인   | 맞춤 해결전략                                              |
| :----- | :--------------------------------------------------- |
| 개인적 요인 | 의사소통 활성화, 상호이해 워크숍, 1:1 코칭                           |
| 구조적 요인 | **R\&R 명확화**(RACI 매트릭스), 자원배분 기준 사전합의, 공동목표(상위목표) 제시 |
| 조직적 요인 | **평가·보상체계 재설계**, 부서 간 협업 KPI 도입, 권한위임 명확화            |

**+ 공통 예방기법 (사전예방, 차별화 핵심)**

| 기법                               | 핵심                       |
| :------------------------------- | :----------------------- |
| **상위목표 제시** (Superordinate Goal) | 부서 이기주의를 넘어서는 공동목표로 재정렬  |
| **경계관리** (Boundary Management)   | 역할·프로세스 경계를 사전에 명확히 문서화  |
| **정기적 소통채널**                     | 갈등이 커지기 전 조기발견(회의체, 1:1) |

→ 토마스-킬만은 "이미 터진 갈등을 어떻게 다루는가"이고, 여기서 다루는 건 \*\*"애초에 갈등요인을 줄이는 제도설계"\*\*라는 점이 차별포인트입니다.

### 도식화 제안

요인-전략을 화살표로 매칭:

```
[개인적요인]──→ 소통/코칭
[구조적요인]──→ R&R명확화(RACI), 공동목표
[조직적요인]──→ 평가보상체계 재설계
        ↓ (공통 예방)
   [상위목표 제시 + 경계관리 + 정기소통]
```

### Ⅳ. 결론 포인트 (차별화 한 줄)

갈등관리의 목표는 \*\*"갈등 제거"가 아니라 "갈등을 순기능(창의성·다양한 시각) 수준으로 유지하고 역기능(감정적 대립) 수준으로 악화되지 않게 관리하는 것"\*\*입니다. 이 한 줄이 앞서 다룬 터크만/토마스-킬만 답안과 자연스럽게 이어지는 결론이 됩니다.

#### **I. \[도입] 갈등의 현대적 관점과 갈등 관리 개요**

* **갈등의 양면성:** 갈등이 너무 없으면 조직이 정체되고, 너무 많으면 파괴적 결과를 낳습니다. 따라서 창의성과 성과를 극대화하는 \*\*기능적 갈등(Functional Conflict)\*\*은 유지하고, 팀워크를 해치는 \*\*역기능적 갈등(Dysfunctional Conflict)\*\*은 신속히 해소해야 합니다.

#### **II. \[본론 1] 프로젝트의 주요 갈등 요인 (발생 빈도순 암기)**

시험에서 "주요 갈등 요인을 나열하라"고 할 때, 아무렇게나 쓰지 말고 **빈도가 높은 순서대로** 쓰면 전문가의 느낌을 줍니다.

1. ⏱️ **일정 (Schedules):** 기한의 압박과 일정 지연에 대한 부담 **(가장 큰 갈등 요인)**
2. 🎯 **프로젝트 우선순위 (Priorities):** 어떤 작업을 먼저 할 것인가에 대한 이견
3. 🛠️ **자원 (Resources):** 한정된 인력, 장비, 예산의 배분 문제
4. 💡 **기술적 이견 (Technical Opinions):** 개발 방식이나 아키텍처 등 기술적 선택의 충돌
5. 📄 **행정 절차 (Administrative Procedures):** 결재 라인, 보고 방식 등 프로세스 불만
6. 💰 **비용 (Costs):** 예산 초과 및 비용 절감에 대한 압박
7. 👤 **개인적 성향 (Personalities):** 성격 차이나 개인적 감정 **(가장 적은 갈등 요인)**
   * *(※ 채점 포인트: 의외로 '성격 차이'가 갈등의 주된 원인이 아니라는 점을 짚어주는 것이 꿀팁입니다.)*

#### **III. \[본론 2] 갈등 해결 5대 전략 (토마스-킬만 모델)**

이 부분은 자신(독단성)과 타인(협력성)의 이익을 얼마나 챙길 것인가에 따른 2x2 매트릭스로 암기합니다.

| **해결 전략**                     | **접근 방식 (결과)**                                               | **적용해야 할 상황 (언제 쓰는가?)**                                                   |
| :---------------------------- | :----------------------------------------------------------- | :------------------------------------------------------------------------ |
| **문제해결 / 협력** (Collaborating) | 🤝 **Win-Win (가장 바람직함)** 양측이 깊이 논의하여 모두가 100% 만족하는 최상의 대안 도출 | - 사안이 매우 중요하여 양측의 타협이 불가할 때 - **장기적이고 근본적인 해결책**이 필요할 때                   |
| **타협** (Compromising)         | ⚖️ **Lose-Lose (부분적 만족)** 양쪽이 조금씩 양보하여 중간 지점의 해결책을 찾는 방식     | - 양측의 주장이 팽팽하게 맞서고 있을 때 - **시간이 촉박하여** 적당한 선에서 합의해야 할 때                   |
| **수용 / 원만** (Accommodating)   | 🕊️ **Lose-Win (양보)** 관계 유지를 위해 자신의 주장을 포기하고 상대방의 의견을 따름     | - 내가 틀렸다는 것을 알았을 때 - 당장의 이슈보다 **조직의 조화나 장기적 관계 유지**가 더 중요할 때              |
| **강제 / 지시** (Forcing)         | 🗡️ **Win-Lose (명령)** 자신의 권력이나 지위를 이용해 상대방에게 강제로 자신의 의견을 관철  | - 위기 상황이 발생해 **신속하고 단호한 결단**이 필요할 때 - 인기 없는 조치를 강력히 시행해야 할 때              |
| **회피 / 철회** (Avoiding)        | 🏃 **Lose-Lose (도피)** 갈등 상황 자체에 개입하지 않고 뒤로 미루거나 피하는 방식       | - 이슈가 사소하여 굳이 에너지를 낭비할 필요가 없을 때 - 감정이 격해져서 **일단 냉각기(Cooling-off)가 필요**할 때 |

#### **IV. \[결론/제언] 성공적인 갈등 관리를 위한 PM의 역량**

* **(키워드 위주 2줄 마무리)** "가장 완벽한 갈등 해결 전략은 '협력(Win-Win)'이지만 모든 상황에 적용할 수는 없습니다. 따라서 PM은 갈등 발생 전 \*\*'그라운드 룰(Ground Rule)'\*\*을 확립하여 갈등을 예방하고, 사안의 중요도와 촉박함에 따라 5가지 전략 카드를 유연하게 선택하는 \*\*'감성 지능(Emotional Intelligence)'\*\*과 \*\*'상황 대응 리더십'\*\*을 발휘해야 합니다."
