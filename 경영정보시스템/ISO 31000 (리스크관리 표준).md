### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (리스크관리 정의, ISO 31000 목적) — 3~4줄
Ⅱ. ISO 31000 구성체계 (원칙·프레임워크·프로세스) — 본론, 도식 1개
Ⅲ. 적용 시 고려사항/기대효과
Ⅳ. 결론
```

포인트: ISO 31000은 "3층 구조"라는 것 자체가 핵심 논리입니다. **원칙(왜) → 프레임워크(누가/어떻게 운영) → 프로세스(실제 절차)** 순서로, 위에서 아래로 구체화되는 흐름임을 강조하면 채점자가 이해도를 바로 알아봅니다.

### 핵심 키워드 (암기용 최소 세트)

**① 원칙 — "가치창출"이 핵심 한 단어, 나머지는 수식어**

암기 팁: 8개 원칙을 낱개로 외우지 말고 "가치창출 + 3형용사"로 압축

| 구분 | 핵심                                                                    |
| :- | :-------------------------------------------------------------------- |
| 목적 | **가치의 창출과 보호** (Value creation & protection)                          |
| 성격 | 통합적(Integrated), 구조적·포괄적(Structured), 맞춤형(Customized)                 |
| 특성 | 동태적(Dynamic), 최적정보 기반(Best available information), 인간·문화요소 반영, 지속적 개선 |

→ "가치창출을 위해 통합·맞춤·동태적으로, 사람과 정보를 반영해 계속 개선한다" 한 문장으로 압축해서 외우면 8개가 자동 복원됩니다.

**② 프레임워크 — "PDCA와 동일 구조"로 외우기**

| 구분    | 핵심활동                                                     |
| :---- | :------------------------------------------------------- |
| Plan  | 리더십·의지(Leadership & commitment), 설계(Design) - 조직이해, 역할부여 |
| Do    | 실행(Implementation)                                       |
| Check | 평가(Evaluation)                                           |
| Act   | 개선(Improvement)                                          |

→ 이미 알고 있는 PDCA에 얹으면 "설계-실행-평가-개선" 4개만 남습니다.

**③ 프로세스 — "소통 감싸고 5단계 진행"**

```
        [의사소통 및 협의] ← 전체를 감싸는 활동
              ↓
[범위·상황·기준 수립] → [리스크 평가] → [리스크 처리]
                          (식별→분석→평가)
              ↓
        [모니터링 및 검토]
              ↓
        [기록 및 보고]
```

→ 외우는 순서: **"범·평·처·모·기"** (범위, 평가, 처리, 모니터링, 기록) + 이걸 양옆에서 "소통·협의"가 감싸는 구조.

### 도식화 제안 (배점 유리)

원, 사각형 3단 피라미드로 그리세요:

```
        [원칙] 가치창출
           ↓
     [프레임워크] 설계-실행-평가-개선(PDCA)
           ↓
      [프로세스] 범위→평가→처리→모니터링→기록
   (전체를 의사소통·협의가 감싸는 구조)
```

이 삼각형 하나로 본론 골격이 완성됩니다.
