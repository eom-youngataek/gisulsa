### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (IT투자평가 필요성, IT-ROI 특수성) — 3~4줄
Ⅱ. IT투자평가 체계 (정량 + 정성, 본론, 도식 1개)
Ⅲ. 평가절차 / 추진 시 고려사항
Ⅳ. 결론
```

포인트: "IT투자는 왜 일반투자와 다른가"를 개요에서 한 줄 잡아야 합니다 → **효과의 무형성·간접성·시차성(지연효과)** 때문에 정량만으로 평가 불가 → 그래서 정성평가가 필요하다는 논리흐름입니다.

### 핵심 키워드 (암기용 최소 세트)

**① 정량평가 — "투·회·순·경" (4대 기법)**

| 기법               | 원어                                             | 핵심                      |
| :--------------- | :--------------------------------------------- | :---------------------- |
| **ROI**          | Return on Investment                           | (효과-비용)/비용 × 100, 투자수익률 |
| **NPV**          | Net Present Value                              | 미래현금흐름을 현재가치로 환산해 순합산   |
| **IRR**          | Internal Rate of Return                        | NPV=0이 되는 할인율           |
| **PP**           | Payback Period                                 | 투자금 회수기간                |
| **TCO/EVA** (보조) | Total Cost of Ownership / Economic Value Added | 총소유비용, 경제적부가가치          |

→ 암기: **"ROI로 비율보고, NPV/IRR로 시간가치 반영하고, PP로 회수기간 본다"** — 3개 핵심기법 + 보조 2개 정도로 압축.

**② 정성평가 — "전·조·고·위" (4대 관점)**

| 관점              | 핵심질문                 |
| :-------------- | :------------------- |
| **전략적 적합성**     | 조직 전략·비전과의 정합성       |
| **조직/프로세스 효과**  | 업무효율화, 의사결정 개선, 협업강화 |
| **고객/이해관계자 가치** | 고객만족, 대외이미지, 서비스품질   |
| **위험/리스크 감소**   | 보안강화, 규제대응, BCP 대응력  |

→ 정량이 "숫자로 증명 가능한 효과", 정성이 "숫자로 증명 어렵지만 실재하는 효과"라는 대비로 외우면 헷갈리지 않습니다.

**③ 대표 프레임워크 — 이름만 매칭 (심화 배점용)**

| 프레임                            | 특징 한 줄                        |
| :----------------------------- | :---------------------------- |
| **Val IT** (ISACA)             | IT투자 가치관리, BSC와 연계            |
| **IE (Information Economics)** | 정량+정성을 가중점수로 통합 평가            |
| **BSC 기반 IT평가**                | 4관점(재무/고객/프로세스/학습성장)에 IT효과 매핑 |

→ 앞서 다룬 BSC 답안과 여기서 연결되는 부분이니, "BSC를 IT투자평가에도 쓸 수 있다"는 한 줄만 기억하면 됩니다.

### 결론 포인트 (차별화 한 줄)

IT투자의 진짜 어려움은 **효과의 시차(time lag)와 간접성**에 있다는 점 — 투자 시점과 효과 발생 시점이 다르고, 다른 요인과 섞여서 순수 IT효과만 분리하기 어렵다(귀속효과 문제, attribution problem)는 점을 결론에 넣으면 이해도를 어필할 수 있습니다.

#### **I. \[도입] IT 투자의 불확실성 극복, IT 투자평가 및 IT-ROI 개요**

* **정의:** IT 프로젝트에 투입된 비용 대비 비즈니스 성과(수익, 전략적 기여도 등)를 정량적/정성적으로 측정하여 타당성을 검증하는 활동.
* **목적:** 맹목적인 IT 투자를 방지하고, **비즈니스 전략과 IT의 연계(Alignment)** 확인 및 자원 할당 최적화.

#### **II. \[본론 1] IT 투자평가 라이프사이클 (단계별 3분할 암기)**

평가는 한 번 하고 끝나는 것이 아님을 어필해야 점수가 오릅니다.

1. **사전 평가 (타당성 분석):** 프로젝트 착수 전, 투자 가치가 있는지 검증 (정량적 ROI 분석 위주).
2. **중간 평가 (위험 통제):** 프로젝트 진행 중, 예산 및 일정 준수 여부 통제 (EVM - 획득가치관리 활용).
3. **사후 평가 (성과 측정):** 시스템 오픈 후, 당초 예상했던 기대효과가 100% 달성되었는지 확인 (정성적 지표 병행).

#### **III. \[본론 2] 핵심 투자평가 기법 비교 (정량적 vs 정성적)**

이 문제의 핵심 채점 포인트입니다. 반드시 표(Table) 형태로 나누어 명확히 제시하세요.

**1) 정량적 평가 기법 (재무적 관점, IT-ROI 중심 4대장)**

* **ROI (투자수익률):** (누적효과 - 누적비용) / 누적비용. 비율(%)로 직관적이나 화폐의 시간가치를 무시함.
* **NPV (순현재가치):** 미래에 들어올 수익을 현재 화폐 가치로 환산해 비용을 뺀 값. **(NPV > 0 이면 투자 채택)**
* **IRR (내부수익률):** NPV를 '0'으로 만드는 이자율. **(IRR > 자본비용(기준 금리) 이면 투자 채택)**
* **PP (투자회수기간):** 투자한 원금을 회수하는 데 걸리는 시간. (짧을수록 좋음)

**2) 정성적/종합적 평가 기법 (비재무적, 전략적 관점 3대장)**

* **BSC (균형성과표):** 재무, 고객, 내부 프로세스, 학습 및 성장이라는 4가지 관점에서 균형 있게 평가.
* **실물 옵션 (Real Options):** 불확실성이 큰 IT 환경에서, 경영자의 향후 선택권(연기, 축소, 확대 옵션)의 가치까지 금액으로 산정하는 최신 기법.
* **정보경제학 (IE, Information Economics):** 전통적 ROI에 전략적 연계도, 기술적 리스크 등 무형의 가치(점수)를 가감하여 종합 평가.

#### **IV. \[결론/제언] 성공적인 IT 투자평가를 위한 핵심 제언**

* **(키워드 위주 2줄 마무리)** "성공적인 IT 투자를 위해서는 정량적 지표의 한계를 정성적 지표(BSC 등)로 보완해야 합니다. 특히 평가 자체가 목적이 되지 않도록 전사적 IT 거버넌스 체계인 **Val IT(가치 기반 IT 거버넌스)** 프레임워크와 연계하여 지속적인 성과 모니터링 체계를 구축해야 합니다."
