## Ⅰ. 개요 키워드

**IT거버넌스(IT Governance)**
이사회·경영진이 IT 전략을 수립하고 IT 투자·리스크·성과를 지속적으로 관리·통제하는 체계.
IT가 **비즈니스 목표 달성**에 기여하도록 의사결정 권한·책임을 명확히 하는 경영 메커니즘.

**정의 (ISO/IEC 38500)**
"조직의 IT 사용을 평가(Evaluate)·지시(Direct)·모니터링(Monitor)하는 시스템"

**등장배경**
- IT 투자 규모 급증 → 투자 대비 효과(IT-ROI) 검증 필요
- 엔론·월드컴 회계 부정 → SOX법(사베인스-옥슬리법) 제정 → IT 내부통제 강화
- IT 리스크(사이버 보안·시스템 장애) 경영 위협 증가
- IT와 비즈니스 전략 불일치(IT-Business Misalignment) 문제 대두

**기업 거버넌스와의 관계**
```
기업 거버넌스 (Corporate Governance)
    └── IT거버넌스 (IT Governance)  ← 기업 거버넌스의 하위 집합
            └── 정보보안 거버넌스
            └── 데이터 거버넌스
            └── AI 거버넌스
```

## Ⅱ. IT거버넌스 5대 구성요소 (COBIT 기반)

### 1. 전략적 정렬(Strategic Alignment)

**정의**
IT 전략과 비즈니스 전략을 연계해 IT 투자가 조직 목표에 기여하도록 하는 활동

**핵심 키워드**
- **IT-Business Alignment**: IT와 사업 방향의 일치
- **ISP(정보전략계획)**: 중장기 IT 방향 수립
- **EA(기업 아키텍처)**: 조직 전체 IT 구조 청사진
- **CIO 역할**: IT 전략과 경영 전략 연계 책임자
- **IT 포트폴리오 관리**: 투자 프로젝트 전략적 선정·조정

---

### 2. 가치 전달(Value Delivery)

**정의**
IT 투자가 약속된 비즈니스 가치를 실제로 창출하도록 최적화하는 활동

**핵심 키워드**
- **Val IT 프레임워크**: ISACA / IT 투자 가치 실현·관리
- **IT-ROI**: 투자수익률 / (순이익/투자비용)×100%
- **TCO(Total Cost of Ownership)**: 전 생애주기 총비용
- **NPV(순현재가치)**: 미래 효익 현재가치 환산 / NPV>0이면 투자 타당
- **IRR(내부수익률)**: NPV=0 할인율 / 자본비용 초과 시 투자 가치
- **유형적 효익**: 비용 절감·매출 증가 (수치 측정 가능)
- **무형적 효익**: 브랜드·고객 만족·의사결정 질 (수치화 어려움)

---

### 3. 리스크 관리(Risk Management)

**정의**
IT 관련 리스크를 식별·평가·통제해 조직의 손실을 예방하는 활동

**핵심 키워드**
- **IT 리스크 유형**: 운영 리스크·보안 리스크·프로젝트 리스크·컴플라이언스 리스크
- **위험관리 4단계**: 식별(Identify)→분석(Analyze)→대응(Respond)→모니터링(Monitor)
- **COSO ERM**: 전사적 리스크 관리 프레임워크
- **리스크 허용 한도(Risk Appetite)**: 조직이 수용 가능한 리스크 수준
- **BCP/DRP**: 비즈니스 연속성·재해복구 계획 / IT 리스크 대응 핵심 수단
- **RTO/RPO**: 복구 목표 시간·복구 목표 시점

---

### 4. 자원 관리(Resource Management)

**정의**
IT 인프라·애플리케이션·데이터·인력 등 IT 자원을 최적화해 효율적으로 운영하는 활동

**핵심 키워드**
- **IT 자원 4요소**: 인프라(Infrastructure)·애플리케이션(Applications)·정보(Information)·인력(People)
- **IT 역량 관리**: IT 인력의 기술·지식·역량 관리 체계
- **클라우드 자원 최적화**: FinOps / 클라우드 비용 최적화
- **IT 자산 관리(ITAM)**: HW·SW 자산 수명주기 관리
- **아웃소싱 관리**: 외부 IT 서비스 제공자 관리·SLA 기반 성과 통제

---

### 5. 성과 측정(Performance Measurement)

**정의**
IT 성과를 지속적으로 측정·모니터링해 전략 목표 달성 여부를 검증하는 활동

**핵심 키워드**
- **KPI(Key Performance Indicator)**: 핵심 성과 지표
- **KGI(Key Goal Indicator)**: 핵심 목표 지표 / 비즈니스 목표 달성 여부
- **BSC(Balanced Scorecard)**: 4관점 균형 성과 측정 → **아래 상세 기술**
- **성숙도 모델(Maturity Model)**: COBIT·CMMI 기반 IT 역량 수준 평가
- **대시보드(Dashboard)**: IT 성과 실시간 가시화 도구

## Ⅲ. 주요 프레임워크 키워드

### COBIT(Control Objectives for Information and Related Technology)

**발행**: ISACA(정보시스템감사통제협회)
**최신 버전**: COBIT 2019

**핵심 구조**
- **거버넌스 목표 5개**: EDM(평가·지시·모니터링)
- **관리 목표 35개**: APO·BAI·DSS·MEA 4개 영역
- **성숙도 레벨 0~5**: IT 프로세스 성숙도 측정

**COBIT 거버넌스 영역 (EDM)**
- **Evaluate(평가)**: IT 전략·방향·우선순위 평가
- **Direct(지시)**: 계획·정책·지시로 원하는 결과 달성
- **Monitor(모니터링)**: 목표 대비 성과 지속 감시

**COBIT 관리 영역**
- **APO(Align·Plan·Organize)**: 정렬·계획·조직
- **BAI(Build·Acquire·Implement)**: 구축·도입·구현
- **DSS(Deliver·Service·Support)**: 전달·서비스·지원
- **MEA(Monitor·Evaluate·Assess)**: 모니터링·평가·사정

---

### ITIL(Information Technology Infrastructure Library)

**발행**: AXELOS (英 정부 기원)
**최신 버전**: ITIL 4

**핵심 개념**
- **서비스 가치 시스템(SVS)**: ITIL 4의 핵심 프레임워크
- **서비스 가치 체인(SVC)**: Plan·Improve·Engage·D&T·Obtain/Build·Deliver&Support
- **4차원 모델**: 조직·정보기술·파트너·가치흐름
- **ITSM(IT Service Management)**: IT 서비스 생명주기 관리

**ITIL 거버넌스 연계**
- IT거버넌스: **무엇을(What)** 해야 하는지 방향 제시
- ITIL: **어떻게(How)** IT 서비스를 관리할지 실천 방법론

---

### ISO/IEC 38500

**정의**: IT거버넌스 국제 표준 (2008 제정·2015 개정)
**원칙 6가지**
- **책임(Responsibility)**: IT 관련 책임과 권한 명확화
- **전략(Strategy)**: IT가 조직 전략 지원
- **취득(Acquisition)**: IT 조달의 합리성·투명성
- **성과(Performance)**: IT가 현재·미래 요구 충족
- **적합성(Conformance)**: 법규·정책 준수
- **인적요인(Human Behaviour)**: IT 정책이 사람 행동 존중

---

### Val IT 프레임워크

**발행**: ISACA / COBIT 보완 프레임워크
**목적**: IT 투자 포트폴리오 관점에서 가치 실현·최적화

**3개 프로세스 도메인**
- **VG(Value Governance)**: IT 투자 거버넌스 체계 수립
- **PM(Portfolio Management)**: IT 투자 포트폴리오 관리
- **IM(Investment Management)**: 개별 IT 투자 수명주기 관리

**핵심 개념**
- **비즈니스 케이스(Business Case)**: IT 투자 정당성·예상 효익 문서
- **편익 실현(Benefits Realisation)**: 약속된 효익을 실제로 달성하는 관리 활동

## Ⅳ. 효과측정 방법론 키워드

### BSC(Balanced Scorecard) — 4관점 균형 성과측정

**개발**: Kaplan & Norton(1992)
**IT거버넌스 적용**: IT-BSC로 변형해 IT 성과 측정에 활용

**IT-BSC 4관점**

| 관점 | 질문 | 주요 KPI |
|---|---|---|
| **재무(Financial)** | IT가 재무 성과에 기여하는가? | IT-ROI·TCO·비용 절감액 |
| **고객(Customer)** | 사용자가 IT에 만족하는가? | 사용자 만족도·서비스 가용성·SLA 준수율 |
| **내부 프로세스(Internal Process)** | IT 운영 프로세스가 효율적인가? | 시스템 가동률·장애 건수·처리 시간 |
| **학습·성장(Learning & Growth)** | IT 역량을 지속 개발하는가? | IT 인력 역량 수준·교육 이수율·혁신 건수 |

**BSC 연계 구조**
```
학습·성장 → 내부 프로세스 → 고객 → 재무
(역량 축적 → 프로세스 개선 → 고객 만족 → 재무 성과)
```

---

### IT-ROI 측정 방법론

**ROI(Return on Investment)**
- **공식**: ROI = (순이익/투자비용) × 100%
- **한계**: 시간가치 미반영 / 무형 효익 누락

**재무적 성과 측정 기법**

| 기법 | 내용 | 특징 |
|---|---|---|
| **ROI** | 투자수익률 | 단순·직관적 / 시간가치 미반영 |
| **NPV** | 순현재가치 | 시간가치 반영 / 할인율 선정 주관적 |
| **IRR** | 내부수익률 | 비율 비교 용이 / 복수해 가능 |
| **PP** | 투자회수기간 | 유동성 파악 / 회수 후 효익 무시 |
| **EVA** | 경제적 부가가치 | 자본비용 차감 후 실질 가치 측정 |

**유형적 효익 vs 무형적 효익**

| 구분 | 내용 | 측정 방법 |
|---|---|---|
| **유형적(Tangible)** | 인건비 절감·처리 속도 향상·오류 감소 | 직접 수치화 가능 |
| **무형적(Intangible)** | 브랜드 가치·의사결정 질·직원 역량 | 간접 지표로 추정 |

---

### COBIT 성숙도 모델 (Maturity Model)

**목적**: IT 프로세스의 현재 수준 진단 및 목표 수준 설정

| 레벨 | 명칭 | 특징 |
|---|---|---|
| **0** | 존재하지 않음(Non-existent) | IT 프로세스 인식조차 없음 |
| **1** | 초기(Initial) | 임시방편적·비정형화 |
| **2** | 반복 가능(Repeatable) | 유사 절차 존재하나 비표준화 |
| **3** | 정의됨(Defined) | 표준화·문서화 완료 |
| **4** | 관리됨(Managed) | 측정·모니터링 체계 구축 |
| **5** | 최적화(Optimized) | 지속적 개선·모범 사례 적용 |

---

### 정보화 투자 성과 측정 기법 (119회 관리 2교시 기출)

**품질 지표 (Quality Indicator)**
- 시스템 가용성(Availability)·응답 시간·오류율·정확성
- 사용자 만족도(CSAT)·SLA 준수율

**이용 지표 (Usage Indicator)**
- 사용자 수·트랜잭션 건수·페이지 뷰·활성 사용자(DAU·MAU)
- 서비스 이용 증가율·채널 전환율

**효과 지표 (Effect Indicator)**
- 업무 처리 시간 단축율·비용 절감액·매출 증가 기여도
- 디지털 전환(DX) 목표 달성율·프로세스 개선 효율

---

### OECD IT 투자 성과 측정 5단계 (119회 관리 2교시 연계)

```
1단계: IT 투자 식별 → IT 지출 항목 명확화
2단계: IT 자산 분류 → HW·SW·서비스 분류
3단계: IT 산출 측정 → 서비스 수준·기능 산출물
4단계: IT 생산성 측정 → 투입 대비 산출 비율
5단계: IT 경제적 효과 측정 → GDP·생산성 기여도
```

## Ⅴ. IT거버넌스 vs 기업 거버넌스 비교

| 구분 | 기업 거버넌스 | IT거버넌스 |
|---|---|---|
| **범위** | 조직 전체 경영 통제 | IT 관련 의사결정·통제 |
| **주체** | 이사회·주주 | CIO·IT 위원회·이사회 |
| **목적** | 주주 가치 극대화 | IT-비즈니스 정렬·가치 창출 |
| **도구** | 재무제표·감사·이사회 | COBIT·ITIL·BSC·ISO 38500 |
| **리스크** | 재무·법적·시장 리스크 | IT 운영·보안·프로젝트 리스크 |
| **성과측정** | EPS·ROE·매출 | IT-ROI·SLA·시스템 가동률 |
| **관계** | 상위 체계 | 하위 구성요소 (부분집합) |

## Ⅵ. 도입 시 고려사항 및 발전 방향

**도입 시 고려사항**

**최고경영층 지원(Top Management Support)**
IT거버넌스는 CIO 혼자 추진 불가. 이사회·CEO의 적극적 지원과 의지가 전제.

**IT거버넌스 위원회 구성**
IT 의사결정을 위한 공식 위원회 설치. CIO·CFO·사업부장·외부 전문가 참여.

**단계적 도입(Phased Approach)**
전체 영역 동시 도입은 저항 유발. 5대 구성요소 중 우선순위 도메인부터 시작.

**성숙도 기반 개선(Maturity-based Improvement)**
현재 성숙도(As-Is) 진단 → 목표 성숙도(To-Be) 설정 → 단계별 개선 로드맵 수립.

**발전 방향**

**AI 거버넌스 통합**
AI 시스템의 윤리·리스크·성과를 IT거버넌스 체계에 통합. 인공지능기본법의 고영향 AI 관리 연계.

**클라우드 거버넌스**
멀티클라우드 환경에서 비용·보안·성과 통제. FinOps·CSPM 도구 활용.

**자동화·AI 기반 거버넌스(AIOps)**
IT 성과 모니터링·리스크 탐지·성숙도 평가를 AI로 자동화하는 차세대 거버넌스 방향.

---

## 📌 1교시 암기 체크리스트

- [ ] IT거버넌스 정의: ISO/IEC 38500 — 평가·지시·모니터링
- [ ] **5대 구성요소**: 전략적 정렬 / 가치 전달 / 리스크 관리 / 자원 관리 / 성과 측정
- [ ] COBIT: ISACA / EDM(평가·지시·모니터링) / APO·BAI·DSS·MEA
- [ ] ITIL: AXELOS / 서비스 가치 시스템(SVS) / 서비스 가치 체인(SVC)
- [ ] ISO/IEC 38500: 6원칙 (책임·전략·취득·성과·적합성·인적요인)
- [ ] Val IT: 가치 거버넌스·포트폴리오 관리·투자 관리 / 편익 실현
- [ ] IT-BSC 4관점: 재무 / 고객 / 내부 프로세스 / 학습·성장
- [ ] COBIT 성숙도 0~5: 존재않음→초기→반복→정의→관리→최적화
- [ ] ROI·NPV·IRR·PP·EVA: 재무적 효과 측정 5대 기법
- [ ] 정보화 투자 성과 3대 지표: 품질·이용·효과
- [ ] 유형적 효익(수치화 가능) vs 무형적 효익(간접 추정)
- [ ] IT거버넌스 ⊂ 기업 거버넌스 (하위 구성요소)
