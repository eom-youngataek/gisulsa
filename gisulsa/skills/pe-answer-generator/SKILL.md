# PE 답안 생성 스킬 (pe-answer-generator)

## 목적

정보처리기술사 채점 기준(정의 정확성 · 핵심 키워드 포함 · 논리적 전개 · 최신성)을 만족하는 4단락 모범답안을 표준화된 형식으로 생성한다.

## 표준 전개 구조

도메인/키워드 유형에 따라 아래 표준 전개를 기본으로 하되, 유형별로 3번째 단락의 성격이 달라진다.

| 유형                       | Ⅰ. 개요/배경    | Ⅱ. 핵심기술/구성요소 | Ⅲ. (유형별 상이)  | Ⅳ. 고려사항/발전방향 |
| ------------------------ | ----------- | ------------ | ------------ | ------------ |
| 관리/거버넌스 계열 (경영정보시스템)     | 정의·필요성·등장배경 | 구성요소·프레임워크   | 수립/이행 절차     | 성공요인·제언      |
| 프로토콜/아키텍처 계열 (네트워크,SW공학) | 정의·등장배경     | 계층/구성요소      | 동작 메커니즘·알고리즘 | 도입효과·발전방향    |
| 데이터/DB 계열                | 정의·특성       | 유형/분류        | 처리 절차·수식     | 실무 적용 고려사항   |
| 보안 계열                    | 위협/필요성      | 핵심 원칙·구성요소   | 대응/구현 절차     | 도입전략·한계      |
| AI/통계 계열                 | 등장배경·문제의식   | 핵심 알고리즘/구조   | 동작 과정·수식     | 한계·발전전망      |

## 실행 절차

1. 입력 키워드와 mainDomain/subDomain을 확인한다.
2. `141회핵심키워드/<도메인>/` 폴더에 관련 원본 노트가 있으면 우선 반영한다 (표, 비유, "암기:" 문구를 재활용).
3. 위 표에서 도메인에 맞는 전개 구조를 선택해 4개 단락을 작성한다. 각 단락은 반드시 로마숫자 헤더(Ⅰ\~Ⅳ)로 시작한다.
4. 채점 포인트가 되는 고유명사·수식·비교표는 굵게 강조하거나 표로 정리한다.
5. `pe-mnemonic-creator` 스킬을 호출해 2줄 암기 스토리를 덧붙인다.
6. 최종 산출물은 KEYWORD\_DATABASE 스키마(`id, mainDomain, subDomain, keyword, examHistory, isPredicted, source, mnemonic, questionType, structured:true, solution:{section1..4}, questionText`)에 맞춰 JSON으로 반환한다.

## 품질 체크리스트

* [x] 각 단락이 로마숫자 헤더로 시작하는가
* [x] 채점 기준상 핵심 키워드(고유명사, 표준번호, 수식)가 최소 3개 이상 포함되는가
* [x] Ⅲ단락에 절차/알고리즘/수식 등 "How"가 구체적으로 기술되는가
* [x] Ⅳ단락에 최신 동향 또는 실무 고려사항이 포함되는가
