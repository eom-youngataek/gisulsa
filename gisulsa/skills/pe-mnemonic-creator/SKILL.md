# PE 암기 스토리 생성 스킬 (pe-mnemonic-creator)

## 목적
채점 기준상 반드시 포함되어야 하는 기술 키워드(구성요소 3~5개)를 시험장에서 즉시 떠올릴 수 있도록 2줄 이내의 스토리 또는 두음자로 압축한다.

## 생성 규칙
1. 답안의 Ⅱ단락(핵심기술/구성요소)에서 채점 포인트가 되는 용어 3~5개를 추출한다.
2. 각 용어의 첫 글자(두음) 또는 핵심 음절을 뽑아 자연스러운 한 문장으로 연결한다.
   - 예: SDN → "[분-중-오-스] 제어부와 전달부를 분리하여 중앙 컨트롤러가 OpenFlow로 스위치를 통제한다!"
3. 가능하면 인과관계·순서가 드러나는 스토리 문장으로 구성한다 (단순 나열보다 기억에 오래 남음).
4. 이모지 🔑 를 접두어로 사용하고, 전체 길이는 2줄(약 100~140자) 이내로 제한한다.
5. `141회핵심키워드/` 폴더의 원본 노트에 이미 "암기:", "→ 암기" 로 시작하는 문장이 있으면 그것을 우선 재사용/다듬는다 (이미 검증된 압축 표현인 경우가 많음).

## 출력 형식
```
🔑 [두음 또는 핵심어 나열] 스토리 문장 (필요시 " / "로 구분해 2번째 힌트 추가)
```

## 예시
- ACID: 🔑 [원-일-고-영] 원자성으로 all-or-nothing, 일관성 유지, 고립성으로 간섭 차단, 영속성으로 커밋 보존!
- 세마포어 vs 뮤텍스: 🔑 [뮤-소-세-카] 뮤텍스는 소유권 기반 바이너리 락이고, 세마포어는 카운터 기반 공유 자원 열쇠다!
- Zero Trust: 🔑 [절-검-최-소] 절대로 신뢰하지 말고 항상 검증하며 최소 권한 원칙을 적용한다!
