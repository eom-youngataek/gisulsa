# PE 무작위 모의고사 조합 스킬 (pe-mock-exam-builder)

## 목적
사용자가 실전과 유사한 긴장감으로 연습할 수 있도록, 실제 기출 + 최신 미출제 예상문제를 비율에 맞춰 무작위로 조합한 문제지를 생성한다. 웹사이트의 `app.js > generateExamPaper()` 가 동일한 로직을 클라이언트에서 수행한다.

## 조합 규칙
### 1교시형 (10점, 10문항)
- 실제 기출(QUESTION_BANK 중 session=="1교시") 6문항
- 예상/기출연계 키워드(KEYWORD_DATABASE 중 questionType=="1교시형") 4문항
- 항목당 배점 10점, 단답형(정의·비교·나열 위주)

### 2~4교시형 (25점, 4문항)
- 실제 기출(QUESTION_BANK 중 session!="1교시") 2문항
- 예상/기출연계 키워드(questionType=="2~4교시형") 2문항
- 항목당 배점 25점, 서술형("가.나.다" 하위문항 구조 권장)

## 실행 절차
1. `gisulsa/scripts/build_output/question_bank.json` 과 사이트 루트 `data.js`(KEYWORD_DATABASE) 를 로드한다.
2. 위 비율대로 무작위 추출한다 (매 실행마다 셔플).
3. 각 문항에 출처 태그를 붙인다: `기출`(실제 120~139회) / `기출연계`(자동 매칭된 원본노트) / `예상`(미출제 신규).
4. 문제지 상단에 회차·배점·구성을 표기하고, 항목을 실제 시험지처럼 번호를 매겨 출력한다.

## 확장 아이디어
- 특정 도메인만 선택해 도메인 집중 모의고사 구성 (예: "정보보안 도메인 2~4교시형만")
- 최근 3개 회차(137~139회)에 출제된 도메인을 제외하고 조합해 "다음 회차 예상" 정확도를 높이는 옵션
- `pe_reviewer` 스킬과 연계해 생성된 문제의 난이도를 검수
