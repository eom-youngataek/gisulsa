# 정보처리기술사 멀티에이전트 하네스 엔지니어링 패키지 (gisulsa)

본 디렉토리는 30년차 정보처리기술사 노하우를 체계화하여 \*\*120회\~139회 기출문제(991문항)**와 141회핵심키워드 폴더의 자체 학습노트(527건)**, 그리고 \*\*최신 미출제 IT 동향(전자신문, ITFIND, 주간기술동향, 위키독스 등)을 바탕으로 모범답안 생성·출제·검수·암기 스토리 생성을 자동화하는 **멀티에이전트 하네스(Multi-Agent Harness)** 체계입니다.

사이트(정적 웹사이트: `index.html` / `app.js` / `data.js` / `style.css`)는 이 하네스가 생성한 `data.js` 를 그대로 읽어 화면에 렌더링합니다. 즉 `gisulsa/`는 **콘텐츠 공장**이고, 사이트 루트의 HTML/CSS/JS는 **진열대**입니다.

***

## 1. 디렉토리 구조

```text
gisulsa/
├── README.md                          # 하네스 전체 가이드 (본 파일)
├── agents/                            # 역할별 멀티에이전트 정의 (LLM 에이전트 프롬프트/스키마)
│   ├── pe_solution_architect.json     # 모범답안 작성 전문 에이전트
│   ├── pe_question_creator.json       # 출제위원 에이전트 (1교시/2~4교시)
│   ├── pe_trend_analyst.json          # 최신 IT동향 분석 에이전트
│   └── pe_reviewer.json               # 30년차 기술사 검수 에이전트
├── skills/                            # 재사용 가능한 기술사 작업 스킬 (SKILL.md)
│   ├── pe-answer-generator/SKILL.md   # 4단락 기술사 모범답안 생성 스킬
│   ├── pe-mnemonic-creator/SKILL.md   # 2줄 암기 스토리/두음 생성 스킬
│   └── pe-mock-exam-builder/SKILL.md  # 회차별/도메인별 무작위 모의고사 조합 스킬
└── scripts/                           # 결정적(deterministic) 데이터 파이프라인 - data.js 생성기
    ├── run_all.sh                     # 0~4단계 전체 재실행 스크립트
    ├── 00_parse_exam_questions.py     # 120~139회 기출문제 md → questions_raw.json (991문항)
    ├── 01_parse_domains.py            # 7개 도메인 폴더(364) + 141회예상문제 폴더(163) 파싱/분류
    ├── 02_classify_and_tag.py         # 기출문제 도메인 자동분류 + 기출/예상 대조 태깅
    ├── 03_finalize_and_tag.py         # questionType/examHistory/source 등 최종 필드 확정
    ├── 04_assemble_data_js.py         # curated_keywords.json + 자동수집 결과 → 사이트 루트 data.js
    ├── classify.py                    # 도메인/하위도메인 분류 규칙, 예외 오버라이드 테이블
    ├── parse_utils.py                 # 마크다운 파싱 유틸(제목/암기문장 추출, 토큰화 등)
    └── curated_keywords.json          # 수작업으로 정예 작성한 답안 17건 (구조형 4단락, 시드 데이터)
```

## 2. 데이터 파이프라인 동작 원리

1. **00단계**: `정보처리기술사_120~139회 기출문제.md`(학원 모의고사·기출 합본)를 정규식으로 파싱해 회차/종목(관리·응용)/교시/문항번호/본문을 구조화한다.
2. **1단계**: `경영정보시스템/`, `네트워크/`, ... 7개 도메인 폴더의 학습노트(.md)와
   `141회예상문제/` 폴더(최신 트렌드 조사 노트)를 파싱한다. 각 파일의 제목은 "답안 전개 스토리" 같은 메타 문구가 아니라 실제 키워드명이 오도록 정제하고, 파일명/본문 토큰을 이용해 7대 대분류 및 세부 하위도메인(예: "5.4 암호화")을 자동 분류한다. 신조어/표준명은 `classify.py`의 오버라이드 테이블로 보정한다.
3. **2단계**: 0단계에서 만든 991문항 기출 뱅크와 1단계 키워드 목록을 토큰 overlap + 핵심어 부분일치로 상호 대조한다. 실제 기출에서 발견되면 `isPredicted:false`와 출제회차(examHistory)를 부여하고, 발견되지 않으면 `isPredicted:true`(미출제 예상)로 태깅한다.
4. **3단계**: 매칭된 문항의 교시(1교시/2~4교시)를 참고해 `questionType`을 확정하고, 출처 문구(`실제 기출문제`, `핵심키워드 정리 노트`, `전자신문·IT FIND·주간기술동향·위키독스 조사`)를 채운다.
5. **4단계**: 수작업 정예 답안 17건(`curated_keywords.json`, 구조형 4단락)과 자동 수집 527건을 병합하여 사이트 루트의 `data.js`(KEYWORD\_DATABASE 544건 + QUESTION\_BANK 991건)를 생성한다.

전체 재실행:

```bash
cd gisulsa/scripts
bash run_all.sh
```

## 3. 에이전트 역할 사양 (Agent Roles) - LLM 기반 콘텐츠 보강용

| 에이전트 ID                 | 역할 (Role)        | 주요 임무 (Main Tasks)                                                                                |
| :---------------------- | :--------------- | :------------------------------------------------------------------------------------------------ |
| `pe_solution_architect` | 모범답안 솔루션 아키텍트    | Ⅰ.개요 - Ⅱ.핵심기술/구성요소 - Ⅲ.구축절차/알고리즘 - Ⅳ.활용사례 및 고려사항 구조화 답안 작성. `structured:false`(원본노트) 항목을 구조형으로 승격 |
| `pe_question_creator`   | 출제위원 에이전트        | 120~~139회 출제경향 분석 + 최신 미출제 예상문제(1교시 10점, 2~~4교시 25점) 출제                                           |
| `pe_trend_analyst`      | 최신 IT동향 연구 에이전트  | 주간기술동향, IT FIND, 위키독스, 전자신문 연재 기사 분석 및 신규 기술 키워드 추출                                               |
| `pe_reviewer`           | 30년차 최고기술위원 에이전트 | 키워드 포함여부, 두음 암기 유효성, 채점기준표에 따른 답안 완성도 검수 및 감점요인 피드백. `structured:false` 항목의 승격 우선순위 산정            |

파이프라인(`scripts/`)이 만드는 것은 **데이터 골격**(도메인 분류, 기출 대조, 원본노트 수집)이고, 위 4개 에이전트는 그 골격 위에서 **콘텐츠 품질을 계속 끌어올리는** 역할을 합니다. 현재 KEYWORD\_DATABASE 544건 중 17건(수작업 curated)만 4단락 구조형이며, 나머지 527건은 `structured:false` + 원본 학습노트(`rawContent`) 상태입니다. `pe_reviewer` → `pe_solution_architect `순서로 실행하면 우선순위가 높은 항목부터 구조형 답안으로 승격시킬 수 있습니다.

***

## 4. 핵심 스킬 (Custom Skills)

* `pe-answer-generator`: 기술사 4단락 구성 표준을 준수하는 고득점 답안 템플릿 적용 스킬
* `pe-mnemonic-creator`: 기술키워드가 스토리가 되도록 2줄 이내 암기 팁(두음 포함) 생성 스킬
* `pe-mock-exam-builder`: 1교시(10점형 10문제) / 2\~4교시(25점형 4문제) 무작위 예상문제 조합 스킬 (웹사이트의 "무작위 모의고사 생성기" 버튼과 동일 로직)

## 6. 향후 보강 가이드

1. `141회핵심키워드/` 폴더에 새 학습노트(.md)를 추가하면 `run_all.sh` 재실행만으로 자동 반영됩니다.
2. 신조어/표준명이 도메인 자동분류에 실패하면 `classify.py`의 `PRED_OVERRIDE`/`SUBDOMAIN_RULES`에 한 줄만 추가하면 됩니다.
3. `pe_reviewer` 에이전트로 `structured:false` 항목(자동수집 527건)을 우선순위별로 훑고, `pe_solution_architect`로 구조형 4단락 답안으로 순차 승격시키는 것을 권장합니다.
4. 다음 회차(141회 등) 대비 신규 트렌드는 `pe_trend_analyst` 에이전트로 전자신문/IT FIND/주간기술동향/위키독스를 정기 스캔하고, `pe_question_creator`로 예상문제를 만들어 `curated_keywords.json` 또는 해당 도메인 폴더에 새 노트로 추가하십시오.
