## Q01. 시큐어코딩(Secure Coding) / SAST·DAST [공통][1교·2교]

### 답안 전개 방식
```
Ⅰ. 시큐어코딩 개요 (등장배경·정의)
Ⅱ. SAST 동작원리 및 절차
Ⅲ. DAST 동작원리 및 절차
Ⅳ. SAST vs DAST 비교표
Ⅴ. SDLC 단계별 적용 방안
Ⅵ. 한계점 및 보완 방향 (IAST·DevSecOps)
```

### 핵심 키워드
- **시큐어코딩**: SW 개발 단계 보안 내재화 / 행안부 소프트웨어 개발보안 가이드
- **SAST**: 소스코드 정적 분석 / 실행 없이 / 개발·빌드 단계 / SQL Injection·버퍼오버플로우
- **DAST**: 실행 중 동적 분석 / 외부 공격 방식 / 테스트·운영 단계 / 인증오류·서버설정 오류
- **도구**: SAST(SonarQube·Fortify·Checkmarx) / DAST(OWASP ZAP·Burp Suite·AppScan)
- **IAST**: 런타임 계측 방식 / 두 방식 장점 결합
- **SCA**: 오픈소스 라이브러리 취약점 분석
- **False Positive**: SAST 한계 / 수동 검토 필요

| 구분     | SAST                    | DAST          |
| ------ | ----------------------- | ------------- |
| 분석 대상  | 소스코드·바이너리               | 실행 중 애플리케이션   |
| 수행 시점  | 개발·빌드 단계                | 테스트·운영 단계     |
| 탐지 취약점 | SQL Injection·하드코딩 크리덴셜 | 인증오류·런타임 인젝션  |
| 장점     | 조기 발견·코드 위치 특정          | 실제 공격 시나리오 검증 |
| 단점     | False Positive 多        | 늦은 발견·커버리지 의존 |
|        |                         |               |

## Q13. 데이터 어노테이션(Data Annotation) [관][1교·2교]

### 핵심 키워드
- **어노테이션(Annotation)**: 원시 데이터에 레이블·태그 부착
- **그라운드 트루스(Ground Truth)**: 정답 데이터·모델 성능 상한선
- **바운딩 박스(Bounding Box)** / **시맨틱 세그멘테이션**
- **Inter-Annotator Agreement(IAA)**: Cohen's Kappa / Fleiss' Kappa
- **코헨의 카파**: 0.8 이상(매우 높음) / 0.6~0.8(상당) / 0.4 미만(낮음)
- **골든 셋(Golden Set)**: 정답 확정 검증 데이터셋
- **액티브 러닝(Active Learning)**: 불확실 샘플 우선 레이블링
- **약지도 학습(Weak Supervision)**: 노이즈 레이블 활용
- **RLHF**: 인간 피드백 강화학습 / LLM 정렬

## Q14. 합성데이터(Synthetic Data) [관][2교·3교]

```
Ⅰ. 합성데이터 개요 및 생성 목적

Ⅲ. 품질 평가 지표 (충실도·다양성·유용성)
Ⅳ. 프라이버시 보호 기법 (k-익명성·차분 프라이버시)
Ⅴ. 도메인별 활용
```

### 핵심 키워드
**생성 기법**
- **SMOTE**: 소수 클래스 보간 / 클래스 불균형 해소
- **CTGAN**: 표형 데이터 특화 GAN
- **VAE**: 연속 잠재 공간 / 다양성 확보
- **Diffusion Model**: 고품질·다양성 / 최신 주류

**품질 평가**
- **충실도(Fidelity)**: 통계 분포 재현
- **다양성(Diversity)**: 패턴 포괄
- **유용성(Utility)**: TSTR(Train on Synthetic Test on Real)

**프라이버시 보호**
- **k-익명성**: 준식별자 k개 이상 동일 레코드
- **l-다양성**: 민감 속성 l개 이상 다양
- **t-근접성**: 민감 속성 분포 거리 t 이하
- **차분 프라이버시(DP)**: ε 기반 수학적 보장

## Q42. PQC vs QKD 비교 [관][2교·3교]

| 구분 | PQC | QKD |

## Q53. VAE(Variational Autoencoder) [공][2교·3교] (생성모델 비교 기출)

### 핵심 키워드
- **변분 추론(Variational Inference)**: 사후 분포 p(z|x)를 q(z|x)로 근사
- **재매개변수화 트릭(Reparameterization Trick)**: z=μ+σ·ε / 역전파 가능화
- **ELBO**: E[log p(x|z)] - KL(q(z|x)||p(z))
- **재구성 손실(Reconstruction Loss)**: 디코더 품질 / MSE or BCE
- **KL 발산**: KL = -½Σ(1+log σ²-μ²-σ²) / 잠재공간 정규화
- **연속 잠재 공간**: 의미적 보간 가능 / 잠재공간 산술 연산
- **흐릿함(Blur)**: MSE 최적화로 평균값 생성 / GAN·Diffusion 대비 단점
- **사후 붕괴(Posterior Collapse)**: q(z|x)→N(0,I) 수렴 / z가 정보 미전달
- **β-VAE**: KL 가중치 β>1 / 분리 표현(Disentangled) 학습
- **VQ-VAE**: 이산 코드북 양자화 / DALL-E 1 기반
- **Latent Diffusion Model**: VAE 인코더-디코더가 Stable Diffusion 압축 모듈

## Q54. GAN(Generative Adversarial Network) [공][2교·3교]

### 핵심 키워드
- **Goodfellow et al.(2014)**: 최초 제안
- **생성자(Generator)**: z→G(z) 생성 / D(G(z))→1 목표
- **판별자(Discriminator)**: 진짜/가짜 분류 / D(x)→1·D(G(z))→0 목표
- **미니맥스 목적함수**: min_G max_D [E[log D(x)] + E[log(1-D(G(z)))]]
- **비포화 손실(Non-saturating)**: L_G = -E[log D(G(z))] / 초기 그래디언트 강화
- **내쉬 균형(Nash Equilibrium)**: p_G=p_data / D(x)=0.5 / 이론적 수렴 목표
- **모드 붕괴(Mode Collapse)**: 다양성 부족 / WGAN으로 이론적 해결
- **교대 학습(Alternating Training)**: D k스텝 → G 1스텝
- **WGAN**: Wasserstein 거리 / Lipschitz 제약 / 모드 붕괴 해결
- **StyleGAN**: AdaIN / 계층별 스타일 제어

## Q55. DCGAN [응][1교] (GAN 변형)

### 핵심 키워드
**4대 설계 원칙**
1. **풀링 레이어 제거**: 스트라이드 합성곱(D) + 전치 합성곱(G)
2. **완전연결층 제거**: 전역 평균 풀링으로 대체
3. **배치 정규화 전층 적용**: G 출력층·D 입력층 제외
4. **ReLU·LeakyReLU**: G 은닉층 ReLU·출력층 Tanh / D 전층 LeakyReLU(α=0.2)

**핵심 키워드**
- **전치 합성곱(ConvTranspose)**: 업샘플링 / 4×4→64×64 점진적 확대
- **스트라이드 합성곱(Strided Conv)**: 다운샘플링 / 풀링 대체
- **잠재공간 보간(Latent Space Interpolation)**: 의미적 연속 변환 증명
- **체커보드 아티팩트**: ConvTranspose 오버랩 / 업샘플링+일반 Conv로 해결

## Q56. Diffusion Model [공][2교·3교]

### 핵심 키워드
- **정방향 과정(Forward)**: 가우시안 노이즈 T스텝 추가 / 마르코프 체인
- **역방향 과정(Reverse)**: U-Net이 노이즈 예측·제거 / 데이터 생성
- **노이즈 스케줄**: 선형·코사인·시그모이드 / 코사인이 이미지에 우수
- **손실함수**: L = E[||ε - ε_θ(xₜ,t)||²]
- **DDPM**: Ho et al.(2020) / 1000 스텝 / 실용화 이정표
- **DDIM**: 결정론적 샘플링 / 10~50 스텝으로 단축
- **CFG(Classifier-Free Guidance)**: 조건부·비조건부 선형 결합 / 품질-다양성 조절
- **Stable Diffusion**: 잠재 확산(Latent) + CLIP 텍스트 인코더 / 오픈소스
- **DiT(Diffusion Transformer)**: ViT 기반 / Sora·SD3 기반 / 스케일링 법칙 적용

| 구분 | VAE | GAN | Diffusion |
|---|---|---|---|
| 학습 방식 | ELBO 최적화 | 적대적 학습 | 노이즈 예측 MSE |
| 생성 품질 | 낮음(흐릿) | 높음(선명) | 매우 높음 |
| 안정성 | 안정적 | 불안정 | 안정적 |
| 샘플링 | 빠름 | 빠름 | 느림 |

## Q57. GNN(Graph Neural Network) [공][1교·2교]

### 핵심 키워드
- **메시지 패싱(Message Passing)**: 이웃 노드→집계→결합→갱신 3단계
- **집계 함수(Aggregation)**: Sum·Mean·Max·Attention 가중합
- **노드 임베딩(Node Embedding)**: 그래프 구조+노드 특징+이웃 관계 반영
- **GCN**: 라플라시안 기반 / 스펙트럴 / Kipf & Welling(2017)
- **GAT**: 어텐션 가중치 / 중요 이웃 집중 / Veličković(2018)
- **GraphSAGE**: 이웃 샘플링 / 귀납적 학습 / 대규모 그래프
- **GIN**: Weisfeiler-Lehman 동치 / 이론적 최고 표현력
- **과평활화(Over-Smoothing)**: 깊은 층→노드 표현 유사화
- **과압축(Over-Squashing)**: 장거리 정보 손실 / Graph Transformer로 극복

## Q58. 그래디언트 소실(Vanishing Gradient) [응][1교]

### 핵심 키워드
- **역전파(Backpropagation)**: 연쇄법칙(Chain Rule)으로 기울기 계산
- **시그모이드 최대 미분값 0.25**: 10층에서 (0.25)¹⁰ ≈ 0.000001
- **포화(Saturation)**: 입력 절댓값 클 때 미분값→0
- **Dead Neuron**: ReLU 음수 구간 미분=0 / Leaky ReLU로 완화
- **해결책**:
  - **ReLU**: 양수 구간 미분=1 / 소실 차단
  - **Xavier 초기화**: Var(W)=2/(n_in+n_out) / tanh·Sigmoid용
  - **He 초기화**: Var(W)=2/n_in / ReLU용
  - **잔차 연결(ResNet)**: F(x)+x / 지름길로 그래디언트 직접 전달
  - **LSTM**: 셀 상태 선형 경로 / 그래디언트 하이웨이
  - **배치 정규화**: 활성값 정규화 / 포화 구간 진입 방지
- **그래디언트 폭주**: 반대 현상 / 그래디언트 클리핑으로 대응
