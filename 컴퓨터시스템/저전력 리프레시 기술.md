### **DRAM 저전력 설계 핵심: 누설 전류 차단과 저전력 리프레시 기술**

***

#### 답안 전체 스토리 흐름 (목차)

```
Ⅰ. 개요 (왜 DRAM 리프레시가 전력 소비의 핵심인가)
Ⅱ. DRAM 누설 전류 발생 원리
Ⅲ. 저전력 리프레시 핵심 기술
Ⅳ. 결론
```

포인트: 개요에서 \*\*"앞서 다룬 HBM4·CXL이 '메모리 대역폭과 연결성 혁신'이라면, DRAM 저전력 리프레시 기술은 메모리 셀의 본질적 한계인 '커패시터 전하 누설'을 극복하는 소자 수준의 전력 혁신이다 — DRAM은 1T1C(트랜지스터 1개·커패시터 1개) 구조로 커패시터에 전하를 저장해 데이터를 유지하나 누설 전류로 전하가 자연 소멸하므로 주기적 리프레시가 필수이며, 이 리프레시가 전체 DRAM 소비전력의 30\~40%를 차지하는 핵심 전력 낭비 원인으로 앞서 다룬 AI 데이터센터 PUE 최적화·온디바이스 AI·모바일 배터리 수명과 직결되는 저전력 설계의 핵심 과제"\*\*라는 한 줄로 시작하면 전체 맥락이 드러납니다.

#### Ⅱ. DRAM 누설 전류 발생 원리

**가. DRAM 1T1C 셀 구조와 누설 경로**

```
[DRAM 셀 구조 및 누설 전류 경로]

워드라인(WL)
     │
  ┌──┴──┐
  │NMOS │  ← 액세스 트랜지스터
  │  T  │
  └──┬──┘
     │
  ┌──┴──────┐
  │커패시터  │  ← 전하 저장 (1=충전·0=방전)
  │    C    │
  └─────────┘

누설 전류 3대 경로:
①접합 누설(Junction Leakage): PN 접합 역방향 누설
②게이트 유도 드레인 누설(GIDL): 게이트-드레인 겹침 구간
③서브임계 누설(Subthreshold): 트랜지스터 OFF 상태 미세 전류

→ 3경로 누설 합산 → 커패시터 전하 소멸
→ 데이터 유지 한계: 64ms (JEDEC 표준)
→ 64ms마다 전체 셀 리프레시 필수
```

***

**나. 누설 전류·리프레시 전력 문제**

| 항목          | 내용                           | 영향                  |
| :---------- | :--------------------------- | :------------------ |
| **리프레시 주기** | JEDEC 표준 64ms / 온도 상승 시 32ms | 고온 환경 리프레시 2배 증가    |
| **리프레시 전력** | 전체 DRAM 소비전력의 30\~40%        | AI 서버·모바일 배터리 직접 영향 |
| **리프레시 지연** | tRFC(리프레시 사이클 시간) 동안 접근 불가   | 성능 저하·지연 발생         |
| **온도 의존성**  | 온도↑ → 누설↑ → 리프레시 주기 단축       | HPC·AI 서버 고온 환경 심화  |

#### Ⅲ. 저전력 리프레시 핵심 기술

**가. 핵심 기술 체계**

| **핵심 척도**  | **📊 리프레시 최적화 🚨**                                                                                                                                              | **🔑 누설 차단 소자 기술 🚨**                                                                                 | **🏁 시스템 레벨 전력 관리 💯**                                                                                                 |
| :--------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------- |
| **핵심 기술**  | **PASR(Partial Array Self Refresh)**: 실제 사용 영역만 선택 리프레시 / 미사용 뱅크 리프레시 생략 / 모바일 DRAM 최대 70% 전력 절감                                                                | **매립형 게이트(Buried Gate)**: 트랜지스터 게이트를 실리콘 내부에 매립 / GIDL·서브임계 누설 대폭 감소 / 삼성·SK하이닉스 10nm급 이하 표준 적용       | **온도 보상 리프레시(TCSR)**: 온도 센서 내장·온도별 리프레시 주기 자동 조절 / 저온 시 리프레시 주기 연장(128ms↑) / 앞서 다룬 **AI 서버 열관리** 연계                    |
| **세부 구현**  | **DSR(Deep Sleep Refresh)**: 대기 모드에서 최소 뱅크만 리프레시 / **TRR(Targeted Row Refresh)**: 로해머 공격 대응 + 불필요 리프레시 제거 / **Variable Refresh Rate**: 셀별 리텐션 특성 측정·최적 주기 개별 설정 | **High-K 유전체 커패시터**: 커패시턴스↑ → 전하 저장 밀도↑ / ZrO2·HfO2 적용 / 동일 면적 더 많은 전하 저장→리프레시 주기 연장                  | **LPDDR5·LPDDR5X**: 앞서 다룬 **온디바이스 AI** 모바일 최적화 / 리프레시 전력 LPDDR4X 대비 20%↓ / 셀프 리프레시 전류(IDD6) 최소화                        |
| **HBM 연계** | 앞서 다룬 **HBM4**: 16단 적층 → 전체 스택 리프레시 동기화 / 스택 내 TSV 기반 리프레시 제어 / 온도 구배에 따른 층별 차등 리프레시                                                                            | **3D DRAM(CFET·VCT)**: 수직 채널 트랜지스터 / 채널 길이 증가→서브임계 누설↓ / 삼성 4F² DRAM / 앞서 다룬 **CXL 메모리** 풀링 전력 최적화 연계 | **RAS(Reliability·Availability·Serviceability)**: 리프레시 오류 감지·ECC 연계 / 리프레시 실패 셀 격리 / 앞서 다룬 **ARIES 회복**과 유사한 데이터 안전 철학 |

**나. 저전력 리프레시 기술 도식화**

```
[리프레시 전력 최적화 전략 계층]

소자 레벨 (누설 차단):
  매립형 게이트 → GIDL·서브임계 누설 ↓
  High-K 유전체 → 커패시턴스↑·전하 유지↑
  3D VCT → 채널 길이↑·누설↓
       ↓
회로 레벨 (리프레시 제어):
  PASR → 사용 영역만 리프레시
  DSR  → 대기 모드 최소 리프레시
  VRR  → 셀별 최적 주기 설정
       ↓
시스템 레벨 (환경 적응):
  TCSR → 온도별 주기 자동 조절
  TRR  → 로해머 대응 + 리프레시 최적화
  AI 기반 예측 리프레시 (연구 단계)

[누설 차단 기술 효과]
매립형 게이트 적용 전·후:
  서브임계 누설:  100nA → 1nA  (100배↓) ✅
  GIDL 누설:     50nA  → 0.5nA (100배↓) ✅
  리프레시 주기: 64ms → 128ms 연장 가능
  리프레시 전력: 최대 50% 절감 ✅
```
