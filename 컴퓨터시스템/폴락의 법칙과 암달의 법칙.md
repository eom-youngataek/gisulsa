#### Ⅱ. 암달의 법칙 핵심 원리

**가. 정의 및 수식**

```
[암달의 법칙 (Amdahl's Law)]

Gene Amdahl 1967년 제안

S(n) = 1 / [(1-P) + P/n]

S(n): 전체 속도 향상 비율 (Speedup)
P   : 병렬화 가능한 구간 비율 (0~1)
n   : 병렬 프로세서 수

핵심 한계:
n → ∞ 일 때 S(∞) = 1/(1-P)

→ 아무리 코어를 늘려도
  순차 실행 구간(1-P)이 상한을 결정
```

***

**나. 암달의 법칙 수치 예시**

| 병렬화 비율(P)        | 코어 2개 | 코어 4개 | 코어 8개 | 코어 ∞개 (이론 상한) |
| :--------------- | :---- | :---- | :---- | :------------ |
| **P=0.5 (50%)**  | 1.33배 | 1.60배 | 1.78배 | **2.0배**      |
| **P=0.8 (80%)**  | 1.67배 | 2.50배 | 3.08배 | **5.0배**      |
| **P=0.9 (90%)**  | 1.82배 | 3.08배 | 4.71배 | **10.0배**     |
| **P=0.95 (95%)** | 1.90배 | 3.48배 | 5.93배 | **20.0배**     |

→ 암기: **"순차 구간 10%만 남아도 코어 무한 추가 시 이론 상한 10배 — 95%를 병렬화해도 20배가 천장"**

#### Ⅲ. 폴락의 법칙 핵심 원리

**가. 정의 및 수식**

```
[폴락의 법칙 (Pollack's Rule)]

Fred Pollack (Intel) 1999년 제안

성능 향상 ∝ √(복잡도 증가)

복잡도 2배 → 성능 √2 ≈ 1.41배
복잡도 4배 → 성능 √4 = 2배
복잡도 9배 → 성능 √9 = 3배

핵심 의미:
단일 코어 성능을 2배 높이려면
트랜지스터·다이 면적을 4배 투자해야 함

→ 단일 코어 고성능화의 수익 체감
→ 복잡도 대비 성능 향상 제곱근 비례
```

***

**나. 폴락의 법칙 수치 예시**

| 복잡도(트랜지스터) 증가 | 성능 향상         | 실제 비용 효율          |
| :------------ | :------------ | :---------------- |
| **2배**        | √2 ≈ 1.41배    | 비용 대비 효율 낮음 🚨    |
| **4배**        | √4 = 2배       | 4배 투자→2배 성능       |
| **같은 면적·2코어** | √2+√2 = 2.83배 | **단일 고성능보다 유리** ✅ |

→ 암기: **"단일 코어를 키우는 것보다 코어를 나누는 것이 면적 대비 성능이 높다 — 폴락의 법칙이 멀티코어 시대를 열었다"**

#### Ⅳ. 두 법칙 비교 및 AI 반도체 연계

**가. 핵심 비교**

| **핵심 척도**     | **📊 암달의 법칙 🚨**                                                   | **🔑 폴락의 법칙 🚨**                                                                        | **🏁 설계 시사점 💯**                                                            |
| :------------ | :----------------------------------------------------------------- | :-------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| **핵심 주장**     | 병렬화해도 순차 구간이 성능 상한 결정 / S(∞) = 1/(1-P)                             | 단일 코어 복잡도 증가 시 성능은 제곱근 비례 향상 / 복잡도 N배→성능 √N배                                            | 두 법칙 결합 → **멀티코어·이기종 컴퓨팅 필연**                                               |
| **병목 지점**     | **순차 실행 구간(1-P)** / 아무리 코어 추가해도 해결 불가                              | **단일 코어 면적·전력** / 2배 면적으로 1.41배 성능 = 비효율                                                | 암달: 소프트웨어 병렬화 필수 / 폴락: 하드웨어 멀티코어 설계 필수                                      |
| **AI 반도체 연계** | GPU 수천 코어도 순차 구간이 병목 / AI 파이프라인 병렬화 설계 필수 / 앞서 다룬 **멀티에이전트 병렬 분업** | 단일 GPU 코어 고성능화 한계 / 앞서 다룬 **텐서코어·시스톨릭 어레이** = 특화 단순 코어 다수 / 앞서 다룬 **NPU = 폴락 법칙 극복 설계** | 앞서 다룬 **CXL 메모리 풀링**: 메모리 병목이 새로운 암달 한계 / 앞서 다룬 **HBM4**: 메모리 대역폭으로 새 병목 해소 |

```
  성능 = 1.0×4 = 4.0배 ████████████████████
  → 단일 코어 9배 복잡(3.0배)보다 우월 ✅

[두 법칙이 만든 컴퓨팅 패러다임 전환]

  폴락 한계 봉착 → 클록 증가 중단
       ↓

  암달 한계 봉착 → 순차 구간이 병목
       ↓

  CPU(순차) + GPU(병렬) + NPU(특화)

       ↓
AI 가속기 시대 (2020s~)
  앞서 다룬 텐서코어·시스톨릭 어레이
  행렬 연산 특화 단순 코어 수천 개
  암달·폴락 동시 극복 설계
```

**(제언)** "암달의 법칙과 폴락의 법칙은 '성능 향상에는 반드시 수학적 한계가 있다'는 컴퓨터 아키텍처의 근본 진리입니다. **암달의 법칙은 소프트웨어 병렬화(순차 구간 최소화)를 강제하고, 폴락의 법칙은 하드웨어 멀티코어·특화 코어 설계를 강제해 두 법칙이 결합해 앞서 다룬 GPU의 수천 단순 코어·NPU의 시스톨릭 어레이·텐서코어 설계를 이론적으로 정당화하며, AI 시대에는 HBM 메모리 대역폭·CXL 연결이 새로운 암달 병목으로 부상하므로 메모리-연산 공동 최적화가 차세대 AI 반도체 설계의 핵심 과제입니다.**"
